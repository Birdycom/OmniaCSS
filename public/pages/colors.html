    Color Utilities Playground

    Browse generated Omnia, HTML and RAL color utilities. This page is used as the visual reference for tokens and color classes.

    Color values now include modern models: OKLCH and OKLAB. You can set the generated utility output model via $DEFAULT-COLOR-TYPE-VALUE in omniacss.config.scss.

    Note: hover or focus a color card to see HEX, RGB, HSL, OKLCH and OKLAB in the tooltip.

    In the palette preview, hover any swatch to read its values (keyboard: focus the base swatch).
