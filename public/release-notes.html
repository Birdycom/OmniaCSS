    v0.17.3

    24 November 2026 latest

    Two small fixes for narrow screens: the contact form block follows --oc-block-gap and long words in display titles now break instead of overflowing.

    New

    • Utility .break-words (overflow-wrap: break-word), next to the existing .wrap-break-word and .wrap-anywhere, with a docs section on long words.

    Fixed

    • Contact form block: under 30rem the inline padding is no longer a fixed 0.5rem. It follows --oc-block-gap (default 0.5rem), so a site that sets the gap keeps its alignment on phones.
    • Display titles (.oc-display and .oc-display--page): long words such as "Datenschutzerklärung" no longer run outside a 390px screen. They get overflow-wrap: break-word and hyphens: auto (only words of 10 letters or more).
    • Combobox: a closed combobox (data-open="false") no longer turns its chevron upward or opens its list through the [data-open] selector.

    v0.17.2

    23 November 2026

    Small additions for app headers and data-heavy screens: a ghost header trigger and icon-only mode for Combobox, radio groups in Dropdown, custom bulk actions and column widths in DataTable, asChild on Button and a search slot that collapses with any search field.

    New

    • Combobox in a header bar: triggerVariant="ghost", size="header" (36px, auto width 6.5rem to 14rem, list in the body by default) and iconOnly (36x36; shows triggerLabel, else the icon or emoji of the chosen option, else a dots icon) with triggerAriaLabel. React, Vue and Blade.
    • DropdownRadioGroup and DropdownRadioItem (React, Vue, Blade). The existing DropdownItem radio checked keeps working.
    • DataTable bulkActions: add your own bulk buttons (key, label, icon, tone, disabled, hidden) or replace the built-in ones. onBulk, @bulk and the oc-datatable-bulk event receive the key.
    • DataTable column width and minWidth.
    • Button asChild (React): render your own element, such as a router link, with the button classes merged in.

    Improved

    • The collapsing search slot of the app header now works with a combobox or any search field, not only a plain .oc-input.

    Check when you update

    • React Combobox: the HTML size attribute (a number) of the input is no longer passed through, because size now takes "full" or "header".

    v0.17.1

    23 November 2026

    A release notes page, status badges with icons, a compound Breadcrumb, currency and percent fields, theming tokens for buttons and fixes for dark mode with a .dark class.

    New

    • A “Release notes” page (/release-notes.html) with every release, newest first, and its own item in the menu of omniacss.eu and omniaui.eu.
    • Status badges with an icon: status="paid", "overdue", "in-progress" … (.oc-badge--status + data-status), and a read-only value chip (variant="readonly").
    • Compound Breadcrumb (BreadcrumbList, BreadcrumbItem, BreadcrumbLink, BreadcrumbPage, BreadcrumbSeparator, BreadcrumbEllipsis) and maxItems, which folds the middle of a long trail into a “…” menu.
    • DecimalInput presets: currency="EUR" shows the symbol where the locale writes it, percent adds “%” after the value.
    • Button theming tokens: --oc-btn-radius, --oc-btn-hover-mix, --oc-btn-hover-tint, --oc-btn-hover-opacity, --oc-btn-outline-mix and --oc-btn-disabled-opacity, all unset by default.
    • .oc-btn--inherit and the inherit prop: an outline or ghost button on a dark or colored band follows the text color around it.
    • DataTable onReorder (React) and the reorder event (Vue): the new row order after a drag (the drag itself is OmniaUI Pro).
    • AppHeader searchCollapse: on a narrow bar the search shrinks to a magnifier and opens over the bar on focus.

    Improved

    • Both sites keep the header in view while you scroll and end every page with one full-width footer bar: copyright, version and the same links on omniacss.eu and omniaui.eu.
    • “Our story” has its place in the main menu of both sites.
    • Barcode: fallback="code128" draws an EAN or UPC value with a wrong check digit as Code 128 instead of an error.
    • OtpInput marks the cell the caret is in, and onComplete also fires when the full code arrives from outside.
    • Webicons: 18 more built-in icons, among them those of the status badges and the breadcrumb ellipsis.
    • Meta descriptions of 55 docs pages now have 120 to 160 characters for search engines.

    Check when you update

    • The --oc-info token is sky blue: info badges, alerts and toasts now differ from the primary color.

    Fixed

    • Dark mode with a .dark or .light class on <html> (Tailwind, shadcn) also sets color-scheme, so form fields and scrollbars follow.
    • The Pro blocks shop product and status page no longer scroll sideways on a 360px screen.
    • The avatar example in the docs.

    v0.17.0

    23 November 2026

    New websites for OmniaCSS and OmniaUI, React, Vue, Blade and Livewire code for every component and block, module colors, the ledger variant, compound components and liquid glass.

    New

    • New home pages for omniacss.eu and omniaui.eu, drawn like a technical drawing, with a new site footer and the “Our story” page (/story.html).
    • Every component and block demo shows HTML, React, Vue, Blade and Livewire code. A code-tabs check runs with the tests.
    • Module colors: data-module, the --oc-module, --oc-module-soft and --oc-module-fg tokens and a module prop.
    • variant="ledger", a Combobox catalog, FormField, input masks and validation.
    • Compound Tabs, Dialog, Popover and Tooltip; AppHeader overflow, a Sidebar provider and a server-side DataTable (free); reorder and ColumnMenu in Pro.
    • Liquid glass with a refracting lens and dragging (Chromium, a frosted look elsewhere), the .oc-btn--float heart button, HeroMedia, split--reverse, aspect--flush, dl--numbered and a scrim.
    • d-* display aliases (d-block, d-flex …) with responsive variants.
    • Print utilities for printable reports: print-hidden, print-only, print-light and page-a4.
    • New components: Calendar (a day or a range), Countdown, SaveStatus, HeaderSettings with ThemeToggle, answer tiles (correct or wrong) and a locked EmptyState.
    • A tooltip on the color palette, playground chips and “What is new” at the top of the components and blocks overviews.

    Improved

    • Redesigned blocks: product grid, hub launcher, features, contact grid and the Pro CMS dashboard.
    • DataTable: translatable labels; view, pagination and bulk actions can be turned off; a print style.
    • Tables with columns sized to their content (--auto), columns that hide in a narrow table and action labels that give way on small screens.
    • Alerts with an icon, buttons and an alarm state; ColorField checks contrast; a collapsed sidebar shows its labels as tooltips; the sidebar opens over the content on tablets.
    • Icon props of the Blade components render as inline SVG through x-oc::webicon.
    • Search engines and share previews on both sites: canonical URLs, Open Graph, Twitter cards, JSON-LD, a 404 page, a sitemap, robots.txt and llms.txt.
    • Syntax colors in every code tab.

    Fixed

    • Blade slots: run php artisan view:clear after you update a Laravel app.
    • Demo data is neutral everywhere (Company 1, Customer 1).
    • Many small fixes on both sites, in light and dark mode and on phones.

    v0.16.0

    17 November 2026

    Creative utilities, new components and free blocks, every docs example in one fixed layout with its full code, tested in Chrome, Firefox and Opera.

    New

    • Utilities for creative effects: border-conic-spin, shadow-neon, text-shadow-neon, text-shadow-3d, glass, animate-float, animate-typing, animate-wave, animate-beat, transition-clip, clip-circle-0, clip-circle-cover, mask-ring, bg-size-full, ease-overshoot and more.
    • scroll-buttons-outside: the arrows of a carousel sit next to the slides.
    • Components: Paper (grain, lines, squares, edges), a combobox with icons, a language menu (flag, own language name, check mark), Logo, mode badge, code plate, a card with an accent band and sheet options (glass, inset, footer panel).
    • Smaller additions: theme.js (remembers the theme without a flash on load), theme choice as cards, separate images for light and dark, .oc-card-grid--scroll, .oc-status-list, .oc-badge--status, card colors through data-tone and a round close button (.oc-close--round).
    • Free blocks: type picker, content blocks, route steps, route progress and step view.
    • The editor extension (IntelliSense 0.16.0) knows all these classes.

    Improved

    • Docs: every example in one fixed layout, with the full code under each example.
    • Glow is an option now (.oc-project-card--glow); the default shadow is neutral.
    • Contact form and call to action are flatter; example names are neutral (Company 1, Customer 1 …).

    Check when you update

    • Hover movement: hover:scale-*, hover:rotate-* and hover:translate-* were applied twice. Now once, so the movement is half of what it was. hover:translate-y-1 now moves down, as its name says.
    • .oc-btn--gradient is calmer (soft gradient, normal button shape, no glow) and .oc-btn--glass is no longer a pill. Add .oc-btn--pill for the old shape.
    • .oc-block-cta puts the text on the left and the buttons on the right. The old centered look is .oc-block-cta--center; new: --solid.
    • Checkbox and radio (.oc-checkbox, .oc-radio) are drawn by OmniaUI, because Opera ignores accent-color. They look the same in every browser.
    • .oc-section-content has a side margin of 1rem (was 1rem 4rem), in line with the header and footer.
    • Block breakpoints: about-timeline, faq and watch-layout switch at 44rem, services-tabs at 40rem.

    Fixed

    • .border-image-stripes shows diagonal stripes again.
    • Glass in the site header follows the theme, also with reduced motion.
    • Fly-in stays inside the grid; AffixInput no longer grows wider than its column.
    • The DataTable card view also works when the wrapper comes from the npm package.
    • Sheet: animation and a click next to the panel; the close button is centered. The wizard dialog has a close button.
    • Firefox: context menu, carousel dots, glass, chart and phone field.
