    Interactivity

    CSS class _interactivity.scss interactivity/index.html 0 KB JavaScriptNewest CSSv0.3.0

    Utilities for controlling user interaction: cursor styles, user selection, pointer events, scroll behavior, snap, touch actions, resize, will-change, accent color, appearance, caret style and color scheme — plus newer features: auto-growing form fields (field-sizing), customizable <select>, reading-flow, CSS carousel scroll markers, scroll anchoring and print color control.

    The four pages at a glance

    This group has four pages. Below is one small, real example from each: try it, then open the page for every class and the details.

    Interactivity at a glance: one example per page

    .cursor-* · .select-all
    Cursor, selection & pointer. Move the mouse over the three boxes: the pointer changes. Click the address once: all of it is selected.

    Form controls. The native checkbox, radio and slider take one color (Opera ignores accent-color). Type in the text field: it grows with your text.
    .flex-row-reverse · .reading-flow-flex-visual
    Performance & accessibility. The HTML lists Step 3, 2, 1; the row shows them reversed. Click Step 1 and press Tab: the focus follows the order you see (Chrome 137+).

<span class="select-all">info@company1.example</span>

<!-- 2. a row that snaps (the cards have a fixed width, e.g. 10rem) -->
<div class="flex gap-0.8 overflow-x-auto snap-x">
  <div class="snap-start">Product 1</div>
  <div class="snap-start">Product 2</div>
  <div class="snap-start">Product 3</div>
  <div class="snap-start">Product 4</div>
  <div class="snap-start">Product 5</div>
  <div class="snap-start">Product 6</div>
</div>

<!-- 3. native controls in one color, a field that grows -->
<label><input type="checkbox" class="accent-green" checked> Send me the invoice</label>
<label><input type="radio" name="plan" class="accent-green" checked> Monthly plan</label>
<label>Seats <input type="range" class="accent-green" min="1" max="10" value="6"></label>
<label>Name <input type="text" class="field-sizing-content" value="Customer 1"></label>

<!-- 4. Tab follows the order you see -->
<div class="flex flex-row-reverse reading-flow-flex-visual">
  <button>Step 3</button><button>Step 2</button><button>Step 1</button>
</div>
