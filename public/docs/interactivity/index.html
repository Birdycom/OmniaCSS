    Interactivity

    CSS class _interactivity.scss interactivity/index.html 0 KB JavaScriptNewest CSSv0.3.0

    Utilities for controlling user interaction: cursor styles, user selection, pointer events, scroll behavior, snap, touch actions, resize, will-change, accent color, appearance, caret style and color scheme — plus newer features: auto-growing form fields (field-sizing), customizable <select>, reading-flow, CSS carousel scroll markers, scroll anchoring and print color control.
