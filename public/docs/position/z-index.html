    Stacking / Z-Index

    _layering.scss 0 KB JavaScriptBaselinev0.2.0

    Control the stacking order of elements that overlap.

    What: z-index orders overlapping boxes inside a stacking context; higher numbers paint on top. When: dropdowns above content, sticky headers above scrolling rows, overlays above everything. Gotchas: z-index only works on positioned elements (anything but static) and on flex or grid children; a parent that creates a stacking context (position + z-index, opacity < 1, transform, isolation: isolate) traps its children, so .z-50 inside a low parent still loses to a sibling of that parent. Keep a small scale (the 0 to 50 steps here) instead of ever larger numbers. More: MDN: Understanding z-index.
