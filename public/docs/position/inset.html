    Inset

    _position.scss 0 KB JavaScriptBaselinev0.2.0

    Utilities for controlling the distance of positioned elements from their parent container.

    What: top, right, bottom, left (and the inset shorthand) set how far a positioned element sits from the edges of its reference box. When: pin badges to a corner (.absolute .top-2 .right-2), stretch an overlay over its parent (.absolute .inset-0), put a dropdown right under its trigger (.absolute .top-full). Gotchas: insets do nothing on position: static; opposite insets on a box without explicit size stretch it (left-0 right-0 makes it as wide as the parent); for direction-aware layouts prefer the logical variants on the Writing Modes page. More: MDN: inset.

    Class GroupValues
    .top-{n}0, 1 (0.25rem), 2, 4, 8, full (100%), auto
    .right-{n}same scale
    .bottom-{n}same scale
    .left-{n}same scale
    .inset-{n}shorthand for all sides
