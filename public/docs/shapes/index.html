    Shapes & Clipping

    CSS class _shapes.scss shapes/index.html 0 KB JavaScriptBaselinev0.3.0

    Clip elements to geometric shapes with clip-path, and let text flow around a floated shape with shape-outside. The .clip-shape-* classes use the newer shape() function for responsive curves. See MDN: clip-path.

    Clip path — basic shapes

    Basic shapes and reference boxes. Everything outside the shape is hidden — including a normal border. For a border that follows the shape, wrap the element in .clip-border-* (see below).

    What it does: clip-path hides everything outside a shape; the hidden part no longer paints or receives pointer events. When to use: non-rectangular images and cards, diagonal section edges, reveal animations. Gotchas: clipping also cuts off the border, outline and box-shadow (draw the border with the .clip-border-* wrapper instead); percentages refer to the element's own box; and a clipped element still occupies its full rectangle in the layout. Use mask instead when you need soft, anti-aliased or gradient edges. See MDN: clip-path.

    .clip-noneclip-path: none
    .clip-circleclip-path: circle(50%)
    .clip-ellipseclip-path: ellipse(50% 40%)
    .clip-inset-4clip-path: inset(4px)
    .clip-inset-8clip-path: inset(8px round 8px)
    .clip-border-boxclip-path: border-box
    .clip-padding-boxclip-path: padding-box
    .clip-content-boxclip-path: content-box

    Clip border

    A normal border is cut away by clip-path. Put .clip-border-* on a wrapper around the clipped element: stacked drop-shadow() filters draw an outline that follows the exact shape (polygon, circle or shape()). The color is the wrapper's text color (e.g. .text-dodgerblue-20); the clipped element needs an opaque background.

    ClassCSS
    .clip-borderfilter: drop-shadow(±1px) × 4 — 1px border in currentcolor
    .clip-border-2filter: drop-shadow(±2px) × 4 — 2px border in currentcolor
    .clip-border-4filter: drop-shadow(±4px) × 4 — 4px border in currentcolor

    Shape outside & shape margin

    Wraps inline content around a floated element. Combine with a float class (.float-left) and usually with the matching .clip-* class so the visual matches the wrap.

    ClassCSS
    .shape-noneshape-outside: none
    .shape-circleshape-outside: circle(50%)
    .shape-ellipseshape-outside: ellipse(50% 40%)
    .shape-margin-boxshape-outside: margin-box
    .shape-border-boxshape-outside: border-box
    .shape-padding-boxshape-outside: padding-box
    .shape-content-boxshape-outside: content-box
    .shape-m-0shape-margin: 0
    .shape-m-1shape-margin: 0.25rem
    .shape-m-2shape-margin: 0.5rem
    .shape-m-4shape-margin: 1rem

    What it does: shape-outside changes the area that inline content has to avoid around a floated element, from the default rectangle to a circle, ellipse, polygon, inset, or even the alpha channel of an image or gradient. shape-margin adds breathing room between the shape and the text. When to use: editorial layouts, pull-quotes and avatars with text flowing around them. Gotchas: the element must be floated and have an explicit width and height (a circle of 50% is relative to that box); the shape only affects text, not the visual, so pair it with a matching clip-path; and there must be enough text next to the float, otherwise you do not see the wrap. See MDN: shape-outside and MDN: shape-margin.

    Circle: float-left + shape-circle + shape-m-4 + clip-circle

    Other shapes: ellipse, polygon, inset and gradient

    Use the classes for the common shapes and an inline shape-outside for anything custom. A polygon makes text follow a diagonal edge (a triangle floated left makes lines longer as you go down); inset(… round …) follows rounded corners; and a gradient or image makes text wrap around every pixel whose alpha is above shape-image-threshold.

    Animate a clip-path: reveal on hover

    clip-path is animatable between shapes with the same number of points, so a plain transition gives you reveals and morphs. Hover or focus the tiles: the left one reveals from inset(0 100% 0 0), the middle morphs a circle, the right one grows a polygon. No JavaScript.

    transition: clip-path

    inset reveal
    circle grow
    polygon morph
    1
2
    .tile { clip-path: inset(0 100% 0 0); transition: clip-path 0.5s; }
.tile:hover { clip-path: inset(0 0 0 0); }
