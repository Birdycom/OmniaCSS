    Intentionally not generated

    • Language features, not utilities: selectors, combinators, pseudo-classes, specificity, !important, cascade layers, nesting, @scope, custom properties, @property, @function, if(), attr(), sibling-index(), units and math functions — use them in your own CSS (see Fluid values for clamp()/min()/max()).
    • Deprecated or non-standard: box-* (old flexbox), ime-mode, color-adjust, -webkit-* proprietary properties without a standard equivalent.
    • Not implemented in any browser yet: block-ellipsis, max-lines, continue, white-space-trim, wrap-inside, hyphenate-limit-lines, background-repeat-x/-y, path-length, link-parameters.
    • Specs still changing: animation-trigger / timeline-trigger-*, border-shape, flow-tolerance, frame-sizing, scroll-axis-lock, window-drag, display: grid-lanes (masonry).
