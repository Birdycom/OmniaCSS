    Font Variants & Text Effects

    CSS class _font_variants.scss variants.html 0 KB JavaScriptNewest CSSv0.3.0

    OpenType features (small caps, ligatures, sub/superscript glyphs, emoji presentation), variable font axes, fallback-font tuning with font-size-adjust, hyphenation details, text stroke/fill effects, ruby annotations and MathML styles. Numeric variants are .font-num-* on the Font Style page. See MDN: font-variant.

    Caps, ligatures & position

    Font features need a font that contains them; otherwise the browser synthesizes or ignores them.

    ClassCSS
    .font-caps-{normal|small|all-small|petite|all-petite|unicase|titling}font-variant-caps
    .font-lig-{normal|none|common|no-common|discretionary|historical|contextual}font-variant-ligatures
    .font-pos-{normal|sub|super}font-variant-position
    .font-east-{normal|jis04|simplified|traditional|full-width|proportional|ruby}font-variant-east-asian
    .font-emoji-{normal|text|emoji|unicode}font-variant-emoji
    .font-alt-{normal|historical}font-variant-alternates
    .font-variant-{normal|none}font-variant

    font-caps-small, font-caps-all-small, font-lig-none, font-emoji-text

    .font-caps-small Small Caps
    .font-caps-all-small All Small
    .font-lig-none office fl
    .font-emoji-text ☎ ✂ ♥

    Variable fonts & size adjust

    font-variation-settings sets variable font axes directly — it only has effect with a variable font (the demo uses Inter Variable). font-size-adjust keeps the x-height equal when a fallback font is used.

    ClassCSS
    .font-wght-{100…900}font-variation-settings: "wght" {n}
    .font-wdth-{75|125}font-variation-settings: "wdth" {n}
    .font-slnt-n10font-variation-settings: "slnt" -10
    .font-variation-normalfont-variation-settings: normal
    .font-size-adjust-{none|from-font|0.5|ex|cap}font-size-adjust
    .font-synthesis-{weight|style|small-caps}-nonefont-synthesis-{part}: none
    .font-lang-normalfont-language-override: normal

    font-wght-300 vs font-wght-800

    .font-wght-300 Omnia
    .font-wght-800 Omnia

    Hyphenation, justify & wrap mode

    Fine-tune hyphenation (use with .hyphens-auto and a lang attribute), justification and line wrapping.

    ClassCSS
    .hyphenate-char-{auto|dash|equals}hyphenate-character
    .hyphenate-limit-{auto|6|10}hyphenate-limit-chars: auto | 6 3 2 | 10 4 4
    .text-justify-{auto|none|inter-word|inter-character}text-justify
    .text-wrap-mode-{wrap|nowrap}text-wrap-mode
    .text-combine-{none|all}text-combine-upright (vertical text)

    Text effects & emphasis

    Outline text with a stroke, make the fill transparent, and set emphasis-mark style and color separately.

    ClassCSS
    .text-stroke-{0|1|2}-webkit-text-stroke-width
    .text-stroke-{current|white|black}-webkit-text-stroke-color
    .text-fill-{transparent|current}-webkit-text-fill-color
    .text-outline-webkit-text-stroke: 1px currentcolor; fill: transparent
    .emphasis-style-{filled|open|double-circle}text-emphasis-style
    .emphasis-color-{current|red|blue}text-emphasis-color

    text-outline, text-stroke-1 + text-stroke-black

    .text-outline Outline
    .text-stroke-1 .text-stroke-black Stroke
    .emphasis-style-open .emphasis-color-red 強調

    Ruby & MathML

    Position and align ruby annotations (<ruby>/<rt>) and switch MathML between display and inline style.

    ClassCSS
    .ruby-{over|under|inter-character}ruby-position
    .ruby-align-{start|center|space-between|space-around}ruby-align
    .ruby-overhang-{auto|none}ruby-overhang
    .math-{normal|compact}math-style
    .math-depth-{auto|0}math-depth: auto-add | 0
    .math-shift-{normal|compact}math-shift

    ruby-over, ruby-under, math-compact

    .ruby-over 漢kan字ji
    .ruby-under 漢kan字ji
    .math-normal 12
    .math-compact 12
