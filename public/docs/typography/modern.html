    Modern Typography

    CSS class _typography_modern.scss modern.html 0 KB JavaScriptNewest CSSv0.3.0

    Newer typography features: trim the extra space above and below text with text-box, drop caps with initial-letter, emphasis marks, CJK spacing control and font rendering switches. These complement the Advanced utilities (line clamp, text-wrap, hyphens). See MDN: text-box.

    Text box trim

    Removes the half-leading above the cap height and below the baseline, so text is optically centered in buttons and badges.

    ClassCSS
    .text-box-normaltext-box: normal
    .text-box-trimtext-box: trim-both cap alphabetic
    .text-box-trim-starttext-box-trim: trim-start; text-box-edge: cap alphabetic
    .text-box-trim-endtext-box-trim: trim-end; text-box-edge: cap alphabetic
    .text-box-trim-extext-box: trim-both ex alphabetic

    text-box-normal vs text-box-trim

    .text-box-trim Omnia

    Text wrap style & white space

    .text-stable keeps earlier lines stable while the user edits text. The white-space-collapse classes control space collapsing independently of wrapping (.text-balance, .text-pretty live in Advanced).

    ClassCSS
    .text-stabletext-wrap-style: stable
    .text-wrap-autotext-wrap-style: auto
    .whitespace-collapsewhite-space-collapse: collapse
    .whitespace-preservewhite-space-collapse: preserve
    .whitespace-preserve-breakswhite-space-collapse: preserve-breaks
    .whitespace-preserve-spaceswhite-space-collapse: preserve-spaces
    .whitespace-break-spaceswhite-space-collapse: break-spaces

    Initial letter

    Drop caps on the first letter of a paragraph. .initial-letter-3-2 = 3 lines tall, sunk 2 lines.

    ClassCSS
    .initial-letter-normal::first-letter { initial-letter: normal }
    .initial-letter-2::first-letter { initial-letter: 2 }
    .initial-letter-3::first-letter { initial-letter: 3 }
    .initial-letter-3-2::first-letter { initial-letter: 3 2 }

    CJK spacing & hanging punctuation

    text-spacing-trim trims full-width punctuation, text-autospace adds space between CJK and Latin text, and hanging-punctuation lets quotes hang outside the text block.

    ClassCSS
    .text-spacing-trim-normaltext-spacing-trim: normal
    .text-spacing-trim-autotext-spacing-trim: auto
    .text-spacing-trim-space-alltext-spacing-trim: space-all
    .text-spacing-trim-space-firsttext-spacing-trim: space-first
    .text-autospace-normaltext-autospace: normal
    .text-autospace-autotext-autospace: auto
    .text-autospace-nonetext-autospace: no-autospace
    .hanging-nonehanging-punctuation: none
    .hanging-firsthanging-punctuation: first
    .hanging-lasthanging-punctuation: last
    .hanging-first-lasthanging-punctuation: first allow-end last
    .break-auto-phraseword-break: auto-phrase
