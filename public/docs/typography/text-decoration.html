    Text Decoration

    CSS class _text.scss text-decoration.html 0 KB JavaScriptBaselinev0.2.0

    Utilities for controlling the decoration (lines, styles, and thickness) of text.

    ClassCSS
    .underline .overline .line-throughtext-decoration-line: underline | overline | line-through
    .no-underlinetext-decoration-line: none
    .decoration-{solid|double|dotted|dashed|wavy}text-decoration-style
    .decoration-0 … .decoration-5text-decoration-thickness: 0em … 0.5em (steps of 0.1em)
    .decoration-autotext-decoration-thickness: auto
    .decoration-{color}text-decoration-color (every palette color, e.g. .decoration-red)
    .decoration-{color}-{10…95}the same color at 10 … 95% opacity
    .underline-offset-1 … .underline-offset-4text-underline-offset: -0.4em … -0.1em (line moves up, into the letters)
    .underline-offset-5 … .underline-offset-9text-underline-offset: 0.1em … 0.5em (line moves down)
    .underline-offset-normaltext-underline-offset: 0em
    .underline-{auto|under|left|right}text-underline-position
    .decoration-skip-spaces-{all|none}text-decoration-skip-spaces
    .decoration-inset-autotext-decoration-inset: auto
    .decoration-clone .decoration-slicebox-decoration-break (how padding and borders behave when an inline element wraps)

    Line

    Pick where the line goes: under, over or through the text. .no-underline removes the underline that links get from the browser.

    Skip ink: why a line can look broken

    By default the browser leaves a small gap in an underline wherever a letter hangs below the line, such as g, j, p, q and y. That keeps links easy to read, but a wavy or thick line then looks broken. Compare the three tiles: the first skips, the second sets text-decoration-skip-ink: none, the third moves the line below the letters with .underline-under.

    skip-ink auto vs none vs underline-under

    skip-ink: auto (default)
    The line stops at p, p and g.

    Shipping

    skip-ink: none
    One continuous line; it runs through the letters.

    Shipping

    .underline-under
    The line sits below the lowest letter, so nothing is in its way.

    Shipping

    Thickness

    The number is the thickness in tenths of the font size: .decoration-1 is 0.1em, .decoration-3 is 0.3em. Because it is in em, the line grows with the text. .decoration-auto lets the font decide.

    .decoration-auto
    The thickness the font itself suggests.

    Underline offset

    Move the underline away from the text. Classes 5 to 9 push it down in steps of 0.1em; classes 1 to 4 are negative and pull it up into the letters, which is only useful for special effects.

    underline-offset-normal, 5, 7, 9

    The line sits where the font puts it.

    Color, and putting it together

    Give the line its own color with .decoration-{color}. Two everyday uses: a red wavy line that marks a spelling mistake, and a link that only shows its line when you point at it. Hover the link to try it.

    Spelling mark and hover link

    .underline .decoration-wavy .decoration-red
    A red wavy line marks a spelling mistake.

    Please recieve the order.

    .no-underline .hover:underline .focus-visible:underline
    No line until you hover the link or Tab to it.
