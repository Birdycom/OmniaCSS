    Fluid values (clamp, min, max)

    Use CSS clamp(), min(), and max() for responsive values without media queries: font-size and width scale with the viewport and stay within bounds. The next step, progress(), and the other math functions are on CSS Functions.

    clamp(), min(), and max() v0.2.0

    0 KB JavaScriptBaseline

    min() returns the smallest of its arguments; max() the largest. clamp(MIN, VAL, MAX) is equivalent to max(MIN, min(VAL, MAX)). The preferred value (VAL) is often viewport-relative (e.g. 7vw + 1rem).

    MDN: clamp() · MDN: min() · MDN: max()

    Function Meaning
    min(A, B, …)Smallest value. Use to cap (e.g. width at most 65ch).
    max(A, B, …)Largest value. Use to set a minimum (e.g. font-size at least 1rem).
    clamp(MIN, VAL, MAX)VAL clamped between MIN and MAX.

    min() and max() v0.2.0

    Use min() / max() on width for the same effect as width + min-width/max-width. Same idea for padding and margin. Override fluid-cap/floor with CSS variables: style="--w-cap-a: 40vw; --w-cap-b: 50ch". For fixed widths use generated classes like w-50vw, w-65ch (see _clamp.scss).

    Class Effect
    .text-minfont-size: max(1rem, 1.2vw)
    .w-fluid-capwidth: min(90vw, 65ch); override with --w-cap-a, --w-cap-b
    .w-fluid-floorwidth: max(20rem, 50vw); override with --w-floor-a, --w-floor-b
    .p-min, .m-minpadding/margin: min(1rem, 5vw)
    .p-max, .m-maxpadding/margin: max(0.5rem, 2vw)
    .w-50vw, .w-65ch, …fixed width (from $fluid-w-vw / $fluid-w-ch)

    Fluid font-size (clamp) v0.2.0

    .text-fluid, .text-fluid-heading, and .text-fluid-heading-wide (clamp(1.8rem, 7vw + 1rem, 5rem)). Defaults in src/scss/utilities/_clamp.scss.

    Variable / Class Default / Effect
    $fluid-font-*1rem / 1.2vw / 1.25rem
    $fluid-heading-*1.5rem / 2.5vw / 2rem
    .text-fluid-heading-wideclamp(1.8rem, 7vw + 1rem, 5rem)

    Fluid width v0.2.0

    .w-fluid and .max-w-fluid use clamp for readable line length. Variables: $fluid-width-min, $fluid-width-preferred, $fluid-width-max.

    Fluid width: w-fluid = clamp(20rem, 90vw, 65ch)

    Resize the browser window: these classes follow the window width (vw).Window: …
    .w-fluid
    width: clamp(20rem, 90vw, 65ch), now …
    A readable line length: 20rem at least, 65ch at most.
    .max-w-fluid
    max-width: clamp(20rem, 90vw, 65ch), now at most, now …
    Full width of the box, but never wider than the clamp.

    Custom use v0.2.0

    Override variables before importing OmniaCSS.

    Use the fluid-clamp($property, $min, $preferred, $max) mixin in your SCSS. See _clamp.scss.
