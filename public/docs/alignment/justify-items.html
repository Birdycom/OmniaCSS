    Justify Items

    _alignment.scss 0 KB JavaScriptBaselinev0.2.0

    Align grid items along the inline axis inside their grid area using .justify-items-{value}.

    In one sentence: justify-items moves every grid item along the inline axis (left to right) inside its own cell; it works in grid, and flexbox ignores it.

    It sets the default justify-self of all items in a grid. Each item moves inside its own cell, so you only see an effect when the item is narrower than the cell. The default is stretch, which fills the cell. left and right ignore the writing direction, start and end follow it. In flexbox use .justify-content or auto margins instead. See MDN: justify-items.

    Safe alignment when an item is too wide

    A centred item that is wider than its cell sticks out on both sides. In the first column that means past the left edge of the grid, where it cannot be scrolled to. safe keeps the start visible.

    center vs center-safe

    Item 1 is wider than its cellInline axis →
    .justify-items-center
    Item 1 sticks out of both sides of its cell. Its start is cut off at the left edge of the grid and you cannot scroll to it.
    Product 1 with a long name
    Item 2
    .justify-items-center-safe
    Falls back to start when the item does not fit, so its start stays visible. It only sticks out on the right, over the next cell.
