    Selectors & Pseudo-classes

    Variant variants.mjs selectors/index.html 0 KB JavaScriptBaselinev0.8.2

    In OmniaCSS every pseudo-class and pseudo-element is a variant: put it in front of any utility, separated by a colon (user-invalid:border-red-60, focus-visible:outline-2, target:block). Variants combine (md:hover:…), work on parents and siblings (group-*, peer-*, has-[…]) and accept any selector in brackets ([&>li]:…). omniacss build generates them on demand. See MDN: CSS selectors.

    Pseudo-class variants

    VariantSelector
    hover: focus: focus-visible: focus-within: active: visited:User action
    target::target — the element whose id is in the URL hash
    user-valid: user-invalid:Validity, only after the user interacted
    valid: invalid: required: optional: in-range: out-of-range: read-only: placeholder-shown: autofill:Form state
    checked: indeterminate: default: disabled: enabled:Control state
    open: popover-open: inert: empty:[open], :popover-open, :open, [inert], :empty
    first: last: only: odd: even: first-of-type: last-of-type: only-of-type:Structure
    nth-3: nth-last-2: nth-of-type-2: nth-[2n+1_of_.is-on]::nth-child(), :nth-last-child(), :nth-of-type(), An+B of S
    has-[…]: not-[…]: in-[…]::has(), :not(), ancestor :where()
    group-hover: group-has-[…]: peer-checked: peer-user-invalid: group-hover/name:State of a parent (.group) or previous sibling (.peer)

    :target — tabs without JavaScript

    A link to #id makes that element :target. The panels are d-none target:block; :has() highlights the active tab and shows the first panel when nothing is targeted. Use scroll-margin-top so a sticky header does not cover the target.

    d-none target:block

    Panel 2: shareable — the link opens this tab.

    :focus-visible — a focus ring for keyboard users only

    :focus also matches after a mouse click; :focus-visible only when the browser decides a ring helps (keyboard, programmatic focus). Click both buttons, then press Tab.

    :user-valid and :user-invalid — validation that waits for the user

    :invalid is red before anyone typed. :user-invalid waits until the user changed the field and left it (or submitted). The message uses peer-user-invalid:block, the form border reacts with has-[:user-invalid]:.

    user-invalid:, user-valid:, peer-user-invalid:, has-[:user-invalid]:

    Please enter a valid e-mail address. Looks good.

    :has() — style the parent

    has-[input:checked]: styles a card when the radio inside it is selected. The whole card is the label, so it is one click target.

    has-[input:checked]:border-vividblue-80 has-[input:checked]:bg-mistblue-20

    1
2
3
    <label class="has-[input:checked]:border-vividblue-80 has-[input:checked]:bg-mistblue-20">
  <input type="radio" name="plan"> <b>Pro</b>
</label>

    SelectorMatches / OmniaCSS
