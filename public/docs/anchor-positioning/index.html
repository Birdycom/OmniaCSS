    Anchor Positioning

    CSS class _anchor_positioning.scss anchor-positioning/index.html 0 KB JavaScriptBaselinev0.3.0

    Position an element relative to another element (the anchor) without JavaScript — ideal for tooltips, menus and popovers. Put .anchor-{name} on the trigger and .anchored-{name} plus an .anchor-area-* class on an .absolute or .fixed element. Available names: oc, trigger, menu, tooltip. See MDN: CSS anchor positioning.

    Anchor name & position anchor

    Register an anchor and attach a positioned element to it. What: anchor-name gives an element a dashed-ident name; position-anchor tells an absolutely or fixed positioned element which name to follow. When: tooltips, dropdowns, popovers, callouts, labels that must stay glued to another element without JavaScript. Gotcha: anchor names are global to the document, and when several elements share a name the last one in tree order wins, so a second tooltip on the page silently attaches to the wrong trigger. Put .anchor-scope-all on every repeated component (or on every demo) so each instance only sees its own anchor. More: MDN: anchor-name, MDN: anchor-scope.

    Position area

    Places the element in one of the nine cells of the grid around the anchor (top-left, top, top-right, left, center, ...). When: the easiest way to say "above / below / next to the anchor" with one declaration; the element is also limited to that cell, so it never exceeds the available room. Gotcha: the grid is built from the containing block (the nearest positioned ancestor), so give that ancestor .relative. Insets other than auto still apply inside the chosen cell (the popover UA style sets inset: 0, reset it with inset: auto). Logical values (block-start, inline-end) follow the writing direction. More: MDN: position-area.

    anchor() insets

    When the nine cells of position-area are not precise enough, use anchor() inside top, left, inset-* and friends: top: anchor(bottom) means "my top edge sits at the anchor's bottom edge". When: arrows, offsets, centering on an edge, lining up two specific edges. Gotcha: anchor() only works on absolutely or fixed positioned elements and only inside inset properties; use anchor-size() for sizes. Where anchor positioning is missing the declaration is invalid and the element keeps its static position. More: MDN: anchor().

    Position try & visibility

    Fallback positions when the element would overflow its containing block, and when to hide it. What: position-try-fallbacks lists alternatives (flip-block, flip-inline or your own @position-try rule) that the browser tries in order until one fits. When: tooltips and menus close to a screen or container edge. Gotcha: "fits" is measured against the containing block of the positioned element (for a fixed or popover element that is the viewport). position-visibility hides the element when its anchor scrolls out of view. More: MDN: position-try-fallbacks.

    Popover + anchor

    A popover lives in the top layer, so it escapes overflow: hidden and z-index battles, but it is also positioned against the viewport. Anchor positioning is the missing half: it glues the popover to its trigger. Two ways: name the trigger with .anchor-* and attach with .anchored-*, or skip the names entirely: a popover opened through popovertarget has the invoking button as implicit anchor (position-anchor: auto). Gotchas: the UA style gives popovers inset: 0; margin: auto, so reset with inset: auto and set your own margin; browsers without anchor positioning centre the popover in the viewport, which is still usable. Fallbacks (.anchor-try-flip-*) on a popover are evaluated against the viewport when it opens; inside an inner scroll container (like this documentation page) they can flip unexpectedly, so test them in your own layout. More: MDN: Using the Popover API.

    Anchor size

    Size the positioned element after its anchor, e.g. a dropdown menu as wide as its button. When: select-like menus, comboboxes, autocomplete lists. Gotcha: anchor-size() works in sizing properties (width, min-width, max-block-size, margins and insets); if the menu content can be wider, use .min-w-anchor instead of .w-anchor. More: MDN: anchor-size().
