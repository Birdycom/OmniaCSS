    Corner shape

    CSS class _corner_shape.scss corner-shape.html 0 KB JavaScriptNewest CSSv0.2.1

    Corner shape changes how the corners look inside the area defined by border-radius. Use it together with a radius utility (e.g. .round-6). Options: round (default), scoop, bevel, notch, square, squircle. Handy for distinctive cards or buttons. This is an experimental CSS feature — see MDN: corner-shape and check browser support.

    What it does: corner-shape changes the geometry of a corner while border-radius keeps controlling its size: round is the classic arc, scoop is concave, bevel is a straight cut, notch is a square cut-out, square ignores the radius and squircle is the smooth iOS-style curve. When to use: tickets, badges, buttons and cards with a distinct character, or app-icon style avatars. Gotchas: without a border-radius nothing happens; borders, outlines, shadows and backgrounds all follow the shape (that is the big win over clip-path); it is new (Chrome 139+), so browsers without it fall back to round corners and the design must still look fine. See MDN: corner-shape and the superellipse() function for custom curves.

    CSS classes

    All classes set corner-shape. Use .corner-round, .corner-scoop, .corner-bevel, .corner-notch, .corner-square, or .corner-squircle. Always combine with a radius utility (e.g. .round-6) so the shape has a size to work with.

    ClassCSS
    .corner-roundcorner-shape: round
    .corner-scoopcorner-shape: scoop
    .corner-bevelcorner-shape: bevel
    .corner-notchcorner-shape: notch
    .corner-squarecorner-shape: square
    .corner-squirclecorner-shape: squircle

    Per corner and custom curves

    Each corner has its own property (corner-top-left-shape, corner-bottom-right-shape, …) and accepts superellipse(<number>): superellipse(0) is a bevel, superellipse(1) a round corner and values above 1 give squircles. No utility class needed, set it inline or in your own CSS.

    Source & Further Reading

    The corner-shape utilities come from _corner_shape.scss in src/scss/utilities/. Classes: .corner-round, .corner-scoop, .corner-bevel, .corner-notch, .corner-square, .corner-squircle. Works together with border-radius (e.g. .round-6). Experimental; see the browser support table above and MDN: corner-shape.
