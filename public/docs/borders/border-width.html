    Border-width

    CSS class _borders_outlines.scss border-width.html 0 KB JavaScriptBaselinev0.2.0

    Border width controls how thick the border is. Use .border-none to remove it, or .border (1px) up to .border-12 (32px) for all sides. The same scale applies to one side (.border-t, .border-b, etc.), to horizontal or vertical pairs (.border-h, .border-v), or to combined sides (.border-trl, .border-brl, …). This section also includes divider classes: put .divider-h or .divider-v on a flex/grid parent to add lines between direct children. Always combine width with a style (e.g. .border-solid) and optionally a color. Values from $bordersizes and $dividersizes in _variables_layout.scss.

    What it does: border-width sets how thick the border is. The size classes (.border, .border-1 … .border-12) use rem so they scale with the font size; the side variants (.border-t1, .border-h1, …) set individual sides. When to use: 1px lines for cards and inputs, thicker borders for emphasis, one-sided borders for dividers and accents. Gotchas: borders add to the element size unless box-sizing: border-box applies (it does by default in OmniaCSS); a border only shows with a style (.border-solid); to avoid layout shift on hover keep the same width and just change the color (or use an outline). See MDN: border-width.

    CSS classes

    All classes set border-width. Use .border-none or .border … .border-12 for all sides; .border-t*, .border-r*, .border-b*, .border-l* for one side; .border-h*, .border-v* for horizontal or vertical; or combinations like .border-tl*, .border-trl*. Divider classes .divider-h* and .divider-v* apply a border between direct children (use on the parent only).
