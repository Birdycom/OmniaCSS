    Border-width

    CSS class _borders_outlines.scss border-width.html 0 KB JavaScriptBaselinev0.2.0

    Border width controls how thick the border is. Use .border-none to remove it, or .border (1px) up to .border-12 (32px) for all sides. The same scale applies to one side (.border-t, .border-b, etc.), to horizontal or vertical pairs (.border-h, .border-v), or to combined sides (.border-tl, .border-trl, .border-brl, …). This section also includes divider classes: put .divider-h or .divider-v on a flex/grid parent to add lines between direct children. Always combine width with a style (e.g. .border-solid) and optionally a color. Values from $bordersizes and $dividersizes in _variables_layout.scss.

    What it does: border-width sets how thick the border is. The size classes (.border, .border-1 … .border-12) use rem so they scale with the font size; the side variants (.border-t1, .border-h1, …) set individual sides. When to use: 1px lines for cards and inputs, thicker borders for emphasis, one-sided borders for dividers and accents. Gotchas: borders add to the element size unless box-sizing: border-box applies (it does by default in OmniaCSS); a border only shows with a style (.border-solid); to avoid layout shift on hover keep the same width and just change the color (or use an outline). See MDN: border-width.

    CSS classes

    All classes set border-width. Use .border-none or .border … .border-12 for all sides; .border-t*, .border-r*, .border-b*, .border-l* for one side; .border-h*, .border-v* for horizontal or vertical; or combinations like .border-tl* (top and left), .border-trl* (top, right and left). Divider classes .divider-h* and .divider-v* apply a border between direct children (use on the parent only).

    The width scale

    Every box has the same size and color; only the width class changes, so you can compare the steps. A border only shows with a style, so each box also has .border-solid and a color (.border-teal-50). .border-none (0) is left out because there is nothing to see.

    Every number from .border-1 to .border-12 exists; the example shows the main steps. The side classes (.border-t, .border-r12, .border-trl …) and the dividers (.divider-h-1, .divider-v-12, .divider-h-none …) take the same numbers; without a number they are 1px.

    Two or three sides

    h means the two horizontal lines (top and bottom), v the two vertical lines (left and right). Letter pairs and triples name the sides that get a border. Each class sets all four widths at once, so .border-t4 .border-l4 together do not add up: the last one in the stylesheet wins. Use .border-tl4 instead.

    In practice: dividers and an accent line

    Put .divider-h (between rows) or .divider-v (between columns) on the parent: every child except the last gets a line on its bottom or end side. The children still need a style on that side and no width elsewhere, so give them .border-none .border-b-solid (rows) or .border-none .border-r-solid (columns) plus a color. The callout on the right is a plain .border-l4.

    Source & Further Reading

    The border-width and divider utilities come from _borders_outlines.scss; the maps $bordersizes and $dividersizes are defined in _variables_layout.scss. Classes: .border-none, .border … .border-12, per side (.border-t*, .border-r*, …), .border-h*, .border-v*, and .divider-h*, .divider-v* for lines between children.
