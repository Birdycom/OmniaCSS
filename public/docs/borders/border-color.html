    Border-color

    CSS class _borders_outlines.scss border-color.html 0 KB JavaScriptBaselinev0.2.0

    Border color sets the colour of the border. Use .border-transparent for an invisible border that still reserves space, or .border-current to match the element’s text color. The full Omnia and HTML palette is available as .border-{name}-{step} (e.g. .border-dodgerblue-50); RAL colors as .border-{name}. See Colors for the full palette. Neutrals from $bordercolors; palette classes are generated in _borders_outlines.scss.

    What it does: border-color sets the color of the border; the border only shows when it has a style and a width (use .border-solid plus a width class). Per side variants exist in the Sides & Images page. When to use: cards, inputs, dividers, state colors (error, success). Gotchas: without a style the border is invisible even with a color; the default color is currentcolor, so a border inherits the text color; and transparent borders still take space (handy to avoid layout shift between states). The -mix-* classes blend the palette color with transparency. See MDN: border-color.

    CSS classes

    All classes set border-color. Neutrals: .border-transparent, .border-current. Palette: .border-{name}-{step} (Omnia/HTML) and .border-{name} (RAL). Same naming as on the Colors page.

    ClassCSS
    .border-transparentborder-color: transparent
    .border-currentborder-color: currentColor
    .border-{name}-{step}border-color: var(--color-{name}-{step}), e.g. .border-red-50, .border-teal-70
    .border-{name}-mix-{n}border-color: the palette color mixed with transparent ({n}% color), e.g. .border-royalblue-mix-40
    .border-ral{number}border-color: var(--color-ral{number}), e.g. .border-ral9023

    Palette colors

    Any palette color works as .border-{name}-{step}. Eight of them on the same 6px border; the text inside stays in the normal text color. Steps around 50 for bright hues and 80 for light ones (orange, goldenrod, magenta) stay visible on both a light and a dark background.

    currentcolor and transparent

    .border-current takes the text color, so one color class sets the text and the border together, and a dark: text color switches both. .border-transparent keeps the space of a border without showing it: the plan cards below all have a 2px border, so picking one only changes its color and nothing moves. Click a plan or use the arrow keys.

    See-through borders: -mix-

    .border-{name}-mix-{n} mixes the color with transparency: -mix-100 is the full color, -mix-10 is 10% of it. The background shows through, so a mixed border is softer on any background. Same 6px border, six steps; the lowest steps are meant to be faint.

    Modern color: light-dark() and color-mix()

    Border colors take any CSS color. light-dark(a, b) picks one value per color scheme, so one line serves both themes: switch the site theme and the first box changes from a dark to a light purple. color-mix() blends a palette color with the text color, so it turns a bit darker on light pages and a bit lighter on dark pages, and relative color syntax (oklch(from …)) changes one channel, here the alpha.

    light-dark(), color-mix(), oklch(from …)

    light-dark(purple-60, purple-20)
    Dark in light mode, light in dark mode.
    light-dark()dark in light mode, light in dark mode
    color-mix(… 65%, foreground)
    Orange mixed with the text color.
    color-mix()orange mixed with the text color
    oklch(from … l c h / 0.6)
    Same green at 60% alpha.
    oklch(from …)same green at 60% alpha

    The border-color utilities come from _borders_outlines.scss; the $bordercolors map and the palette (Omnia, HTML, RAL) are generated there. Classes: .border-transparent, .border-current, and .border-{name}-{step} / .border-{name}-mix-{step}. See Colors for the full palette.
