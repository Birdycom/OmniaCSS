    Outline-style

    CSS class _borders_outlines.scss outline-style.html 0 KB JavaScriptBaselinev0.2.0

    Outline style sets how the outline is drawn: solid, dashed, dotted, double, or 3D-like options. Use .outline-none for no outline, or .outline-hidden for an invisible outline that keeps focus behaviour (2px solid transparent). Combine with outline width and color. Values from $outlinestyles in _variables_layout.scss.

    What it does: outline-style chooses the line pattern of an outline (same keywords as border-style, but hidden is not valid). When to use: solid for focus rings, dashed for drop targets. Gotchas: the default style is none; .outline-hidden in OmniaCSS is a transparent 2px outline so that it stays visible in Windows forced-colors (high contrast) mode, unlike outline: none; outline styles other than solid may render slightly differently across browsers. See MDN: outline-style.

    CSS classes

    All classes set outline-style. Use .outline-solid, .outline-dashed, .outline-dotted, etc. Pair with an outline width (e.g. .outline-2) and a color. .outline-hidden uses a transparent outline for accessibility.

    ClassCSS
    .outline-noneoutline-style: none (and outline-width: 0)
    .outline-hiddenoutline: 2px solid transparent; outline-offset: 2px (visible in forced-colors mode)

    Every style on the same outline

    An outline is drawn outside the border and takes no space. Each box has the same 8px outline (.outline-4), a 4px gap (.outline-offset-2) and the same color; only the style class changes. Outlines use the same styles as borders, except hidden.

    .outline-none removes the outline, so there is nothing to show; .outline-hidden does the same for outlines. Never remove the focus outline without a replacement: see Focus Ring.

    Outline vs border: no layout shift

    Hover the first tile in each box, or Tab to it. Left: .hover:border-8 adds a 16px border; the tile has no fixed width, so it grows by 32px and its neighbours jump to the right. Right: .hover:outline-8 draws a 16px outline around the tile and nothing moves. That is why focus rings and hover frames use outlines.

    outline-none vs outline-hidden

    Both hide the outline, but not in the same way. .outline-none removes it completely. .outline-hidden draws a 2px transparent outline: invisible on a normal screen, but Windows high-contrast mode (forced colors) paints it in a system color, so a custom focus style still has a visible fallback there. Use .outline-hidden when you replace the focus ring with something else, such as a shadow. Both look the same here, so there is no preview; see the focus ring page for what a good ring looks like.

    Source & Further Reading

    The outline-style utilities come from _borders_outlines.scss; the map $outlinestyles is defined in _variables_layout.scss. Classes: .outline-none, .outline-hidden, .outline-dotted, .outline-dashed, .outline-solid, .outline-double, and the 3D variants. Combine with outline-width and outline-color.
