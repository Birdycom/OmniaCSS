    Scroll Snap

    CSS class _interactivity.scss scroll-snap/index.html 0 KB JavaScriptNewest CSSv0.8.2

    Scroll snapping makes a scroll container stop on its items: carousels, full-screen sections and pickers, without JavaScript. Put .snap-x or .snap-y on the container and .snap-start/.snap-center on the items. Modern CSS adds generated controls (.scroll-markers-after for dots, .scroll-buttons for arrows) and lets you style the snapped item with the snapped: variant. Basics are also on Scrolling & touch. See MDN: CSS scroll snap.

    Classes

    ClassCSS
    .snap-x / .snap-y / .snap-bothscroll-snap-type: x | y | both mandatory
    .snap-proximity / .snap-nonescroll-snap-type: both proximity | none
    .snap-start / .snap-center / .snap-end / .snap-align-nonescroll-snap-align
    .snap-always / .snap-normalscroll-snap-stop: always | normal (never skip an item)
    .scroll-p-{n}, .scroll-m-{n} (+ block/inline sides)scroll-padding / scroll-margin (sticky headers, peeking)
    .scroll-markers-before / .scroll-markers-afterscroll-marker-group + styled ::scroll-marker dots
    .scroll-buttons::scroll-button(inline-start / inline-end) arrows, positioned with anchor positioning
    .container-scroll-state + snapped:, snapped-x:, snapped-y:@container scroll-state(snapped: x)
    .scroll-smooth, .overscroll-containscroll-behavior, overscroll-behavior
