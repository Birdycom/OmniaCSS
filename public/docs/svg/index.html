    SVG

    CSS class _svg.scss svg/index.html 0 KB JavaScriptBaselinev0.3.0

    Style inline SVG with utilities: fill and stroke color, opacity and rules, dash patterns, line caps and joins, paint-order, non-scaling strokes, SVG text alignment and marker/stop/filter colors. See MDN: Fill and stroke.

    Fill & stroke

    fill paints the inside of a shape, stroke its outline. Use .fill-current / .stroke-current so icons follow the text color of the parent: one class and the icon adapts to light, dark and hover states. .stroke-n sets the stroke width in user units (it scales with the viewBox), .fill-rule-evenodd punches holes where a path overlaps itself, and the opacity classes make the paint translucent. Gotcha: an SVG without a fill is black, and fill-none is needed for line icons. See MDN: fill and MDN: stroke.

    ClassCSS
    .fill-{none|current|black|white|blue-500|red-500|green-500}fill
    .stroke-{none|current|black|white|blue-500|red-500|green-500}stroke
    .stroke-{0|1|2|3|4|8}stroke-width
    .fill-rule-{nonzero|evenodd} / .clip-rule-*fill-rule / clip-rule
    .fill-opacity-{0|50|100} / .stroke-opacity-*fill-opacity / stroke-opacity

    Dashes, caps & joins

    stroke-dasharray turns a solid stroke into dashes (lengths are in user units), stroke-dashoffset shifts the pattern, which animates nicely for line-drawing effects. Caps shape the ends of open lines and dashes: butt ends exactly at the point, round and square extend by half the stroke width (the thin guides mark the true end points). Joins shape the corners of paths; with miter a sharp angle is converted to a bevel once it exceeds stroke-miterlimit. See MDN: stroke-dasharray and MDN: stroke-linejoin.

    ClassCSS
    .stroke-dash-{none|2|4|8|dot}stroke-dasharray
    .stroke-dashoffset-{0|4|8}stroke-dashoffset
    .stroke-cap-{butt|round|square}stroke-linecap
    .stroke-join-{miter|round|bevel}stroke-linejoin
    .stroke-miterlimit-{4|10}stroke-miterlimit

    Paint order, vector effect & rendering

    paint-order sets the order in which fill, stroke and markers are drawn. The default paints the stroke on top and eats into thin letters; .paint-order-stroke draws the stroke first so only the outside half remains visible (clean outlined text, also available for HTML text through -webkit-text-stroke combos). .vector-effect-non-scaling keeps the stroke width in screen pixels when the SVG is scaled, which keeps chart gridlines hairline thin. shape-rendering trades anti-aliasing for crisp edges. See MDN: paint-order and MDN: vector-effect.

    ClassCSS
    .paint-order-{normal|stroke}paint-order
    .vector-effect-{none|non-scaling}vector-effect
    .shape-rendering-{auto|crisp|geometric}shape-rendering
    .color-interpolation-{srgb|linear}color-interpolation
    .color-interpolation-filters-{srgb|linear}color-interpolation-filters

    SVG text, markers & stops

    SVG text is positioned by an x/y anchor point. text-anchor says which side of the text sits on x (start, middle, end); dominant-baseline says which baseline sits on y, so .dominant-baseline-central + .text-anchor-middle centres a label on a point. baseline-shift raises or lowers a span (sub/superscripts). Gotcha: Safari treats alignment-baseline differently on <text>, prefer dominant-baseline for the whole element. See MDN: text-anchor and MDN: dominant-baseline.

    ClassCSS
    .text-anchor-{start|middle|end}text-anchor
    .dominant-baseline-{auto|middle|central|hanging}dominant-baseline
    .alignment-baseline-{middle|central}alignment-baseline
    .baseline-shift-{sub|super}baseline-shift
    .baseline-source-{first|last}baseline-source
    .marker-none / .marker-{start|mid|end}-nonemarker
    .stop-color-current / .stop-opacity-{0|100}stop-color / stop-opacity
    .flood-color-current / .flood-opacity-50 / .lighting-color-currentflood-color / flood-opacity / lighting-color
