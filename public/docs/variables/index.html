    Variables (Custom Properties)

    CSS feature _colors_tokens.scss variables/index.html 0 KB JavaScriptBaselinev0.8.2

    Custom properties (--name: value, read with var(--name, fallback)) inherit through the DOM, can be changed per element, per state or per media query, and are live: change one and everything that uses it updates. All OmniaCSS colors are variables (--color-{name}-{step}), the theme is built on --oc-* tokens, and several utilities read a variable you can override (--oc-stagger, --oc-fan). See MDN: Using CSS custom properties.

    OmniaCSS variables

    VariableMeaning
    --color-{name}-{2…95|100}Omnia, HTML palette tone (OKLCH); -100 is the base color
    --color-{name}-mix-{0…100}The color mixed with transparent (alpha steps)
    --color-ral{nnnn}RAL Classic colors
    --oc-foreground, --oc-background, --oc-card, --oc-muted, --oc-border, --oc-primary …Theme tokens: light-dark() of Omnia colors
    --oc-staggerStep for .delay-stagger (default 60ms)
    --oc-fanAngle for .fan (default 6deg)

    Scope, inheritance and fallback

    A variable set on an element applies to that element and all its descendants. var(--x, fallback) uses the fallback when --x is not set. The same card component below gets three looks from one inline variable.

    Theming with :has() and one variable

    The radio buttons set --va-brand on the whole panel through :has(). The background, button and bar all derive from it with color-mix(). No JavaScript.

.va-theme:has(input[value="magenta"]:checked) { --va-brand: var(--color-magenta-50); }

.va-bar { background: linear-gradient(90deg, var(--va-brand),
                      color-mix(in oklch, var(--va-brand), var(--oc-card) 60%)); }

    @property: typed variables you can animate

    An unregistered variable is just text and jumps from value to value. Register it with @property and the browser can interpolate it: an integer becomes a counter, a color becomes a gradient you can transition.

    @property --va-num { syntax: "<integer>"; inherits: false; initial-value: 0; }
.va-counter { counter-reset: va var(--va-num); transition: --va-num 2s ease-out; }
.va-counter::after { content: counter(va) "+"; }
.va-count-wrap:hover .va-counter { --va-num: 2500; }

@property --va-from { syntax: "<color>"; inherits: false; initial-value: transparent; }
.va-grad { --va-from: var(--color-blue-50);
           background: linear-gradient(135deg, var(--va-from), var(--color-magenta-50));
           transition: --va-from 0.6s; }
.va-grad:hover { --va-from: var(--color-orange-50); }

    Variables in OmniaCSS utilities

    Utilities that read a variable can be tuned without new classes: set it inline, on a parent, or in a state.

<div class="fan" style="--oc-fan: 12deg"></div>
<div style="--status: danger"> … </div>   <!-- read by @container style(--status: danger) -->

    Advanced: the space toggle

    A variable set to a single space is valid but empty; set to initial it is "guaranteed invalid", so var() falls back. That makes an on/off switch inside a single value.

    --va-on: ; (on) versus --va-on: initial (off)

    --va-on: ␠ (on) --va-on: initial (off) 
    1
2
    .va-toggle        { --va-on: ; background: var(--va-on) var(--color-green-60); }
.va-toggle.is-off { --va-on: initial; }   /* var() invalid → background falls back to its initial value */
