    Writing Modes & Logical Properties

    CSS class _writing_modes.scss writing-modes/index.html 0 KB JavaScriptBaselinev0.3.0

    Control the direction in which text flows (writing-mode, direction) and use logical inset and sizing utilities that follow that flow. In a right-to-left page .start-0 sticks to the right edge automatically. See MDN: Logical properties.

    Writing mode

    Horizontal or vertical text flow. The older .writingmode-* classes from _text.scss stay available. What: writing-mode sets the direction in which lines are laid out and in which blocks stack; everything that is "logical" (inline-size, margin-inline, inset-inline-start) follows it. When: vertical labels in tables and charts, East Asian typography, sideways rotated headings without transform. Gotcha: sideways-* is newer than vertical-*, and a vertical box needs an explicit block size to avoid collapsing. More: MDN: writing-mode.

    ClassCSS
    .write-horizontalwriting-mode: horizontal-tb
    .write-vertical-rlwriting-mode: vertical-rl
    .write-vertical-lrwriting-mode: vertical-lr
    .write-sideways-rlwriting-mode: sideways-rl
    .write-sideways-lrwriting-mode: sideways-lr

    Direction

    Base direction for text and inline layout. Prefer the HTML dir attribute for real content; use these classes for isolated components. Gotcha: the direction property alone does not change the document language; the dir attribute does both and is also read by assistive technology and bidi algorithms. More: MDN: direction.

    ClassCSS
    .dir-ltrdirection: ltr
    .dir-rtldirection: rtl

    Text orientation

    Orientation of characters in a vertical writing mode. When: mixed keeps Latin text sideways while CJK stays upright; upright stacks Latin letters upright, useful for short codes and abbreviations. More: MDN: text-orientation.

    Unicode bidi

    Fine-grained control over bidirectional text, e.g. user-generated names inside a sentence in another direction. Gotcha: isolate is the safe default for user-generated content: it prevents a right-to-left name from reordering the punctuation around it. More: MDN: unicode-bidi.

    ClassCSS
    .bidi-normalunicode-bidi: normal
    .bidi-embedunicode-bidi: embed
    .bidi-isolateunicode-bidi: isolate
    .bidi-overrideunicode-bidi: bidi-override
    .bidi-isolate-overrideunicode-bidi: isolate-override
    .bidi-plaintextunicode-bidi: plaintext

    Logical inset

    Position utilities that follow the writing direction. Values: auto, 0, 1 (0.25rem), 2 (0.5rem), 4 (1rem), 8 (2rem), full (100%). When: any component that must work in left-to-right and right-to-left layouts (badges, close buttons, drawers): inset-inline-start flips automatically where left would not. More: MDN: inset-inline-start.

    ClassCSS
    .start-{n}inset-inline-start: {value}
    .end-{n}inset-inline-end: {value}
    .inset-inline-{n}inset-inline: {value}
    .inset-block-{n}inset-block: {value}

    Logical sizing

    inline-size is the width in horizontal text and the height in vertical text; block-size is the other axis. Gotcha: mixing physical (width) and logical (block-size) sizes in one component works, but switch the whole component to logical values if you plan to support vertical text. More: MDN: inline-size.

    ClassCSS
    .inline-size-autoinline-size: auto
    .inline-size-fullinline-size: 100%

    Source & Further Reading

    Writing-mode, direction, bidi and logical inset/sizing utilities come from _writing_modes.scss. Logical margin and padding are generated in _spacing_margin.scss and _spacing_padding.scss. See MDN: writing-mode.
