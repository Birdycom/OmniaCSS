    CSS Functions

    CSS class _css_functions.scss functions/index.html 0 KB JavaScriptNewest CSSv0.8.2

    CSS can calculate. From calc() via clamp() to progress(), stepped values (round(), mod()), exponents and trigonometry, tree counting (sibling-index(), sibling-count()), typed attr(), inline conditions with if(), calc-size() and random(). OmniaCSS ships utilities on top of them (.delay-stagger, .fan, .text-fluid-*), and you can use every function in your own CSS next to the tokens. Color functions are on Color functions. See MDN: CSS functions.

    Function families

    FunctionsWhat they do
    calc()Mix units: calc(100% - 2rem)
    min(), max(), clamp()Smallest, largest, or a value between a minimum and maximum — see Fluid values
    progress()Where a value sits between two others, as a number 0…1
    round(), mod(), rem()Snap to a step, remainder (sign of divisor / of dividend)
    abs(), sign()Absolute value, -1 / 0 / 1
    pow(), sqrt(), hypot(), log(), exp()Exponential functions (type scales, diagonals)
    sin(), cos(), tan(), asin(), acos(), atan(), atan2()Trigonometry (circular layouts, waves)
    sibling-index(), sibling-count()Position of an element among its siblings, and their number
    attr()Read an HTML attribute, now typed: attr(data-x type(<length>))
    if()Inline condition on style(), media() or supports()
    calc-size()Calculate with auto, fit-content … (animate to auto)
    random()A random value per element
    env(), var(), counter(), url(), image-set()Environment, variables, counters, images

    From clamp() to progress()

    clamp(min, value, max) limits a value. progress(value, start, end) goes one step further: it tells you how far a value is between two points, as a number from 0 to 1. Use that number for anything: width, opacity, a color mix, a counter. Below, the container width (100cqi) between 12rem and 36rem drives the bar, its color and the percentage text. Drag the corner to resize.

.fn-progress {
  --p: 0.5;                                                    /* fallback */
  --p: clamp(0, progress(100cqi, 12rem, 36rem), 1);           /* 0 … 1 */
  inline-size: calc(var(--p) * 100%);
  background: color-mix(in oklch, var(--color-blue-50), var(--color-magenta-50) calc(var(--p) * 100%));
  counter-reset: fnp calc(var(--p) * 100);                     /* integer context rounds */
}
.fn-progress::after { content: counter(fnp) "%"; }

/* The same idea for fluid type, without the "preferred value" math of clamp() */
h1 { font-size: calc(1.5rem + progress(100vw, 20rem, 80rem) * 2rem); }

    Stepped values: round(), mod(), rem()

    round(strategy, value, step) snaps to a multiple of step (nearest, up, down, to-zero). The bar below only grows in whole 3rem steps, whatever the container width.

    Exponential: pow(), sqrt(), hypot(), log(), exp()

    Trigonometry + tree counting: a circle without JavaScript

    Each dot computes its own angle from sibling-index() and sibling-count(), then its position with cos() and sin(). Add or remove dots and the circle redistributes itself; the color mixes between two Omnia tokens along the way.

    if(): conditions inside a value

    if() picks a value based on style(), media() or supports(), without a separate rule. Write a plain value first for browsers without if().

  background: if(
    style(--fn-state: done): var(--color-green-60);
    style(--fn-state: busy): var(--color-orange-60);

}
.card { padding: if(media(width >= 40rem): 2rem; else: 1rem); }
.grid { display: if(supports(display: grid-lanes): grid-lanes; else: grid); }

    calc-size() and interpolate-size: animate to auto

    interpolate-size: allow-keywords (utility .interpolate-size-keywords) lets height: auto animate. calc-size(auto, size + 1rem) calculates with intrinsic sizes. Open the accordion: no JavaScript, no max-height trick.

    details + ::details-content + interpolate-size

    How does this open smoothly?

    The ::details-content pseudo-element animates its block-size from 0 to auto, because the parent allows keyword interpolation. content-visibility switches with allow-discrete at the end.

  overflow: clip;
  transition: block-size 0.35s, content-visibility 0.35s allow-discrete;
}
.fn-acc[open]::details-content { block-size: auto; }

/* Only for one property: */
.panel { block-size: calc-size(auto, size + 2rem); }

    random(): a different value per element

    Every piece of confetti gets its own position and angle. Browsers without random() keep the line above it: a pseudo-random spread from sin() of the sibling index.

  translate: calc(sin(sibling-index() * 57deg) * 9rem) calc(cos(sibling-index() * 91deg) * 3.5rem);

    Browser support

    calc(), min(), max(), clamp(), the stepped, exponential and trigonometric functions work in every current browser. progress(), sibling-index() and typed attr() are new; if(), calc-size() and random() are not everywhere yet — every demo here writes a fallback first.
