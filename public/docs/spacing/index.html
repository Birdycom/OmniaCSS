    Spacing

    0 KB JavaScriptBaselinev0.2.0

    Core utilities for controlling the inner and outer space of elements.

    The Spacing module provides a consistent scale for padding and margin, allowing you to control document hierarchy and element breathing room.

    The pages of this section, each with a small live example. Click a title to open the page. Gap, the space between the items of a flex or grid container, has its own page under Flex & Grid.

    Padding and margin on one element

    The blue box is the content. The green band around it is its padding (inside the border). The orange band outside the border is its margin. Both use the same scale, so p-2 and m-2 are both 2rem.

    The spacing scale

    Padding, margin and gap share one rem scale: the number is the size in rem, so p-1, m-1 and gap-1 are all 1rem (16px). Each bar below is exactly as long as its value.

    Watch out with the decimals: the digit after the dot is a short name for a quarter or eighth step, not a decimal. 0.2 is 0.25rem, 0.7 is 0.75rem, 1.2 is 1.25rem and 1.7 is 1.75rem. Only .5 means a half.

    Spacing scale: class suffix, value and real length

    Use the suffix after any spacing class:p-pt-ph-m-mt-mh-gap-
    p-* · m-* · gap-*
    Each bar is an empty element with only pl-*, so its length is exactly the value.
