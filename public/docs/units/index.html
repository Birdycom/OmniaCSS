    CSS Units

    CSS class _sizing_logical.scss units/index.html 0 KB JavaScriptBaselinev0.8.2

    Lengths can be absolute (px, cm), relative to the font (em, rem, ch, cap, ic, lh, rlh), to the viewport (vw, svh, lvh, dvh) or to a container (cqi, cqb). OmniaCSS uses rem for its scale (.size-4 = 1rem) and has dedicated utilities for line-height and viewport units. See MDN: Values and units.

    All length units

    UnitRelative to
    px, cm, mm, Q, in, pt, pcAbsolute (1in = 96px = 2.54cm)
    em / remFont size of the element / of the root
    lh / rlhLine height of the element / of the root
    ch / rchWidth of the "0" glyph (element / root)
    ex / rexx-height
    cap / rcapHeight of capital letters
    ic / ricWidth of the CJK water ideograph "水" (full-width character)
    vw, vh, vi, vb, vmin, vmax1% of the viewport (inline/block = writing-mode aware)
    svh / lvh / dvh (and sv*, lv*, dv*)Small (browser bars shown), large (bars hidden), dynamic (follows the bars)
    cqw, cqh, cqi, cqb, cqmin, cqmax1% of the nearest size container
    %, frParent size, free space in a grid
    deg, rad, grad, turn · s, ms · dpi, dppx, xAngles · time · resolution

    rem, em and %: what does the width follow?

    Three boxes with a different font size, each with the same three bars: width: 8rem, width: 8em and width: 50%. The grid lines in the track are 2rem apart. The rem bar never changes (8 × the root font size, 16px). The em bar grows with the font size of its box. The % bar is always half of the track.

    The lh unit: size things in lines of text

    1lh is the computed line height of the element. An icon of 1lh always lines up with the first line, a box of 3lh shows exactly three lines, and a background of 1lh stripes follows the text, whatever the font size.

    ClassCSS
    .size-lh, .w-lh, .h-lhwidth/height: 1lh
    .h-{2|3|4|5|6|8|10}lhheight: {n}lh
    .min-h-{n}lh, .max-h-{n}lhmin-height / max-height: {n}lh
    .block-size-{n}lhblock-size: {n}lh
    .size-rlh, .h-rlh, .max-h-rlh …Same with rlh (root line height)

    The same check icon and sentence at two font sizes. The icon has .size-lh, so it is one line high in both and stays level with the first line when the text wraps.

    cap, ch and ic

    1cap matches the height of capital letters (icons next to headings), ch counts characters (a readable line length of 45–75ch), ic does the same for CJK text.

    First: a 1cap square in front of headings of three sizes. It always has exactly the height of the capital letters. Then: two paragraphs with a ruler above them, one limited to 30ch and one to 45ch (about 30 and 45 characters per line).

    A 1cap square next to capitals, and ch measures

    inline-size: 1cap; block-size: 1cap
    The magenta square is exactly as high as the capital letters, at every font size.

    Viewport units: svh, lvh and dvh

    On mobile the browser bars come and go. 100svh fits with the bars shown, 100lvh with them hidden, 100dvh follows them live (and may cause layout shifts while scrolling). Pick svh for hero sections that must fit, dvh for full-screen apps.

    ClassCSS
    .h-screen / .h-svh / .h-lvh / .h-dvhheight: 100vh / 100svh / 100lvh / 100dvh
    .min-h-svh, .min-h-lvh, .min-h-dvhmin-height
    .max-h-svh, .max-h-lvh, .max-h-dvhmax-height
    .w-svw, .w-lvw, .w-dvw, .min-w-dvw, .max-w-dvwwidth
    .h-screen-safeheight: calc(100dvh - env(safe-area-inset-top) - env(safe-area-inset-bottom))

    Three sketches of a phone. The dark bands are the browser bars (address bar on top, toolbar below); the teal block is an element with a height of 100 of each unit. Watch the right phone: dvh grows and shrinks as the bars slide away and come back.

    What 100svh, 100lvh and 100dvh cover (dark bands = browser bars)

    .h-svh
    Fits between the bars. Never hidden behind them.
    100svh
    .h-lvh
    As tall as the screen without bars. Partly hidden while they show.
    100lvh
    .h-dvh

    Container units: cqi and cqb

    Inside a size container (.cq-inline), 1cqi is 1% of its inline size. Type scales with the card, not with the screen. Drag the corner.

    font-size: clamp(1rem, 7cqi, 2.75rem) (drag the corner)

    .cq-inline + font-size: clamp(1rem, 7cqi, 2.75rem)
    Drag the bottom-right corner of the dashed box: the heading and the text follow the width of the box, not the screen.

    Spring sale at Company 1

    The heading and this text follow the width of this box, not the width of the screen. Make the box narrow and the heading shrinks, down to 1rem.
