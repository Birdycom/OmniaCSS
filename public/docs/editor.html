    Editor extension

    OmniaCSS IntelliSense for VS Code and Cursor: autocomplete for every utility, variant and OmniaUI class, the generated CSS on hover, color swatches and linting with quick fixes.

    Install for VS Code Install for Cursor (Open VSX)

    Install Birdycom.omniacss-intellisense

    Free, MIT licensed, same version number as @birdycom/omniacss. Updates arrive automatically.

    • VS Code: VS Code Marketplace, or search for OmniaCSS IntelliSense in the Extensions view (Ctrl Shift X).
    • Cursor, VSCodium, Windsurf: Open VSX, the same search in the Extensions view.
    • Theme: the extension pairs with Birdycom Omnia Dark, Birdycom's dark theme for HTML, Blade, PHP and CSS (optional).
    • From a file: build the .vsix from the source and install it with Extensions: Install from VSIX…
    1
2
    code --install-extension Birdycom.omniacss-intellisense     # VS Code
cursor --install-extension Birdycom.omniacss-intellisense   # Cursor

    Nothing is needed in your project: no config file and no install. The extension ships the full OmniaCSS index and works in HTML, Blade, PHP, Vue, Svelte, Astro, JSX/TSX, Markdown, Twig and CSS files.

    Utilities, colors and hover

    Suggestions for every utility and variant (hover:, dark:, cq-md:, group-hover/card:, data-[state=open]: …). Color classes show their swatch, also for the RAL colors and their mix steps (bg-ral3020-mix-20), and the details panel shows the CSS the class generates.

    Inside var( you get every Omnia token with its OKLCH value; the color picker snaps a class or token to the nearest Omnia color.

    Hover a class to see its CSS exactly as the build writes it, variants included; rem values get a px comment.

    OmniaUI components and blocks

    Component classes from OmniaUI are in the same list: oc-btn, oc-card, oc-tooltip__title, oc-block-….

    • Without anything installed you get the free OmniaUI classes of the version the extension was built with (handy with the CDN links or @omniacss in Laravel).
    • When @birdycom/omniaui, @birdycom/omniaui-blocks or @birdycom/omniaui-pro is in your project's node_modules, the classes and CSS of that installed version are used. After npm install or an upgrade the list follows within a few seconds.
    • OmniaUI Pro classes appear only in projects that have Pro installed.

    Recommended settings

    Suggestions inside strings (class attributes) need editor.quickSuggestions; otherwise press Ctrl Space.

    1
2
3
4
5
6
    // .vscode/settings.json
{
  "editor.quickSuggestions": { "strings": "on" },
  "omniacss.classFunctions": ["clsx", "cn", "cx", "cva", "classNames", "classnames", "@class", "myClasses"],
  "omniacss.lint.unknownClass": "ignore"
}
    • omniacss.classAttributes and omniacss.classFunctions: where classes are read (class, className, :class, @class, clsx(), cn() … by default; add your own helpers to the list).
    • omniacss.lint.*: unknown variants and utilities are warnings; plain unknown classes are off by default because projects have their own classes.
    • omniacss.rootFontSize and omniacss.showPixelEquivalents: the px comments in hovers.
    • Run OmniaCSS: Show Output to see which index and OmniaUI version are loaded.
