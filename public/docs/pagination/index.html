    Pagination

    CSS class variants.mjs pagination/index.html 0 KB JavaScriptNewest CSSv0.8.2

    Pagination splits content over pages. For the links, mark the current page with aria-current="page" and style it with the aria-[current=page]: variant, so the visual state and the accessible state can never disagree. Newer CSS can even generate the page buttons (::scroll-marker), and @page paginates printed documents. See MDN: aria-current.

    Markup and classes

    Use a <nav aria-label="Pagination"> with a list of links. The current page gets aria-current="page", unavailable links aria-disabled="true" (and no href).

    ClassRole
    aria-[current=page]:bg-vividblue-80 aria-[current=page]:text-white-50Active page
    hover:bg-mistblue-20 transition-colors duration-200Hover with a transition
    focus-visible:outline-solid focus-visible:outline-2 focus-visible:outline-vividblue-80Keyboard focus ring
    aria-disabled:opacity-40 aria-disabled:pointer-events-noneDisabled previous/next
    round-2, round-full, border-1 border-solid border-mistblue-30Rounded, pill and bordered styles

    Breadcrumbs

    The separators are generated with ::after, so screen readers only read the links; the last item is the current page.

    Breadcrumb with ::after separators

    2. Selectors
    3. Pagination

2
    .crumbs li:not(:last-child)::after { content: "/"; margin-inline: 0.6rem; }
/* <nav aria-label="Breadcrumb"><ol class="crumbs flex list-none"> … <li><span aria-current="page">Pagination</span></li></ol></nav> */

    Page buttons generated by CSS: ::scroll-marker

    Put the pages in a horizontal snap container and let CSS create one marker per page. content: attr(data-page) turns the markers into numbered buttons, :target-current highlights the visible page. The browser handles clicks, keyboard arrows and the accessible tab roles — no JavaScript.

    scroll-marker-group: after + ::scroll-marker { content: attr(data-page) }

    Click the numbers below: they are ::scroll-marker pseudo-elements.

    Print pagination: @page and page breaks

    For printed pages, @page margin boxes add page numbers and .break-* utilities decide where a new page starts. Use the print: variant to hide navigation when printing.

    1
2
3
4
5
6
7
8
    @page {
  size: A4;
  margin: 2cm;
  @bottom-right { content: "Page " counter(page) " / " counter(pages); }
}
/* <h2 class="break-before-page">Chapter 2</h2>
   <figure class="break-inside-avoid">…</figure>
   <nav class="print:d-none">…</nav> */
