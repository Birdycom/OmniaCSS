    Content

    Content helpers for the pseudo-elements. .content-attr prints the value of the data-oc-content attribute. What: content fills ::before and ::after with text, an attribute value, a counter or an image. When: small decorations, labels taken from data-* attributes (tooltips without extra markup), icons from masks. Gotchas: generated text is not selectable, may be read by screen readers and cannot be translated by the page, so never put essential information there; a pseudo-element only renders when content is set (even ""). More: MDN: content.

    ClassCSS
    .content-none::before, ::after { content: none }
    .content-empty::before, ::after { content: "" }
    .content-open-quote::before { content: open-quote }
    .content-close-quote::after { content: close-quote }
    .content-attr::before { content: attr(data-oc-content) }

    content-attr

    Every badge has class="content-attr"; only its data-oc-content attribute differs
    data-oc-content="★ "
    The star in front of Featured comes from the attribute; the HTML text only says Featured.

    data-oc-content="New · "
    The word New and the dot come from the attribute, the rest is the text.
    Product 2Just added
    data-oc-content="−20% · "
    The −20% comes from the attribute; the HTML text only says Sale.

    Quotes

    Quotation marks for <q> and nested quotes (outer pair, inner pair). What: quotes defines the outer and inner pair that <q> and open-quote / close-quote use. Gotcha: the browser picks quotes from the lang attribute by default, so set lang correctly first and override only when the design demands a house style. More: MDN: quotes.

    ClassCSS
    .quotes-nonequotes: none
    .quotes-autoquotes: auto
    .quotes-englishquotes: “ ” ‘ ’
    .quotes-frenchquotes: « » ‹ ›
    .quotes-germanquotes: „ “ ‚ ‘

    quotes-english, quotes-french, quotes-german

    .quotes-english
    Curly double quotes outside, single quotes for the quote inside.
    Customer 1 said: it arrived a day early.
    .quotes-french
    Guillemets « » outside, single guillemets ‹ › inside.
    Customer 1 said: it arrived a day early.
    .quotes-german
    Low and high quotes „ “ outside, ‚ ‘ inside.
    Customer 1 said: it arrived a day early.

    Four ways to control quotation marks. The first tile puts marks around a plain div (no <q>) with the content classes. The other three use a <q> element. .content-empty has no tile: it gives ::before and ::after an empty text so you can style them as shapes, and shows nothing on its own.

    content-open-quote, content-close-quote, quotes-none, quotes-auto, content-none

    .content-open-quote .content-close-quote
    A plain div gets quotation marks, for example around a customer review.
    The bag is sturdy and it arrived a day early.
    q.quotes-none
    The q element keeps its meaning, but shows no marks.
    it arrived a day early
    q.quotes-auto + lang="fr"
    The marks follow the language of the text: French gets « ».
    it arrived a day early
    q.content-none
    The pseudo-elements that hold the marks are switched off.
    it arrived a day early
