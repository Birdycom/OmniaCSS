    Entry & Exit Animations

    CSS class _starting_style.scss starting-style/index.html Newest CSSv0.3.0

    Animate elements when they appear — popovers, dialogs, newly inserted items — and animate to height: auto, mostly without JavaScript (only the example that adds rows to the page needs a few lines). .starting-* classes set the state before the first render via @starting-style; combine them with a transition utility such as .transition-all .duration-300. See MDN: @starting-style.

    Starting style

    Initial values the element transitions from when it is first rendered or goes from display: none to visible. What: a normal CSS transition needs a "before" style, but a freshly inserted element has none. @starting-style supplies it, so the element animates to its real style on first render. When: popovers, dialogs, toasts, list items added from JavaScript, anything that appears. Gotchas: you still need a transition on the element (for example .transition-all .duration-300); these utilities animate the entry only, for the exit you also need .transition-discrete and a closed-state style (see the dialog demo). More: MDN: @starting-style.

    ClassCSS
    .starting-opacity-0@starting-style { opacity: 0 }
    .starting-scale-95@starting-style { scale: 0.95 }
    .starting-translate-y-2@starting-style { translate: 0 0.5rem }
    .starting-translate-y-n2@starting-style { translate: 0 -0.5rem }
    .starting-translate-x-full@starting-style { translate: 100% 0 }

    Three popovers, opened and closed with the popover attributes only: no script. Each one fades in with .starting-opacity-0 and moves in a different way. The extra CSS in the sample gives the closed state, so the panel also fades out.

<script>
  {
    // Adding a row to the page needs script. The row only gets classes: the CSS does the animation.
    const list = document.getElementById('ss-list');
    const button = document.getElementById('ss-add');
    button.addEventListener('click', () => {
      const n = list.children.length + 1;
      if (n > 6) { list.replaceChildren(); button.textContent = 'Add order'; return; }
      const row = document.createElement('li');
      row.className = 'ss-item starting-opacity-0 starting-translate-x-full transition-all duration-700';
      row.innerHTML = '<span>Order ' + n + ' · Customer ' + n + '</span><small>just added</small>';
      list.append(row);
      if (n === 6) button.textContent = 'Clear the list';
    });
  }
</script>

<style>
  /* overflow-x: clip hides the row while it is still to the right of the list */
  .ss-list { display: grid; gap: 0.6rem; overflow-x: clip; }
</style>

    Transition behavior

    .transition-discrete allows transitions on discrete properties like display and overlay, so exit animations can finish before the element is hidden. What: normally display: none flips instantly, which cuts every exit animation. With allow-discrete the flip is delayed until the other transitions have finished (and for the top layer, overlay keeps the element there until then). Gotcha: list display and (for popover, dialog) overlay in the transition property, because the shorthand transition: all does not animate them unless behavior is set. More: MDN: transition-behavior.

    ClassCSS
    .transition-normaltransition-behavior: normal
    .transition-discretetransition-behavior: allow-discrete

    .transition-discrete is at work in the popovers above. .transition-normal is the default and has no demo of its own: it switches the behaviour back off, and then a popover disappears at once when it closes.

    Interpolate size & details

    .interpolate-size-keywords lets height: auto (and other size keywords) be animated; it is inherited, so set it on a parent or on :root. .details-animate animates the open/close of a <details> element via ::details-content. When: accordions, expanding cards, collapsible sidebars: anything that grows to its content size. Gotchas: without the opt-in a transition to or from auto jumps. calc-size(auto, size) is the per-value alternative: it makes a single declaration animatable without the inherited property, and allows maths on the intrinsic size such as calc-size(auto, size + 2rem). More: MDN: interpolate-size, MDN: calc-size().

    ClassCSS
    .interpolate-size-numericinterpolate-size: numeric-only
    .interpolate-size-keywordsinterpolate-size: allow-keywords
    .details-animate::details-content { block-size: 0 → auto } (300ms)

    .interpolate-size-numeric is the default and has no demo of its own: set it on a part of the page to switch .interpolate-size-keywords off again there (the box then jumps open).

    interpolate-size-keywords vs calc-size(): animate height to auto (hover or focus the cards)

    Not in this browser yet. Your browser does not support interpolate-size or calc-size(): both cards still open, but they jump open without the slide.
    .interpolate-size-keywords
    Hover or focus the card: it grows smoothly to its natural height. One class on a parent opts in the whole subtree.
    interpolate-sizeHover or tap to open

    The box grows smoothly from a fixed height to height: auto. The property is inherited, so one class on a parent opts in the whole subtree. Without it the box would jump open.

    block-size: calc-size(auto, size)
    Hover or focus the card: the same effect, with calc-size() in the hover rule only and no opt-in.
    calc-size()Hover or tap to open

    Same effect with no opt-in at all: the keyword is wrapped in calc-size() in the hover rule only. You can also add to it, for example calc-size(auto, size + 2rem).
