    At-rules

    CSS feature variants.mjs at-rules/index.html 0 KB JavaScriptNewest CSSv0.8.2

    Every CSS statement that starts with @: conditional rules (@media, @container, @supports), cascade control (@layer, @scope), definitions (@property, @keyframes, @font-face, @counter-style, @function) and page/print rules (@page). OmniaCSS turns the conditional ones into variants (md:, cq-md:, supports-[…]:, starting:), so you rarely write them by hand. See MDN: At-rules.

    All at-rules and how OmniaCSS uses them

    The left column is the at-rule; the right column is the OmniaCSS way to use it, or the page that covers it.

    At-ruleOmniaCSS
    @mediaVariants sm: md: lg: xl: 2xl:, max-md:, min-[40rem]:, print:, motion-safe:, dark:, contrast-more:, pointer-coarse: — see Responsive
    @containerVariants cq-sm: … cq-7xl:, @md:, cq-[30rem]:, cq-md/name:; scroll-state variants stuck:, snapped: — see Container queries
    @supportsVariants supports-[prop:value]:, supports-[selector(:has(a))]:, not-supports-[…]: (this page)
    @starting-styleVariant starting: and .starting-* utilities — see Entry animations
    @layeromniacss build wraps the utilities in @layer omnia (this page)
    @propertyRegistered tokens for animatable gradients and counters (this page, Variables)
    @scopeWrite scoped component CSS next to the utilities (this page)
    @keyframes.animate-* presets and .animate-name-* — see Animations
    @font-face, @font-palette-values, @font-feature-values.font-* families — see Fonts
    @counter-style.list-* custom counters — see Lists & counters
    @pagePrint layout with .break-* — see Fragmentation and Pagination
    @view-transitionCross-document transitions — see View transitions
    @position-tryFallback positions — see Anchor positioning

    @import, @namespace, @charset, @custom-mediaPlain CSS (this page)

    @supports: feature queries

    Apply styles only when the browser understands a declaration, a selector (selector()), a font technology (font-tech(), font-format()) or an at-rule (at-rule()). Combine them with and, or and not. In OmniaCSS you write the condition in the class: supports-[field-sizing:content]:inline; spaces become _.

    VariantCSS
    supports-[display:grid]:…@supports (display:grid)
    supports-grid:…@supports (grid: inherit) — property name only
    supports-[selector(:has(a))]:…@supports selector(:has(a))
    supports-[font-tech(color-COLRv1)]:…@supports font-tech(color-COLRv1)
    supports-[at-rule(@scope)]:…@supports at-rule(@scope)
    not-supports-[…]:…@supports not (…)
    supports-[(a:b)_and_(c:d)]:…@supports (a:b) and (c:d)

    @layer: cascade layers

    Layers decide which rules win before specificity is compared: a later layer beats an earlier one, even when the earlier rule uses an id. omniacss build puts all utilities in @layer omnia, so you can place your own reset before it and your overrides after it. Unlayered CSS always beats layered CSS.

    The later layer wins over an id selector in an earlier layer

    #id in layer ar-base → loses
    .class in layer ar-theme → wins (green)

    @layer ar-base, ar-theme;                /* order is decided here */

@layer ar-theme {
  .ar-layer-box { background: var(--color-green-50); }
}
@layer ar-base {
  #ar-layer-target.ar-layer-box { background: var(--color-red-60); }  /* higher specificity, earlier layer */
}

/* With OmniaCSS */
@layer reset, omnia, components, overrides;
@import url("omnia.css") layer(omnia);
@import url("theme.css") layer(components) supports(display: grid);

    @property: typed, animatable variables

    A registered custom property has a type (<angle>, <color>, <length>, <integer> …), an initial value and an inheritance flag. Because the browser knows the type it can interpolate it: gradients, angles and counters become animatable. More on the Variables page.

    linear-gradient(var(--oc-card), var(--oc-card)) padding-box,

                   var(--color-orange-50), var(--color-blue-50)) border-box;
  animation: ar-angle 4s linear infinite;
}
@keyframes ar-angle { to { --ar-angle: 360deg; } }

    @scope: styles with an upper and a lower limit

    @scope (root) to (limit) styles only the elements between the scope root and the limit (a "donut"). Slots, nested widgets and user content inside the limit stay untouched, without long selectors or naming schemes.

    @scope (.ar-scope-card) to (.ar-scope-slot)

    Inside the scope: blue and bold.

    Inside the limit (.ar-scope-slot): not styled by the scope.

    1
2
3
4
5
    @scope (.ar-scope-card) to (.ar-scope-slot) {
  p { color: var(--color-vividblue-80); font-weight: 600; }
}
/* :scope refers to the root itself */
@scope (.card) { :scope { container-type: inline-size; } }

    @container style(): query a variable

    Size queries are covered on Container queries. Style queries test a custom property of the parent: set --status once and every child adapts. Every element is a style container, so no container-type is needed.

    One variable, three looks

    --status: ok
    --status: warn
    --status: danger
    1

    @container style(--status: ok)     { .ar-badge { background: var(--color-green-60); } }
@container style(--status: warn)   { .ar-badge { background: var(--color-orange-60); } }
@container style(--status: danger) { .ar-badge { background: var(--color-red-60); } }

    @function: your own CSS functions

    A custom function takes arguments and returns a result. Write the plain declaration first: browsers without @function drop the second line and keep the fallback. Drag the corner of the box to resize it.

    --ar-fluid(min, max) — fluid type from the container width

    Resize me: fluid heading

    @function --ar-fluid(--min, --max) {
  result: clamp(var(--min), 0.5rem + 4cqi, var(--max));
}
.ar-fn-text {
  font-size: 1.25rem;                     /* fallback */
  font-size: --ar-fluid(1rem, 2.75rem);   /* Chromium 139+ */
}

    @media: range syntax and custom media

    Media queries accept comparison operators. @custom-media gives a query a name; until browsers support it widely, the OmniaCSS breakpoint variants do the same job.

@custom-media --tablet (40rem <= width < 64rem);  /* Firefox only, behind a flag */
@media (--tablet) { … }
