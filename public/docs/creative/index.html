    Creative CSS

    Showcase _css_functions.scss creative/index.html 0 KB JavaScriptNewest CSSv0.8.2

    Effects people usually reach for JavaScript or images to build, made with CSS and the Omnia tokens only: animated gradient borders (@property), neon buttons, 3D flip cards, glassmorphism, text fills, typing and wave text, clip-path reveals, a scroll-driven reading bar, a theme switch with :has(), retro 3D type and loaders. Every effect respects prefers-reduced-motion. Copy the CSS next to your utilities; all colors are var(--color-*) tokens.

    Animated glowing border

    A registered --cr-angle rotates a conic gradient in the border box; a blurred copy in ::before is the glow, and ::after paints the card face over it, so only a ring and its glow remain.

.cr-glow {
  --cr-ring: conic-gradient(from var(--cr-angle), var(--color-vividblue-80), var(--color-magenta-50),
             var(--color-orange-50), var(--color-teal-50), var(--color-vividblue-80));
  position: relative; isolation: isolate;
  border: 3px solid transparent; border-radius: 18px;
  background: var(--cr-ring) border-box;                    /* the ring */
  animation: cr-spin 4s linear infinite;
}
.cr-glow::before {                                          /* the glow, painted first */
  content: ""; position: absolute; inset: -3px; z-index: -1; border-radius: inherit;
  background: var(--cr-ring); filter: blur(1.5rem); opacity: 0.75;
}
.cr-glow::after {                                           /* the card face, painted over the glow */
  content: ""; position: absolute; inset: 0; z-index: -1; border-radius: 15px;
  background: var(--color-black-30);
}
@keyframes cr-spin { to { --cr-angle: 360deg; } }

    Scroll-driven reading progress

    The bar is driven by animation-timeline: scroll(), not by time. Scroll the text box. More on Scroll animations.

    animation-timeline: scroll(nearest block)

    Scroll this box. The bar at the top grows from 0 to 100% while you read.

    It is a normal @keyframes animation, but its progress comes from the scroll position of the nearest scroll container instead of a clock.

    On a real page use scroll(root) on a fixed bar at the top of the viewport.

    Browsers without scroll-driven animations simply do not show the bar.

    No scroll listeners, no requestAnimationFrame, and it runs off the main thread.

    End of the article.

    .cr-read-bar {
  position: sticky; top: 0; block-size: 5px; transform-origin: left; scale: 0 1;
  background: linear-gradient(90deg, var(--color-vividblue-80), var(--color-magenta-50));
  animation: cr-grow linear both;
  animation-timeline: scroll(nearest block);   /* page: scroll(root) */
}
@keyframes cr-grow { to { scale: 1 1; } }

    Loaders

    A conic gradient masked into a ring, and pulsing dots whose delay comes from sibling-index().

    .cr-loader {
  inline-size: 4.5rem; aspect-ratio: 1; border-radius: 50%;
  background: conic-gradient(from 0deg, transparent 10%, var(--color-skycyan-50));
  mask: radial-gradient(farthest-side, transparent calc(100% - 0.5rem), var(--color-black-50) calc(100% - 0.45rem));
  animation: cr-rot 1s linear infinite;
}
.cr-dots i { animation: cr-pulse 1s ease-in-out infinite;
             animation-delay: calc((sibling-index() - 1) * 150ms); }   /* = .animate-delay-stagger .stagger-150 */
@keyframes cr-rot { to { rotate: 1turn; } }
@keyframes cr-pulse { 0%, 100% { scale: 0.5; opacity: 0.4; } 50% { scale: 1.1; opacity: 1; } }
