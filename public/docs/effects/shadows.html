    Elevation effects using .shadow-{size}, tinted with .shadow-{color} or any --oc-shadow-color.

    Classbox-shadow (light scheme; the dark scheme uses a much stronger alpha)
    .shadow-nonenone
    .shadow-sm0 1px 2px 0 / 0.08
    .shadow0 1px 3px 0 / 0.12, 0 1px 2px -1px
    .shadow-md0 4px 6px -1px / 0.15, 0 2px 4px -2px
    .shadow-lg0 10px 15px -3px / 0.18, 0 4px 6px -4px
    .shadow-xl0 20px 25px -5px / 0.22, 0 8px 10px -6px
    .shadow-2xl0 25px 50px -12px / 0.35
    .shadow-innerinset 0 2px 4px 0 / 0.12

    The scale side by side

    The shadow utilities are light-dark() aware: in a dark color scheme the shadow alpha is much stronger and a faint light ring (plus a top highlight on .shadow-lg and up) lifts the edge of the surface, so elevation stays visible on dark backgrounds. This field follows the page theme: switch the theme in the header to compare.

    Colored shadows & glow

    ClassCSS
    .shadow-blue · .shadow-cyan · .shadow-purple · .shadow-green · .shadow-red · .shadow-black--oc-shadow-color: vividblue-80 / skycyan-80 / purple-20 / green-40 / red-40 / black-50. Tints every .shadow-* / .drop-shadow-* / .text-shadow-*
    .shadow-glowbox-shadow: 0 0 0 1px (shadow color / 0.35), 0 0 32px -4px (shadow color / 0.6); default color vividblue-80
    .shadow-neonbox-shadow: 0 0 0.6rem c, 0 0 2.5rem c, 0 0 5rem (c / 0.5), c = shadow color, default skycyan-50
    .border-conic-spina conic gradient turning round a transparent border (registered --oc-conic-angle, 4s per turn) and a blurred copy behind it as the glow. Variables: --oc-conic-colors, --oc-conic-width (3px), --oc-conic-blur (1.5rem), --oc-conic-opacity (0.75), --oc-conic-speed (4s), --oc-conic-fill (card color). Stops with prefers-reduced-motion
    .hover:shadow-{none,sm,md,lg,xl,glow}the shadow on :hover (combine with .transition-shadow)
    .focus-visible:shadow-{none,sm,md,lg,xl}the shadow on keyboard focus

    Every .shadow-{size} takes the color of a .shadow-{color} class, or of any palette token you put in --oc-shadow-color (the last card). Each card uses .shadow-xl so the color has room to show.

    Text shadow

    Classtext-shadow
    .text-shadow-nonenone

    .text-shadow-md0 2px 4px (shadow color / 0.4)
