    Blur Filters

    _filters.scss 0 KB JavaScriptBaselinev0.2.0

    Apply Gaussian blur effects to elements using .blur-{size}.

    What it does: filter applies graphical effects (blur, color shifts, shadows) to an element and everything inside it, after it is rendered. When to use: image treatments, disabled/hover states, quick duotone-ish looks, icon recoloring. Gotchas: each utility sets the whole filter property, so classes on one element do not stack (the last one wins); a filter creates a stacking context and a containing block for fixed descendants; heavy blurs on large areas cost GPU time. See MDN: filter.

    Blur

    blur() applies a Gaussian blur; the value is the standard deviation in pixels. Use it for placeholders, depth of field and to soften decorative backgrounds. MDN: blur()

    Backdrop Filters

    _filters.scss v0.2.0

    Glassmorphism effects using .backdrop-blur-{size} and friends.

    What it does: backdrop filters apply the same effects to whatever is painted behind the element, visible through its (semi-)transparent background: the classic frosted glass. When to use: sticky headers, modals, popovers, cards over imagery. Gotchas: the element needs a translucent background or you see nothing; parents with overflow: hidden and a radius clip the blur edge; and performance drops with large blurred areas. See MDN: backdrop-filter.

    The stripes behind the glass get progressively blurrier.
