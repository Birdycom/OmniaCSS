    Blur Filters

    _filters.scss 0 KB JavaScriptBaselinev0.2.0

    Apply Gaussian blur effects to elements using .blur-{size}.

    What it does: filter applies graphical effects (blur, color shifts, shadows) to an element and everything inside it, after it is rendered. When to use: image treatments, disabled/hover states, quick duotone-ish looks, icon recoloring. Gotchas: each utility sets the whole filter property, so classes on one element do not stack (the last one wins); a filter creates a stacking context and a containing block for fixed descendants; heavy blurs on large areas cost GPU time. OmniaCSS has no hover: variants for filters: for a hover effect add one rule of your own, as the practical examples below show. See MDN: filter.

    Every example uses the same test picture: a flat landscape above a strip of six colors and a grey ramp from white to black. The strip shows what a filter does to color, the ramp shows what it does to light and dark.

    Blur

    blur() applies a Gaussian blur; the value is the standard deviation in pixels. Use it for placeholders, depth of field and to soften decorative backgrounds. MDN: blur()

    ClassFilter value
    .blur-noneblur(0)
    .blur-smblur(4px)
    .blurblur(8px)
    .blur-mdblur(12px)
    .blur-lgblur(16px)
    .blur-xlblur(24px)

    Compare the edges of the barn and the sun: at .blur-sm they are soft, from .blur-lg the shapes melt into each other. Each picture sits in a wrapper with overflow: hidden, so the blur does not bleed past the rounded corners.

    Backdrop Filters

    _filters.scss v0.2.0

    Glassmorphism effects using .backdrop-blur-{size} and friends.

    What it does: backdrop filters apply the same effects to whatever is painted behind the element, visible through its (semi-)transparent background: the classic frosted glass. When to use: sticky headers, modals, popovers, cards over imagery. Gotchas: the element needs a translucent background or you see nothing; parents with overflow: hidden and a radius clip the blur edge; and performance drops with large blurred areas. See MDN: backdrop-filter.

    Classbackdrop-filter
    .backdrop-filter-nonenone
    .backdrop-blur-sm · .backdrop-blur · .backdrop-blur-mdblur(4px) / blur(8px) / blur(12px)
    .backdrop-brightness-{50,100,125}brightness(0.5 / 1 / 1.25)
    .backdrop-contrast-{50,100,150}contrast(0.5 / 1 / 1.5)
    .backdrop-saturate-{0,100,150}saturate(0 / 1 / 1.5)
    .glassblur(14px) saturate(1.4) (--oc-glass-backdrop), plus a white tint at 12% (--oc-glass-tint, --oc-glass-alpha) and a 1px edge in that tint
    .backdrop-grayscale · .backdrop-sepia · .backdrop-invert (and -0)grayscale(1) / sepia(1) / invert(1)
    .backdrop-hue-rotate-{0,30,90,180}hue-rotate(…deg)
    .backdrop-opacity-{0,50,100}opacity(0 / 0.5 / 1)
