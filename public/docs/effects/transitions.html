    Transitions

    _motion_transforms.scss 0 KB JavaScriptNewest CSSv0.4.0

    Animate the change between two states (for example normal → :hover) with .transition-{property}, .duration-{ms}, .ease-{curve} and .delay-{ms}. Nothing moves until a value changes: every demo below reacts when you hover it, focus it with the keyboard, or press its Run button.

    What it does: a transition animates a property from its old to its new value when it changes, instead of switching instantly. You choose which property (.transition-*), how long (.duration-*), how it accelerates (.ease-*) and when it starts (.delay-*). When to use: hover, focus and state changes: color, opacity, shadow, transform. Gotchas: the .transition-* classes only set the property, so always add a .duration-* (without one the duration is 0 and nothing animates); put the transition classes on the base state, not only on :hover, or the way back is instant; transition-all is convenient but animates everything (including layout properties); display and height: auto do not animate without transition-behavior: allow-discrete / interpolate-size. Reduced motion: OmniaCSS shortens every transition to 0.01ms when the visitor asks for reduced motion, so the demos below then jump straight to their end state. See MDN: transition.

    Transition property

    ClassCSS
    .transition-alltransition-property: all (no duration of its own: add .duration-*)
    .transition-colorstransition-property: color, background-color, border-color, text-decoration-color, fill, stroke
    .transition-opacitytransition-property: opacity
    .transition-shadowtransition-property: box-shadow
    .transition-transformtransition-property: transform, translate, scale, rotate
    .transition-cliptransition-property: clip-path (a circle that grows: see Shapes)
    .transition-nonetransition-property: none
    .transition-discrete · .transition-normaltransition-behavior: allow-discrete / normal

    Hover each card or Tab through them: each one animates a single property over 300ms. The last card has the same scale change as the fourth but .transition-none, so it jumps.

    Hover or focus each card: one property animates

    Animates color changes only.
    .transition-opacity

    .transition-shadow
    Animates the shadow only.
    .transition-transform
    Animates transforms only: scale, move, rotate.
    .transition-none
    No animation: the change happens at once.

    Duration

    .duration-{ms} sets how long the change takes. Every dot travels the same distance with the same curve; only the duration differs.

    ClassCSS
    .duration-{75,100,150,200,300,500,700,1000}transition-duration: 75ms, 100ms, 150ms, 200ms, 300ms, 500ms, 700ms, 1000ms

    Press Run (or hover the lanes): all eight dots start together. Short durations (100 to 150ms) suit small feedback such as a button, 200 to 300ms suits panels and menus, longer durations only large movements.

    Timing & easing

    The easing curve controls acceleration: same distance, same duration (.duration-1000), different curve. .ease-spring and .ease-bounce use the CSS linear() function, .ease-steps-4 jumps in four steps.

    ClassCSS
    .ease-lineartransition-timing-function: linear
    .ease-intransition-timing-function: cubic-bezier(0.4, 0, 1, 1)
    .ease-outtransition-timing-function: cubic-bezier(0, 0, 0.2, 1)
    .ease-in-outtransition-timing-function: cubic-bezier(0.4, 0, 0.2, 1)
    .ease-overshoottransition-timing-function: cubic-bezier(0.3, 1.4, 0.5, 1): shoots a little past the end and settles
    .ease-spring / .ease-bouncetransition-timing-function: linear(…): overshoot / bounce
    .ease-steps-4transition-timing-function: steps(4, end)
    .ease-step-start · .ease-step-endtransition-timing-function: step-start / step-end

    Press Run and watch the start and the finish: .ease-in starts slowly, .ease-out brakes at the end, .ease-overshoot goes a little past the line once, .ease-spring shoots past the line and comes back, .ease-bounce bounces against it, .ease-steps-4 jumps. All arrive after one second.

    Easing race

    or hover the lanes
    .ease-linear
    The same speed all the way.
    .ease-in
    Starts slow and ends fast.
    .ease-out
    Starts fast and ends slow.
    .ease-in-out
    Slow at both ends, fast in the middle.
    .ease-overshoot
    Goes a little past the end once, then settles.
    .ease-spring
    Shoots past the end, then settles back.
    .ease-bounce
    Hits the end and bounces back twice.
    .ease-steps-4
    Jumps in four steps instead of gliding.

    Delay

    .delay-{ms} waits before the transition starts, handy for staggered effects.

    ClassCSS
    .delay-{0,75,100,150,200,300,500}transition-delay: 0ms, 75ms, 100ms, 150ms, 200ms, 300ms, 500ms
    .delay-stagger · .delay-stagger-reversetransition-delay: (sibling-index() - 1) × var(--oc-stagger, 60ms), or counted from the last sibling

    Press Run: every dot has the same duration (500ms) but waits a little longer before it leaves.

    Animate a custom property

    A gradient cannot transition, but @property turns a custom property into a typed, animatable value. Hover or focus a ring: --tr-p goes from 0 to its target, so the ring fills and the number counts up with it.

    @property + transition (progress ring)

    @property --tr-p + transition
    Hover the ring or Tab to it: it fills to 75% and the number counts up.
    @property --tr-p + transition
    The same ring in orange: it fills to 40%.

    @property --p { syntax: "<integer>"; inherits: false; initial-value: 0; }
.ring { background: conic-gradient(light-dark(var(--color-teal-70), var(--color-teal-10)) calc(var(--p) * 1%), var(--oc-border-strong) 0);
        transition: --p 1.2s ease-out; }
.ring::after { counter-reset: p var(--p); content: counter(p) "%"; }
.ring:is(:hover, :focus-visible) { --p: 75; }
