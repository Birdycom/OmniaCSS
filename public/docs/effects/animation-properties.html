    Animation Properties & Motion Path

    CSS class _animation_properties.scss animation-properties.html 0 KB JavaScriptBaselinev0.3.0

    Control every part of an animation separately (duration, delay, iterations, direction, fill mode, play state, composition), use modern easing with linear() and steps(), move elements along a path with offset-*, and rotate with the individual rotate property. The ready-made animations (.animate-spin, …) are on the Animations page. See MDN: animation.

    Animation longhands

    Combine them with an animation name: .animate-name-* for the four built-in keyframes, or your own animation-name. The races below use a keyframes rule of their own that moves a dot from the start to the end of its track; every other part of the animation comes from the utility classes. Press Play above a race to start it and Replay to see it again (the buttons are checkboxes, so no script is needed). Reduced motion: OmniaCSS then shortens every animation to 0.01ms and one cycle, so the dots jump straight to the finish.

    ClassCSS
    .animate-duration-{75|150|300|500|700|1000|2000}animation-duration: {n}ms
    .animate-delay-{0|75|150|300|500|1000}animation-delay: {n}ms
    .animate-delay-staggeranimation-delay: (sibling-index() - 1) × var(--oc-stagger, 60ms)
    .animate-repeat-{1|2|3|infinite}animation-iteration-count
    .animate-direction-{normal|reverse|alternate|alternate-reverse}animation-direction
    .animate-fill-{none|forwards|backwards|both}animation-fill-mode
    .animate-running · .animate-pausedanimation-play-state
    .animate-compose-{replace|add|accumulate}animation-composition
    .animate-name-{none|spin|pulse|bounce|ping}animation-name: none / oc-spin / oc-pulse / oc-bounce / oc-ping

    Fill mode decides where an element is before its animation starts (during the delay) and after it ends. Every dot sits at the left of its track; its keyframes start at the dashed ring and end at the finish. Each lane waits 1 s (.animate-delay-1000) and then runs 2 s. Press Play and watch steps 1 and 3: backwards and both jump to the ring during the wait; forwards and both stay at the finish afterwards; none does neither.

    animate-fill-none / forwards / backwards / both

    Watch where each dot is during step 1 and step 3.1. Delay 1 s2. Running 2 s3. FinishedDashed ring = first keyframe (from)

    Easing functions

    linear() approximates springs and bounces with many points; steps() jumps between frames. .animate-ease-* for animations, .ease-* for transitions.

    ClassCSS
    .animate-ease-{linear|in|out|in-out}animation-timing-function: linear / ease-in / ease-out / ease-in-out
    .animate-ease-steps-4animation-timing-function: steps(4, end)
    .animate-ease-springanimation-timing-function: linear(… spring curve …)
    .ease-spring / .ease-bouncetransition-timing-function: linear(…)
    .ease-steps-4 / .ease-step-start / .ease-step-endtransition-timing-function: steps()

    Same run of 2 seconds, different curve. .animate-ease-spring overshoots the finish and settles back; .animate-ease-steps-4 jumps in four steps.

    animate-ease race

    The same two-second run, a different curve per lane.
    .animate-ease-linear
    The same speed all the way.
    .animate-ease-in
    Starts slow and ends fast.
    .animate-ease-out
    Starts fast and ends slow.
    .animate-ease-in-out
    Slow at both ends, fast in the middle.
    .animate-ease-spring
    Shoots past the end, then settles back.
    .animate-ease-steps-4
    Jumps in four steps instead of gliding.

    Motion path

    Move an element along a path (offset-path) and set its position on that path (offset-distance). .animate-follow-path animates the distance from 0% to 100% and back.

    ClassCSS
    .offset-path-noneoffset-path: none

    .offset-path-ellipseoffset-path: ellipse(45% 35% at 50% 50%)
    .offset-path-insetoffset-path: inset(10% round 1rem)
    .offset-path-waveoffset-path: path("M 0 40 C 40 0, 80 80, 120 40 S 200 0, 240 40") (240 × 80px)
    .offset-path-rayoffset-path: ray(45deg closest-side)
    .offset-distance-{0|25|50|75|100}offset-distance: {n}%
    .offset-rotate-{auto|reverse|0}offset-rotate: auto / reverse / 0deg
    .offset-anchor-{center|auto}offset-anchor
    .offset-position-{normal|center}offset-position
    .offset-noneoffset: none

    Rotate property & transform-box

    The individual rotate property works independently of transform, so it does not overwrite translate/scale utilities. transform-box sets the reference box for transform-origin (useful in SVG).

    ClassCSS
    .rotate-prop-{0|45|90|180|n45|n90}rotate: {n}deg (n = negative)
    .rotate-prop-x-180 / .rotate-prop-y-180rotate: x 180deg | y 180deg
    .transform-box-{content|border|fill|stroke|view}transform-box: content-box / border-box / fill-box / stroke-box / view-box

    The dashed outline is the box before rotation. The letter shows the turn: with .rotate-prop-x-180 it is flipped upside down, with .rotate-prop-y-180 mirrored.
