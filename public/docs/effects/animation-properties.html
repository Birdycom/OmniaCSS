    Animation Properties & Motion Path

    CSS class _animation_properties.scss animation-properties.html 0 KB JavaScriptBaselinev0.3.0

    Control every part of an animation separately (duration, delay, iterations, direction, fill mode, play state, composition), use modern easing with linear() and steps(), move elements along a path with offset-*, and rotate with the individual rotate property. The ready-made animations (.animate-spin, …) are on the Animations page. See MDN: animation.

    Animation longhands

    Combine with an animation name (.animate-name-*) or a preset.

    ClassCSS
    .animate-duration-{75|150|300|500|700|1000|2000}animation-duration: {n}ms
    .animate-delay-{0|75|150|300|500|1000}animation-delay: {n}ms
    .animate-repeat-{1|2|3|infinite}animation-iteration-count
    .animate-direction-{normal|reverse|alternate|alternate-reverse}animation-direction
    .animate-fill-{none|forwards|backwards|both}animation-fill-mode
    .animate-running / .animate-pausedanimation-play-state
    .animate-compose-{replace|add|accumulate}animation-composition
    .animate-name-{none|spin|pulse|bounce|ping}animation-name

    animate-name-spin + duration/direction

    .animate-duration-2000
    .animate-direction-alternate
    .animate-paused

    Easing functions

    linear() approximates springs and bounces with many points; steps() jumps between frames. .animate-ease-* for animations, .ease-* for transitions.

    ClassCSS
    .animate-ease-{linear|in|out|in-out}animation-timing-function
    .animate-ease-steps-4animation-timing-function: steps(4, end)
    .animate-ease-springanimation-timing-function: linear(… spring curve …)
    .ease-spring / .ease-bouncetransition-timing-function: linear(…)
    .ease-steps-4 / .ease-step-start / .ease-step-endtransition-timing-function: steps()

    animate-ease-steps-4, animate-ease-spring

    .animate-ease-steps-4
    .animate-ease-spring

<div class="animate-name-bounce animate-duration-1000 animate-repeat-infinite animate-ease-spring bg-dodgerblue size-12 round-full"></div>

    Motion path

    Move an element along a path (offset-path) and set its position on that path (offset-distance). .animate-follow-path animates the distance from 0% to 100%.

    ClassCSS
    .offset-path-{none|circle|ellipse|inset|wave|ray}offset-path
    .offset-distance-{0|25|50|75|100}offset-distance: {n}%
    .offset-rotate-{auto|reverse|0}offset-rotate
    .offset-anchor-{center|auto}offset-anchor
    .offset-position-{normal|center}offset-position
    .offset-noneoffset: none
    .animate-follow-pathanimation: offset-distance 0% → 100% (3s, alternate)

    Rotate property & transform-box

    The individual rotate property works independently of transform, so it does not overwrite translate/scale utilities. transform-box sets the reference box for transform-origin (useful in SVG).

    ClassCSS
    .rotate-prop-{0|45|90|180|n45|n90}rotate: {n}deg
    .rotate-prop-x-180 / .rotate-prop-y-180rotate: x 180deg | y 180deg
    .transform-box-{content|border|fill|stroke|view}transform-box

    rotate-prop-45, rotate-prop-y-180

    .rotate-prop-45
    .rotate-prop-n90

<div class="rotate-prop-n90 bg-linear-to-r from-teal to-blue size-12 round-3"></div>

    .scroll-timeline-name-ocscroll-timeline-name: --oc-timeline
