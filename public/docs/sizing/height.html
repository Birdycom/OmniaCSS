    Height

    _sizing.scss 0 KB JavaScriptNewest CSSv0.2.0

    Utilities for setting the height of an element using rem-based scales, percentages, intrinsic keywords or viewport units.

    Height utilities set height. Unlike width, a percentage height only works when the parent has a definite height; otherwise it falls back to auto, which is the number one reason .h-full "does not work". Prefer letting content define the height and use min-height for floors. See MDN: height.

    Viewport heights: vh, dvh, svh, lvh

    On mobile the browser toolbar slides away while scrolling, so 100vh is as tall as the largest viewport and the bottom of a "full screen" element can hide behind the toolbar. Three newer unit families fix this: svh is the small viewport (toolbar visible), lvh the large one (toolbar hidden) and dvh the dynamic viewport that follows the toolbar and therefore resizes while scrolling. OmniaCSS ships .h-dvh, .min-h-dvh and .max-h-dvh; .h-screen-safe additionally subtracts the safe-area insets of notched devices. On desktop all units are identical. See MDN: viewport units.

    Class / unitMeaning
    .h-screen100vh — largest viewport (legacy)
    .h-dvh100dvh — dynamic: follows the browser UI
    .min-h-dvhmin-height: 100dvh
    .h-screen-safe100dvh minus safe-area insets
    svh / lvhSmall and large viewport; use in custom CSS, e.g. height: 100svh
