    Icon & Square Size

    _sizing.scss 0 KB JavaScriptBaselinev0.2.0

    Set width and height at the same time with .size-{n}.

    .size-n sets width and height to the same value, ideal for icons, avatars and square buttons. The number counts quarter rems: .size-8 is 2rem (32px). Pair it with .flex-shrink-0 so the box is not squeezed in a flex row, and with .round-full for circles. If you need a ratio rather than a fixed size, use .aspect-1 with a width instead. See MDN: width and MDN: height.

    Typical uses

    A customer list uses three square sizes: a .size-10 round avatar, a .size-2 status dot and a .size-8 icon button. Because they have a fixed size, every row lines up, also when a name is long.

    Avatar, status dot and icon button in a list

    .size-10 · .size-2 · .size-8
    A round avatar, a status dot and an icon button. Their fixed size keeps every row lined up.
