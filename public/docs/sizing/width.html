    Width

    _sizing.scss 0 KB JavaScriptNewest CSSv0.2.0

    Utilities for setting the width of an element using rem-based scales, percentages or intrinsic keywords.

    Width utilities set width (the inline size in horizontal writing modes). Use the scale for fixed components, fractions for proportional columns and the keywords when the content should decide: .w-fit shrink-wraps but never exceeds the available space, .w-min is the narrowest possible (longest word), .w-max never wraps. .w-full is 100% of the parent's content box, so it overflows once you add padding and border without box-sizing: border-box; .w-stretch fills the container including margins. See MDN: width.

    Viewport widths: .w-screen is 100vw and includes the scrollbar, which causes horizontal scrolling on desktop; prefer .w-full for page-wide boxes. .w-dvw uses the dynamic viewport and is mainly useful on mobile.
