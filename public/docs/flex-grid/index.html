    Flexbox & Grid

    0 KB JavaScriptBaselinev0.2.0

    Complete utility-class reference for CSS Flexbox and Grid layout.

    Build responsive, one-dimensional (flex) or two-dimensional (grid) layouts without writing custom CSS. Every class is generated from SCSS variables and compiled into omnia.css (@birdycom/omniacss).

    Source FileUtilities Provided
    _flexbox.scssdisplay flex, direction, wrap, basis, grow, shrink
    _grid.scssdisplay grid, template cols/rows, col/row span
    _gap.scssgap, row-gap, column-gap, gap-x/gap-y aliases

    Flex or grid?

    The same eight items in a wrapping flex container and in a grid. Use flex for a row of things that may have their own size (buttons, tags, a toolbar). Use grid when items must line up in columns (cards, forms, dashboards).

    flex or grid

    .flex .flex-wrap .gap-0.5
    One direction. Every item is as wide as its text, each line is filled on its own, so the lines do not form columns.
