    Column Span

    _grid.scss 0 KB JavaScriptBaselinev0.2.0

    Let a grid item cover more than one column track with .col-span-{n}.

    grid-column: span n makes the item as wide as n tracks and lets the auto-placement algorithm place it where it fits. .col-span-full (1 / -1) always covers the complete explicit grid, however many columns it has. If the span is larger than the number of columns, the browser adds implicit columns, so keep it in range. See MDN: grid-column.

    ClassSpan Amount
    .col-span-1 … .col-span-12Span 1 to 12 columns
    .col-span-fullSpan all available columns (1 / -1)
    .col-span-autoAutomatic spanning

    Line Placement

    Explicitly position items by start and end lines.

    Grid lines are numbered from 1 (a four-column grid has lines 1 to 5; negative numbers count from the end). .col-start-n and .col-end-n pin an item to those lines; the end line is exclusive, so start-2 end-4 covers columns 2 and 3. Mix with spans: .col-start-2 .col-span-2. Items placed explicitly are positioned first, the remaining ones fill the gaps.

    ClassCSS Output
    .col-start-{n}grid-column-start: n
    .col-end-{n}grid-column-end: n

    .col-end-autoauto
