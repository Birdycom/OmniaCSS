    Gradients

    CSS class _gradients.scss gradients/index.html 0 KB JavaScriptNewest CSSv0.3.0

    Compose gradients from two kinds of classes: a shape/direction class (.bg-linear-to-r, .bg-radial, .bg-conic, …) and color stops (.from-{color}, optional .via-{color}, .to-{color}) for every Omnia color plus white, black, current and transparent. See MDN: gradient.

    What it does: CSS gradients are generated images: linear blends along a line, radial out from a point, conic around a point. The classes set the shape and the .from-*, .via-* and .to-* classes set the stops from Omnia colors. When to use: hero backgrounds, buttons, borders (via border-image), gradient text, progress and chart backgrounds. Gotchas: a gradient is a background-image, so it replaces other background images and can be tinted with background-blend-mode; the default interpolation is sRGB which can look muddy between complementary colors (use in oklch); and gradients are not animatable directly (use @property or move the background position). See MDN: gradient and MDN: linear-gradient().

    Linear gradients

    Direction keywords (to-t, to-tr, … to-tl) or fixed angles. .bg-linear-to-r-oklch interpolates in OKLCH for smoother mid tones.

    ClassCSS
    .bg-linear-to-{t|tr|r|br|b|bl|l|tl}background-image: linear-gradient(to {direction}, stops)
    .bg-linear-{0|45|90|135|180|225|270|315}background-image: linear-gradient({n}deg, stops)
    .bg-linear-to-r-oklchbackground-image: linear-gradient(to right in oklch, stops)

    Color stops & gradient text

    Stops set custom properties, so they combine with every gradient class. .text-gradient clips the gradient to the text.

    ClassCSS
    .from-{color}--oc-gradient-from: var(--color-{color}-100)
    .via-{color}--oc-gradient-via + three-stop gradient
    .to-{color}--oc-gradient-to: var(--color-{color}-100)
    .from-/to-/via-{white|black|current|transparent}keyword stops
    .text-gradientbackground-clip: text; color: transparent

    All conic variants

    Conic gradients sweep around a center, ideal for pie charts, color wheels and loading rings. .bg-conic-90 and -180 rotate the start angle (watch where the blue lands); .bg-conic-at-t moves the center to the top edge; .bg-conic-wheel is a full hue wheel with its own colors. The other classes need color stops: end on the start color (from-yellow via-blue to-yellow) to avoid a hard seam.

    Animate a gradient with @property

    A gradient cannot transition, but a registered custom property can. @property --angle makes the angle numeric, so a transition (or animation) on it spins the gradient smoothly. Hover or focus the card. This is plain CSS (Chrome, Edge, Safari 16.4+, Firefox 128+).

    @property --angle + transition

    hover
    --angle: 0deg to 360deg
    1
2
3
    @property --angle { syntax: "<angle>"; inherits: false; initial-value: 0deg; }
.card { background: linear-gradient(var(--angle), …); transition: --angle 1s; }
.card:hover { --angle: 360deg; }
