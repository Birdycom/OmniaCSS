2

    Referencing in CSS

    Using design tokens directly in your stylesheets.

    OmniaCSS emits --color-{name}-{step} on :root. Use these variables for custom components.

    1
2
3
4
    .custom-panel {
  background-color: var(--color-blue-50);
  color: var(--color-white);
}
