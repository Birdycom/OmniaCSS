    Basic Combinations

    Omnia scale, HTML color and RAL base color

    .bg-red-70 .text-white
    A step of the Omnia scale: red at 70, with white text.
    Omnia scale.bg-red-70.text-white
    .bg-cornflowerblue .hover:bg-cornflowerblue-90
    An HTML color name. Hover it: the background and text change.
    HTML color (hover me).bg-cornflowerblue.hover:bg-cornflowerblue-90
    .bg-ral1003 .text-ral9005
    A RAL base color with RAL black text.
    RAL base color.bg-ral1003.text-ral9005

    Responsive Overrides

    Color utilities have no responsive prefix of their own; combine the color classes with the responsive display utilities (md:hidden, none md:block) to switch colors per breakpoint.

    Resize the window: blue below 50rem, green from 50rem up

    .md:hidden · .none .md:block
    Below 50rem the blue box shows, from 50rem up the green one. Resize the window to switch.
    Below 50rem: blue
    50rem and wider: green
    Below 50remPhones and narrow windows now
    50rem and widerTablets and desktops now

<style>
  /* The card only uses theme tokens */
  .card { background: var(--oc-card); border: 2px solid var(--oc-border); }
  .card button { background: var(--oc-primary); color: var(--oc-primary-foreground); }

  /* Override the tokens on the wrapper: the same card changes color */
  .promo {
    --oc-card: light-dark(color-mix(in oklch, var(--color-orange-60) 14%, var(--color-white-50)),
                          color-mix(in oklch, var(--color-orange-60) 16%, var(--color-black-50)));
    --oc-border: var(--color-orange-60);
    --oc-primary: var(--color-orange-95);
    --oc-primary-foreground: var(--color-white-50);
  }
  .calm {
    --oc-card: light-dark(color-mix(in oklch, var(--color-teal-70) 10%, var(--color-white-50)),
                          color-mix(in oklch, var(--color-teal-70) 22%, var(--color-black-50)));
    --oc-border: var(--color-teal-70);
    --oc-primary: var(--color-teal-70);
    --oc-primary-foreground: var(--color-white-50);
  }
</style>
