    ConfigurationContent globs, layers, components and the omnia.config.json options. Editor extensionOmniaCSS IntelliSense for VS Code and Cursor: autocomplete, hover CSS, swatches and linting, OmniaUI classes included. AI assistants (MCP)Let Claude, Cursor or Copilot check OmniaCSS classes instead of guessing: lookup, variants, tokens, docs and Tailwind conversion. Fluid values (clamp, min, max)Font sizes and widths that scale with the viewport and stay within bounds. CSS FunctionsFrom clamp() to progress(), stepped values, trigonometry, sibling-index() and typed attr(). VariablesCustom properties, the Omnia tokens, @property and theming with :has(). Unitslh, rlh, cap, ch, small and dynamic viewport units, container units. At-rules (@supports, @layer …)Feature queries as variants, cascade layers, @scope, @property and @function. Selectors & Pseudo-classesEvery pseudo-class and pseudo-element as a variant: user-invalid:, target:, has-[…]:. Responsive & Dark ModeBreakpoint and container variants, the CSS-only theme switch. UtilitiesCursor, scrolling, touch, SVG, accessibility and state variants.
