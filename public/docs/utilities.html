    Accessibility _accessibility.scss v0.2.0

    Utilities for screen readers and Windows High Contrast mode support.

    ClassCSSDescription
    .sr-onlyposition: absolute; width: 1px; height: 1px; clip: rect(0,0,0,0); …Hidden visually, accessible to screen readers
    .not-sr-onlyposition: static; width: auto; height: auto; clip: auto; …Undoes sr-only to show element again
    .forced-color-autoforced-color-adjust: autoBrowser may override colors in High Contrast
    .forced-color-noneforced-color-adjust: nonePrevent color override in High Contrast

  Custom-styled badge
</div>

    Utilities are generated from functions, variables, mixins, and utility SCSS in src/scss/.

    SCSS Source Files

    FileContains
    src/scss/functions/_functions.scssstr-replace, sizing generation functions
    src/scss/variables/_variables.scssCore variable definitions
    src/scss/variables/_mixins.scssRespond mixin for breakpoints
    src/scss/variables/_modifiers.scssPseudo-class modifier map (hover:, focus:, etc.)
