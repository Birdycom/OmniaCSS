    Layout Extras

    CSS class _layout_extras.scss extras.html 0 KB JavaScriptNewest CSSv0.3.0

    Properties that complete the layout families: the inset shorthand, logical min/max sizes, flex-flow, named grid areas, margin-trim, logical overflow/overscroll/scroll spacing, safe-area padding for notched phones, zoom, all, mask shorthands and print pages. See MDN: inset.

    What it covers: smaller layout properties that do not fit elsewhere: inset (offsets for positioned elements), flex-flow and named grid areas, logical overflow/scroll properties, safe areas for notched screens, zoom, and mask for fading content. When to use: reach for the logical (-inline/-block) variants when you need RTL-ready layouts, and for mask-fade-* when a gradient fade is nicer than a hard clip. Gotchas: inset only has an effect on positioned elements; zoom is non-standard in older browsers and changes layout size; masks hide content visually but not from assistive tech. See MDN: inset and MDN: mask.

    Inset & logical sizes

    Values: 0, 1 (.25rem), 2 (.5rem), 4 (1rem), 8 (2rem), auto, full (100%).

    ClassCSS
    .inset-{n}inset: {value}
    .inset-x-{n} / .inset-y-{n}left + right / top + bottom
    .inset-bs-{n} / .inset-be-{n}inset-block-start / inset-block-end
    .min-inline-{0|full|fit|min|max} / .min-block-*min-inline-size / min-block-size
    .max-inline-{full|fit|min|max|none} / .max-block-*max-inline-size / max-block-size

    Flex flow & grid areas

    flex-flow sets direction and wrapping at once. Named grid areas give readable layouts: put .grid-areas-holy-grail on the grid and .area-* on the children.

    ClassCSS
    .flex-flow-{row|row-wrap|col|col-wrap|row-reverse-wrap}flex-flow
    .grid-areas-holy-grailgrid-template-areas: "header header" "sidebar main" "footer footer"
    .grid-areas-stackgrid-template-areas: "header" "main" "sidebar" "footer"
    .grid-areas-none / .grid-template-none / .grid-nonereset grid templates
    .area-{header|sidebar|main|footer|auto|full}grid-area
    .margin-trim-{none|block|inline}margin-trim

    Logical overflow, overscroll & scroll spacing

    Inline/block versions of overflow, overscroll-behavior and scroll-margin/padding. Values for spacing: 0, 2, 4, 8.

    ClassCSS
    .overflow-{inline|block}-{auto|hidden|clip|visible|scroll}overflow-inline / overflow-block
    .overflow-clip-margin-{0|2|4|content}overflow-clip-margin
    .overscroll-{inline|block}-{auto|contain|none}overscroll-behavior-inline / -block
    .scroll-m-inline-{n} / .scroll-m-block-{n}scroll-margin-inline / -block
    .scroll-{ms|me|mbs|mbe}-{n}scroll-margin-{inline|block}-{start|end}
    .scroll-p-inline-{n} / .scroll-p-block-{n}scroll-padding-inline / -block
    .scroll-{ps|pe|pbs|pbe}-{n}scroll-padding-{inline|block}-{start|end}

    Safe areas, zoom, container & reset

    Safe-area padding keeps content clear of notches (add viewport-fit=cover to the viewport meta). .all-* resets every property of an element.

    ClassCSS
    .p-safe / .pt-safe / .pb-safe / .pl-safe / .pr-safepadding: env(safe-area-inset-*)
    .mb-safemargin-bottom: env(safe-area-inset-bottom)
    .h-screen-safeheight: 100dvh minus top/bottom safe areas
    .zoom-{50|75|100|125|150}zoom: {n}%
    .cq-{card|main|sidebar}container: {name} / inline-size
    .all-{initial|inherit|unset|revert|revert-layer}all
    .empty-cells-{show|hide}empty-cells
    .image-orientation-{from-image|none}image-orientation
    .bg-pos-x-{left|center|right|0|50|100}background-position-x
    .bg-pos-y-{top|center|bottom|0|50|100}background-position-y

    Mask shorthand, print pages & SVG geometry

    Fade content out with a mask, print a section on a landscape page, and size SVG shapes with CSS geometry properties.

    ClassCSS
    .mask-resetmask: none
    .mask-fade-{b|r|x}mask: linear-gradient(…) — fade to transparent
    .page-{auto|landscape}page (with @page landscape { size: landscape })
    .anchor-try-most-height-flipposition-try: most-height flip-block, flip-inline
    .cx-{0|25|50|100} / .cy-* / .x-* / .y-*cx / cy / x / y
    .r-{25|50} / .rx-{0|4} / .ry-{0|4}r / rx / ry
    .d-noned: none
