    Images & Object Fit

    CSS class _layout_flow.scss images/index.html 0 KB JavaScriptNewest CSSv0.3.0

    Control how replaced elements (<img>, <video>) fill their box with object-fit and object-position, how they are scaled with image-rendering, and how bright HDR content may get with dynamic-range-limit. See MDN: object-fit.

    Object fit

    object-fit is to <img> and <video> what background-size is to backgrounds: it decides how the picture is resized inside a box whose size is fixed by CSS. cover fills the box and crops the overflow (hero images, avatars, cards), contain shows the whole picture with empty bars, fill stretches it (distorts), none keeps the natural size and scale-down picks the smaller of none and contain. Gotcha: the box needs both dimensions (or .aspect-*), otherwise there is nothing to fit. See MDN: object-fit.

    ClassCSS
    .object-containobject-fit: contain
    .object-coverobject-fit: cover
    .object-fillobject-fit: fill
    .object-noneobject-fit: none
    .object-scale-downobject-fit: scale-down

    Object position

    object-position chooses which part of the picture stays visible when it is cropped (cover, none) or where it sits when there is spare room (contain, scale-down). Use .object-top to keep faces in portrait crops. The default is center. See MDN: object-position.

    Image rendering

    image-rendering sets the scaling algorithm used when a raster image is drawn larger or smaller than its natural size. The default auto smooths (blurs) the result, pixelated and crisp-edges keep hard pixel edges. Use .image-pixelated for pixel art, sprites and QR codes that are scaled up. It does not affect SVG. See MDN: image-rendering.

    ClassCSS
    .image-autoimage-rendering: auto
    .image-smoothimage-rendering: smooth
    .image-crispimage-rendering: crisp-edges
    .image-pixelatedimage-rendering: pixelated

    Dynamic range limit

    dynamic-range-limit caps how bright HDR images and video may render. HDR media can be far brighter than the SDR page around it; .dynamic-range-standard keeps thumbnails and ads from glowing next to the UI, constrained allows some extra headroom and no-limit (the default) shows the full range. It has no visible effect on SDR content or on displays without HDR, so it cannot be demonstrated on every screen. See MDN: dynamic-range-limit.

    ClassCSS
    .dynamic-range-standarddynamic-range-limit: standard
    .dynamic-range-constraineddynamic-range-limit: constrained
    .dynamic-range-no-limitdynamic-range-limit: no-limit

    Object view box

    object-view-box crops a replaced element before object-fit is applied, so you can zoom into part of an image or video without a wrapper and overflow: hidden. .object-view-box-center uses inset(25%) (the central half), .object-view-box-none resets it. It is currently Chromium-only; elsewhere the full picture is shown, so treat the crop as an enhancement. See MDN: object-view-box.

    Resolution-aware images with image-set()

    image-set() lets CSS pick the right candidate for a background, mask or list-style-image by pixel density (1x, 2x) or format (type()), the CSS counterpart of srcset. Put the most modern format first; the browser takes the first candidate it supports. See MDN: image-set().

    .hero {
  background-image: image-set(
    url("hero.avif") type("image/avif") 1x,
    url("hero@2x.avif") type("image/avif") 2x,
    url("hero.jpg") 1x
  );
  background-size: cover;
}
