Layout Flow

_layout_flow.scss v0.2.0

Utilities for controlling Floats, Object Fit, Order, and Multi-column layouts.

What it does: floats take an element out of the normal flow and push it to one side so text wraps around it; multi-column utilities flow content into newspaper-style columns. When to use: images inside articles and long text that should be read in columns. For page layout use flex or grid instead. Gotchas: floats do not give the parent height (use .flow-root), .float-start/-end follow the writing direction while .float-left/-right do not, and columns balance their height so very short content can look uneven. See MDN: float and MDN: columns.
