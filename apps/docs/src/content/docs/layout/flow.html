Layout Flow

_layout_flow.scss v0.2.0

Utilities for controlling Floats, Object Fit, Order, and Multi-column layouts.

What it does: floats take an element out of the normal flow and push it to one side so text wraps around it; multi-column utilities flow content into newspaper-style columns. When to use: images inside articles and long text that should be read in columns. For page layout use flex or grid instead. Gotchas: floats do not give the parent height (use .flow-root), .float-start/-end follow the writing direction while .float-left/-right do not, and columns balance their height so very short content can look uneven. See MDN: float and MDN: columns.

Columns: 1 to 6, and by minimum width

.columns-{n} asks for exactly n columns; .columns-xs/sm/md ask for columns of at least 20, 24 or 28rem and let the browser decide how many fit, which is naturally responsive. .columns-auto sets the count back to auto: without a column width that is one column, so it looks like .columns-1 and has no example of its own; use it to undo a count at a breakpoint, for example md:columns-auto.

The same text with a different number of columns. The vertical line between the columns is a column-rule, added here only to make the columns easy to see.

.columns-1
One column: the text runs the full width.
Multi-column layout pours one text into several columns, like a newspaper. The text runs down the first column and continues at the top of the next one. The browser balances the columns so they end at about the same height. Use it for long lists, footers and short articles; for page layout use grid instead.
