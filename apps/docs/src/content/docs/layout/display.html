Display

_display.scss v0.2.0

Control the display box type of an element using .block, .inline, .none, and more.

What it does: display decides how an element takes part in layout: as a full-width block, as a flowing inline piece of text, as an inline-block (flows like text, sizes like a box), or not at all (none). When to use: switch an element between these roles, hide things responsibly, or clear floats with flow-root. Gotchas: .none removes the element from the accessibility tree and layout (use .invisible to keep its space); width, height and vertical margins are ignored on inline elements; and contents removes the box but keeps the children, which has had accessibility bugs on buttons and tables. Flex and grid have their own pages. See MDN: display.

Why flow-root

A floated child takes no height, so a parent with a border collapses around it (left). .flow-root makes the parent contain its floats (right) without clearfix hacks.
