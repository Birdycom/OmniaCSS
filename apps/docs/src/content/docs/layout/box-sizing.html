Box Sizing

_display.scss v0.2.0

Control how the total width and height of an element is calculated.

What it does: box-sizing sets what width and height measure. border-box includes padding and border (a 160px box stays 160px), content-box measures only the content (padding and border are added on top). When to use: .box-border is the sane default and is applied by the reset; use .box-content only when you deliberately want the content size fixed. Gotchas: mixing both in one layout makes widths hard to predict, and percentage widths plus content-box padding overflow their parent. See MDN: box-sizing.
