Layering

_layering.scss v0.2.0

Control the stacking order (Z-index), visibility, and isolation of elements.

What it does: z-index orders overlapping elements along the z axis, isolation: isolate starts a new stacking context, and visibility hides an element while keeping its space. When to use: dropdowns, sticky headers, overlays. Gotchas: z-index only works on positioned elements (.relative, .absolute, .fixed, .sticky) and flex/grid items; a high z-index inside a stacking context can never rise above a sibling context, so .isolate on a component is the cleanest way to stop z-index wars. See MDN: z-index and MDN: isolation.

Isolation: contain the z-index war
