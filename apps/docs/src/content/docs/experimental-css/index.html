Gap decorations

Draw lines in the gaps of grid, flex and multi-column layouts — no borders or pseudo-elements needed. What: the rule family generalises the old column-rule from multi-column to every gap-based layout. When: divider lines between cards, table-like grids, toolbars, without the usual :not(:last-child) border hacks that break when items wrap. Gotcha: experimental and only in recent Chromium: elsewhere no line shows, so never rely on it as the only separator. More: MDN: Gap decorations.

Caret & interactivity

Shape and blink behaviour of the text cursor, and making a subtree inert from CSS. What: caret-shape switches the text cursor between bar, block and underscore (useful for code editors and terminals); interactivity: inert does what the inert attribute does, but from a stylesheet. Gotchas: caret-color still decides the colour; interactivity: inert hides the subtree from assistive technology and blocks focus, so use it only for content that really is unavailable. More: MDN: caret-shape.

Scroll targets, reading order & overlay

Start a scroller at a given item, build scroll-spy navigation, reorder items for assistive technology and animate the top layer. What: scroll-initial-target chooses where a scroller starts, scroll-target-group turns a list of in-page links into a scroll-spy (the link of the visible section matches :target-current), reading-order tweaks the focus and reading sequence. Gotcha: reordering visually without matching the DOM order is an accessibility risk: change reading-flow or reading-order instead of faking order with order. More: MDN: scroll-target-group.

Text, images & shapes

Mobile text inflation, auto-fitting text, underline insets, cropping images and per-corner shapes. What: corner-shape changes how a border-radius is drawn (bevel, scoop, notch, squircle) without clip-path or SVG; text-decoration-inset shortens underlines; text-fit scales a line to fill its container. Gotchas: corner-shape only does something where a border-radius is set, and borders and shadows follow the new shape; pair experimental features with @supports or accept the plain fallback (round corners, full underline). More: MDN: corner-shape.
