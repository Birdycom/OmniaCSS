Selectors & Pseudo-classes

Variant variants.mjs selectors/index.html v0.8.2

In OmniaCSS every pseudo-class and pseudo-element is a variant: put it in front of any utility, separated by a colon (user-invalid:border-red-60, focus-visible:outline-2, target:block). Variants combine (md:hover:…), work on parents and siblings (group-*, peer-*, has-[…]) and accept any selector in brackets ([&>li]:…). omniacss build generates them on demand. See MDN: CSS selectors.

:target — tabs without JavaScript

A link to #id makes that element :target. The panels are d-none target:block; :has() highlights the active tab and shows the first panel when nothing is targeted. Use scroll-margin-top so a sticky header does not cover the target.

OverviewDetailsReviews
Panel 1: the URL now ends in #se-p1.
Panel 2: shareable — the link opens this tab.
Panel 3: the back button goes to the previous tab.
<div class="se-tabs"> <nav><a href="#se-p1">Overview</a> <a href="#se-p2">Details</a> <a href="#se-p3">Reviews</a></nav> <div id="se-p1" class="d-none target:block">…</div> <div id="se-p2" class="d-none target:block">…</div> <div id="se-p3" class="d-none target:block">…</div> </div> <style> .se-tabs:not(:has(:target)) > div:first-of-type { display: block; } .se-tabs:has(#se-p2:target) a[href="#se-p2"] { background: var(--color-vividblue-80); } </style>

:focus-visible — a focus ring for keyboard users only

:focus also matches after a mouse click; :focus-visible only when the browser decides a ring helps (keyboard, programmatic focus). Click both buttons, then press Tab.

<button class="outline-none focus-visible:outline-solid focus-visible:outline-2 focus-visible:outline-vividblue-80 outline-offset-2"> Save </button>

:user-valid and :user-invalid — validation that waits for the user

:invalid is red before anyone typed. :user-invalid waits until the user changed the field and left it (or submitted). The message uses peer-user-invalid:block, the form border reacts with has-[:user-invalid]:.

Please enter a valid e-mail address. Looks good.
<form class="has-[:user-invalid]:border-red-60 has-[:user-valid]:border-green-50"> <input type="email" required class="peer border-2 border-solid border-mistblue-20 user-invalid:border-red-60 user-valid:border-green-50"> <small class="d-none peer-user-invalid:block text-red-60">Please enter a valid e-mail address.</small> <small class="d-none peer-user-valid:block text-green-60">Looks good.</small> </form>

:has() — style the parent

has-[input:checked]: styles a card when the radio inside it is selected. The whole card is the label, so it is one click target.

<label class="has-[input:checked]:border-vividblue-80 has-[input:checked]:bg-mistblue-20"> <input type="radio" name="plan"> <b>Pro</b> </label>

Browser support

All selectors on this page work in current browsers. :user-valid/:user-invalid need Chrome 119, Firefox 88, Safari 16.5; :has() Chrome 105, Firefox 121, Safari 15.4.
