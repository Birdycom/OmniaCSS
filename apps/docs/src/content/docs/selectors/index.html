Selectors & Pseudo-classes

Variant variants.mjs selectors/index.html v0.8.2

In OmniaCSS every pseudo-class and pseudo-element is a variant: put it in front of any utility, separated by a colon (user-invalid:border-red-60, focus-visible:outline-2, target:block). Variants combine (md:hover:…), work on parents and siblings (group-*, peer-*, has-[…]) and accept any selector in brackets ([&>li]:…). omniacss build generates them on demand. See MDN: CSS selectors.

:target — tabs without JavaScript

A link to #id makes that element :target, and target:block shows it. The catch: the browser also scrolls the target to the top of the window. In these tabs the links point to small markers that are fixed at the top of the window, so there is nothing to scroll; each panel follows its marker with peer-target/name:block. :has() highlights the active tab and shows the first panel when nothing is targeted. When the jump is welcome (a long page with sections), put target:block or a highlight right on the section and use scroll-margin-top so a sticky header does not cover it.

:user-valid and :user-invalid — validation that waits for the user

:invalid is red before anyone typed. :user-invalid waits until the user changed the field and left it (or submitted). The message uses peer-user-invalid:block, the form border reacts with has-[:user-invalid]:.

Type something in the field, then click outside it: the borders and the message follow what you typed.

Media states: a player that follows the audio v0.18.0

playing:, paused:, seeking:, buffering:, stalled:, muted: and volume-locked: style an <audio> or <video> by what it is doing. Combine them with group-has-, has- or peer- to style the player around it. Press play in the native controls below: the badge, the bars and the border follow the audio. The page itself has no player script.

Native and fallback. Safari (15.4+) and Firefox (150+) know :playing, :paused and friends. Chrome and Edge add them in version 158 (November 2026); the support table below may still say no. For older Chrome and Edge, load the small optional script media-states.js: it copies the state of every audio and video element to attributes (data-paused, data-playing, data-muted, data-seeking, data-buffering, data-stalled). Every media-state variant writes two separate rules, one for the pseudo-class and one for the attribute, so the classes are the same everywhere. In a browser with native support the script does nothing. volume-locked: has no script equivalent and stays native only. This page loads the script, so the demo works in every browser.

:state(): custom states of your own elements v0.18.0

A custom element can set its own states with this.attachInternals().states.add("on"), without attributes in the HTML. state-[on]: styles the element in that state, group-state-[on]: its children and has-state-[on]: a parent. Click the switch (or press Space). Chrome 125, Firefox 126, Safari 17.4.

state-[on]:border-green-50 · group-state-[on]:d-none · group-state-[on]:inline
The script only adds or removes the state "on"; the border and the text come from the classes.
Notifications offon
<se-toggle class="group state-[on]:border-green-50"> Notifications <span class="group-state-[on]:d-none">off</span><span class="d-none group-state-[on]:inline">on</span> </se-toggle> <script> customElements.define("se-toggle", class extends HTMLElement { #internals = this.attachInternals(); connectedCallback() { this.role = "switch"; this.tabIndex = 0; this.ariaChecked = "false"; this.addEventListener("click", () => this.toggle()); this.addEventListener("keydown", (e) => { if (e.key === " " || e.key === "Enter") { e.preventDefault(); this.toggle(); } }); } toggle() { const on = !this.#internals.states.has("on"); on ? this.#internals.states.add("on") : this.#internals.states.delete("on"); this.ariaChecked = String(on); } }); </script>

Browser support

All selectors on this page work in current browsers, except the media states. :user-valid/:user-invalid need Chrome 119, Firefox 88, Safari 16.5; :has() Chrome 105, Firefox 121, Safari 15.4; :state() Chrome 125, Firefox 126, Safari 17.4. The media states (:playing, :paused …) are native in Safari 15.4, Firefox 150 and Chrome/Edge 158 (too new for the table below); in older Chrome and Edge the optional media-states.js fallback makes the same classes work.
