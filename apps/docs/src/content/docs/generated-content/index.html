Content

Content helpers for the pseudo-elements. .content-attr prints the value of the data-oc-content attribute. What: content fills ::before and ::after with text, an attribute value, a counter or an image. When: small decorations, labels taken from data-* attributes (tooltips without extra markup), icons from masks. Gotchas: generated text is not selectable, may be read by screen readers and cannot be translated by the page, so never put essential information there; a pseudo-element only renders when content is set (even ""). More: MDN: content.

ClassCSS
.content-none::before, ::after { content: none }
.content-empty::before, ::after { content: "" }
.content-open-quote::before { content: open-quote }
.content-close-quote::after { content: close-quote }
.content-attr::before { content: attr(data-oc-content) }

Quotes

Quotation marks for <q> and nested quotes (outer pair, inner pair). What: quotes defines the outer and inner pair that <q> and open-quote / close-quote use. Gotcha: the browser picks quotes from the lang attribute by default, so set lang correctly first and override only when the design demands a house style. More: MDN: quotes.
