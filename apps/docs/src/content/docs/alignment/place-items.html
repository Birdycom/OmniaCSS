Place Items

_alignment.scss v0.2.0

Shorthand for align-items and justify-items: align grid items on both axes inside their cells.

place-items positions each item inside its grid cell horizontally and vertically in one go. .place-items-center is the shortest way to centre content in every cell, e.g. icon tiles or a single child (.grid.place-items-center). A single value is applied to both axes. In flexbox only the align part applies. See MDN: place-items.
