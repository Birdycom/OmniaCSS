Align Content

_alignment.scss v0.2.0

Distribute the lines of a multi-line flex container, the rows of a grid, or the content of a block container along the cross axis.

align-content packs whole lines (not individual items) inside a container that is taller than its content. It only shows up when the container is multi-line: .flex.wrap, a grid with extra block-size, or (since Chrome 123 / Firefox 125 / Safari 17.4) a plain block container. For a single flex line use .align-items-* instead. See MDN: align-content.

Block containers

Newer browsers apply align-content to ordinary block containers, so vertical centring no longer needs flex or grid. Add .align-center to any element with a height; in older browsers the content simply stays at the top.
