Justify Self

_alignment.scss v0.2.0

Align one grid item along the inline axis inside its cell with .justify-self-{value}.

justify-self overrides the container's justify-items for a single item. Put it on the child of a grid. Gotcha: it has no effect in flexbox because flex items share the main axis; use an auto inline margin (.ml-auto) to push a flex item to the end. See MDN: justify-self.

.justify-self-startjustify-self: start

.justify-self-stretchjustify-self: stretch
