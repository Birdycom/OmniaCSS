Justify Self

_alignment.scss v0.2.0

Align one grid item along the inline axis inside its cell with .justify-self-{value}.

In one sentence: justify-self moves one grid item along the inline axis (left to right) inside its own cell; put it on the child. In flexbox it does nothing: use .ml-auto there.

It overrides the grid's justify-items for a single item. Flex items share one main axis, so there is no cell to move in; an auto inline margin (.ml-auto) pushes a flex item to the end instead. See MDN: justify-self.

Real use: a form button

A two-column form whose button spans both columns. Grid items stretch by default, so the button becomes a wide bar. .justify-self-end on the button alone fixes that.

No justify-self class
The button spans both columns and stretches to the full width of the form.
.justify-self-end
The button keeps its natural width and sits at the right, under the fields.
