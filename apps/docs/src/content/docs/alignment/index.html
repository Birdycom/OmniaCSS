Alignment

v0.2.0

Complete reference for positioning items along the main and cross axes.

OmniaCSS has a class for every CSS alignment property, for both flexbox and grid. They decide where items go when the container has more room than they need. The names follow one rule: justify-* works along the main (inline) axis, align-* along the cross (block) axis, and place-* sets both at once.

Which axis is which

In a flex row the main axis runs left to right; .flex-col turns it top to bottom. A grid has no main axis: justify-* is always horizontal and align-* always vertical.

Cheat sheet

*-content moves the whole group (or the lines and tracks), *-items sets the position of every item, *-self overrides it for one item.

PropertyWhat movesFlex rowGrid
justify-contentthe group of items, or the column tracksleft to rightleft to right
