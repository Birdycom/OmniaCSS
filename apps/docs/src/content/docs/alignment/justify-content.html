Justify Content

_alignment.scss v0.2.0

Distribute free space along the main axis of a flex or grid container using .justify-{value}.

justify-content decides where the items (flex) or tracks (grid) sit along the main axis when they do not fill the whole container. In a row flexbox that is horizontal, in .flex-col it is vertical. Use it for toolbars (.justify-between), centred groups and button rows. It only has an effect when there is leftover space; with .flex-1 children or a full-width grid there is nothing to distribute. See MDN: justify-content.

ClassJustify Value
.justify-startjustify-content: start
.justify-centerjustify-content: center
.justify-endjustify-content: end
.justify-betweenjustify-content: space-between
.justify-aroundjustify-content: space-around
.justify-evenlyjustify-content: space-evenly
.justify-stretchjustify-content: stretch
.justify-center-safejustify-content: safe center (never clips on overflow)

Stretch needs auto-sized tracks

justify-content: stretch does nothing on a flex container (items are sized by flex rules). It grows auto grid tracks, so use it with .grid-cols-auto and an implicit column flow. Compare it with the same grid on .justify-start.

Safe alignment

Plain center can push items out of the start edge when they overflow, where they can no longer be scrolled to. The safe keyword falls back to start in that case. Both containers below are too narrow for their content.

.justify-center
long item one
long item two
long item three
.justify-center-safe
long item one
long item two
long item three
<div class="flex justify-center-safe">…</div>

Gotcha: the axis follows flex-direction. With .flex-col, .justify-* works vertically and needs a container height to show anything.
