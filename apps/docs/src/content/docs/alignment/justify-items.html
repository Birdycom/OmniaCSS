Justify Items

_alignment.scss v0.2.0

Align grid items along the inline axis inside their grid area using .justify-items-{value}.

justify-items sets the default justify-self of all items in a grid (and block layout). Each item is positioned inside its own cell, so the effect is only visible when the item is narrower than the cell. The default is stretch, which fills the cell. It is ignored by flex containers: use .justify-content or auto margins there. See MDN: justify-items.

Every value in a three column grid

left and right ignore writing direction, start and end follow it. The stretch tile uses items without a fixed width.
