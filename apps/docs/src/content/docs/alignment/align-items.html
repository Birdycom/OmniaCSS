Align Items

_alignment.scss v0.2.0

Align all children of a flex or grid container on the cross axis with .align-items-{value}.

align-items sets the default align-self of every child. In a row flexbox it controls the vertical position; the default is stretch, which is why flex children are equally tall. Use .align-items-center for icon + label rows and .align-items-baseline when text of different sizes must share one baseline. Items with a fixed height are not stretched. See MDN: align-items.

Baseline alignment

Baseline alignment lines up the first line of text of every item, regardless of padding or box height. baseline-last aligns the last line, which is useful for multi-line labels with a trailing amount.
