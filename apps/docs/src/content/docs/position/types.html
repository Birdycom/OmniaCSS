Position Types

_position.scss v0.2.0

Control the positioning method of an element.

What: position decides how an element takes part in layout and what its top / right / bottom / left (inset) values mean. static is the default and ignores insets; relative keeps its place in the flow but can be nudged, and becomes the reference box for absolute children; absolute leaves the flow and is placed against the nearest positioned ancestor; fixed sticks to the viewport; sticky is relative until a scroll threshold is reached, then sticks. When: overlays, badges and corner labels (absolute in relative), sticky table headers and navbars, floating buttons (fixed). Gotchas: an absolute element needs a positioned ancestor (.relative), otherwise it jumps to the page; sticky needs an inset (.top-0) and stops working inside an ancestor with overflow: hidden; a transformed ancestor becomes the reference of its fixed children. More: MDN: position.
