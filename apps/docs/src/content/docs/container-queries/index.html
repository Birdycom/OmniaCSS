Container Queries

CSS class _containment.scss container-queries/index.html v0.3.0

Container queries style elements based on the size of their container instead of the viewport. Turn an element into a query container with .container-inline-size (or the short alias .cq-inline), then use the .cq-{xs|sm|md|lg|xl}: variants on its children. Containment and content-visibility isolate rendering work for better performance. See MDN: Container queries.

Container type

Makes an element a query container. inline-size is the one you need in most cases; scroll-state enables @container scroll-state(...) queries (stuck, snapped, scrollable).

.container-inline-size and its short alias .cq-inline are the ones you need most: the examples below use .cq-inline. .container-size / .cq-size also let you query the height, but then the box needs a height of its own. .container-normal / .cq-normal switch size queries off again (style queries keep working). .container-scroll-state / .cq-scroll-state have their own example at the end.

Name a container so a @container name (...) rule targets that specific ancestor instead of the nearest one.

.cq-name-sidebar has an example below; .cq-name-main and .cq-name-card work the same way with their own name, and .cq-name-none removes a name.

Container query variants

Same idea as the responsive sm:/md:/lg: prefixes, but measured against the nearest query container. Available for block, hidden, flex, grid, inline-flex, flex-row, flex-col and grid-cols-1 … grid-cols-6.

ClassCSS
.cq-xs:{utility}@container (min-width: 20rem)
.cq-sm:{utility}@container (min-width: 24rem)
.cq-md:{utility}@container (min-width: 28rem)
.cq-lg:{utility}@container (min-width: 32rem)
.cq-xl:{utility}@container (min-width: 36rem)
.style-[--tone:warn]:{utility}@container style(--tone: warn), any utility, on demand
.style-[--tone:warn]/card:{utility}@container card style(--tone: warn), only the container named card

What it does: a container query applies styles based on the width of a parent (the query container) rather than the viewport, so a component adapts to wherever you place it: a wide main column, a narrow sidebar or a modal. When to use: reusable cards, widgets and form rows. Use the viewport prefixes (md:) for page-level layout and cq-*: for component-level layout. Gotchas: an element cannot query itself, only an ancestor; inline-size containment means the container no longer sizes itself from its children (give it a width); and a child never reacts to a container that is not container-type. See MDN: container queries.

Container query units: cqi, cqb, cqw

1cqi is 1% of the container's inline size (cqb block size, cqmin/cqmax the smaller/larger). They let type and spacing scale with the component, not the viewport. Without a container they fall back to the small viewport units. Drag the handle: the heading and padding scale smoothly.

Named containers

With .cq-name-* a rule can target one specific ancestor. Below, the inner card sits in a small box inside a resizable sidebar container, but @container sidebar (min-width: 26rem) skips the nearest container and reacts to the sidebar. The card turns green when the sidebar is wide, no matter how small the card itself is.

Style queries

@container style(--tone: warn) queries the computed value of a custom property on a parent, so a component can change look from a single data attribute or token set by its parent, without extra classes. The custom property does not need any container-type. Gotcha: only custom properties are supported cross-browser (Chrome, Edge, Safari 18+ and current Firefox); older browsers ignore the query, so the base style must still look acceptable. See MDN: style queries.

The style-[…]: variant v0.18.0

The same query as a variant, so you need no CSS of your own: style-[--tone:warn]:bg-orange-50 writes @container style(--tone: warn) around the utility. Write the colon without spaces; an underscore becomes a space (style-[--size:very_large]:). Add /name to ask one named container (style-[--tone:warn]/card:). Without a value (style-[--featured]:) the query asks whether the property is set at all. Here the text color comes from text-contrast-*, so it stays readable on every tone.

Containment

Tells the browser that a subtree is independent from the rest of the page, so layout, style and paint work can be skipped or limited.

ClassCSS
.contain-nonecontain: none
.contain-strictcontain: strict
.contain-contentcontain: content
.contain-sizecontain: size
.contain-inline-sizecontain: inline-size
.contain-layoutcontain: layout
.contain-stylecontain: style
.contain-paintcontain: paint

Two of these have a visible effect: .contain-paint clips what sticks out, and .contain-size makes the box ignore its content for its size. .contain-layout, .contain-style, .contain-content and .contain-strict only let the browser skip work, so they look the same as .contain-none; .contain-inline-size is .contain-size for the width only.

Content visibility

.content-auto skips rendering of off-screen content until it is needed. Combine with .contain-intrinsic-auto-* so the placeholder keeps a realistic height and the scrollbar does not jump.

ClassCSS
.content-visiblecontent-visibility: visible
.content-autocontent-visibility: auto
.content-hiddencontent-visibility: hidden
.contain-intrinsic-nonecontain-intrinsic-size: none
.contain-intrinsic-auto-smcontain-intrinsic-size: auto 200px
.contain-intrinsic-auto-mdcontain-intrinsic-size: auto 500px
.contain-intrinsic-auto-lgcontain-intrinsic-size: auto 1000px

.content-auto looks like .content-visible: the browser only skips the content while it is off screen, which you notice as speed on a long page, not on screen. The .contain-intrinsic-* classes give such a skipped box a stand-in height (200, 500 or 1000px) so the scroll bar does not jump.

Usage example

For queries the variants do not cover, write your own @container rule against a named container.

<aside class="cq-inline cq-name-sidebar"> <div class="card">…</div> </aside> /* In your CSS */ @container sidebar (min-width: 400px) { .card { flex-direction: row; } } /* Scroll-state query: style a sticky header once it is stuck */ .header { position: sticky; top: 0; } @container scroll-state(stuck: top) { .header > nav { box-shadow: 0 2px 8px rgb(0 0 0 / 0.15); } }

Browser support

Size container queries degrade gracefully: without support the base (mobile-first) classes stay active. Scroll-state queries are newer and are simply ignored by browsers that lack them.
