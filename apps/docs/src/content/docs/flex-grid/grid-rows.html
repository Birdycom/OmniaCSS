Grid Rows

_grid.scss v0.2.0

Define row tracks with .grid-rows-{n} and let items span rows with .row-span-{n}.

Template Rows

Rows are normally created automatically, so .grid-rows-n is only needed when you want a fixed number of equal-height rows, most often together with .grid-flow-col (fill columns first) or a container with a fixed height. Each row is minmax(0, 1fr), so they divide the available height, which means the container needs a height of its own. See MDN: grid-template-rows.

Subgrid rows

Cards of different content length normally have misaligned headers and footers. Let each card span three parent rows and use .grid-rows-subgrid: the title, body and footer rows are then shared, so all footers line up. The cards keep the parent's row gap. Subgrid is supported in all current browsers; older ones show the cards without alignment. See MDN: subgrid.

Line Placement

Explicitly position items by start and end row lines.

Like columns, rows are addressed by grid line number. .row-start-2 .row-end-4 covers rows 2 and 3. Explicit placement can overlap other items: later items paint on top. Use it for hero layouts, overlays and captions on images.
