Flex Wrap

_flexbox.scss v0.2.0

Decide whether flex items stay on one line or wrap onto multiple lines.

By default a flex container keeps all items on one line and shrinks them (nowrap). With .flex-wrap (alias .wrap) items that do not fit move to the next line. wrap-reverse stacks the new lines upwards. Gotcha: wrapped lines are independent, so items in different lines do not align in columns; use grid for that. The distance between lines is controlled by .align-* (align-content) and the gap utilities. See MDN: flex-wrap.

ClassBehavior
.flex-nowrapForce items onto a single line (prevent wrap)
.flex-wrapWrap items onto multiple lines (standard)
.wrapShort alias for .flex-wrap
.flex-wrap-reverseWrap items onto multiple lines in reverse order
