Display

_flexbox.scss v0.2.0

Choose how an element generates its box: block-level or inline-level flex and grid containers.

Setting display to flex or grid turns an element into a container: its direct children become flex or grid items. The block-level versions (.flex, .grid) take the full available width, the inline-* versions only as much as their content and sit in the text flow like a word. Only direct children are affected; nested containers need their own class. .contents removes the box itself so its children take part in the parent layout. See MDN: display.

ClassRender Mode
.flexBlock-level flex container
.inline-flexInline-level flex container
.gridBlock-level grid container
.inline-gridInline-level grid container
.blockBlock box (default for div)
.flow-rootBlock box that contains its floats
.contentsBox disappears, children stay

display: contents

Wrapper elements that exist only for markup reasons can be dissolved so their children join the grid of the grandparent. Gotcha: older browsers dropped display: contents elements from the accessibility tree; always test buttons and lists.
