Flex Direction

_flexbox.scss v0.2.0

Set the main axis of a flex container with .flex-row and .flex-col (and their reverse variants).

flex-direction defines the main axis and the order items follow it. row (default) runs along the inline direction, column stacks items. The -reverse variants only reverse the visual order: tab order and screen readers still follow the DOM, so use them sparingly. Combine with a breakpoint prefix (.flex-col md:flex-row) for layouts that stack on small screens. See MDN: flex-direction.

ClassDirection
.flex-rowHorizontal (start to end)
.flex-row-reverseHorizontal (end to start)
.flex-colVertical (top to bottom)
.flex-col-reverseVertical (bottom to top)
