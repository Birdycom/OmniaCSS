Flex Direction

_flexbox.scss v0.2.0

Set the main axis of a flex container with .flex-row and .flex-col (and their reverse variants).

flex-direction defines the main axis and the order items follow it. row (default) runs along the inline direction, column stacks items. The -reverse variants only reverse the visual order: tab order and screen readers still follow the DOM, so use them sparingly. Combine with a breakpoint prefix (.flex-col md:flex-row) for layouts that stack on small screens. See MDN: flex-direction.

ClassDirection
.flex-rowHorizontal (start to end)
.flex-row-reverseHorizontal (end to start)
.flex-colVertical (top to bottom)
.flex-col-reverseVertical (bottom to top)

Real use: toolbar or stacked menu

The same four buttons, only the direction differs. A row gives a toolbar (.align-items-start keeps the buttons at their own height), a column gives a menu where every button is as wide as the container. Add a breakpoint prefix (.flex-col md:flex-row) to switch between the two.

.flex .flex-row
A toolbar.
.flex .flex-col
The same four buttons as a stacked menu.

Real use: chat messages

The reverse variant mirrors a row without changing the HTML: the avatar of your own messages moves to the right. Screen readers still read avatar first, then text, which is what you want here.

.flex-row and .flex-row-reverse
Each message is avatar + text in the same order. Your own messages use .flex-row-reverse.
