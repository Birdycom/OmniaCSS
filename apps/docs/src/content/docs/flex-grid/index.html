Flexbox & Grid

v0.2.0

Complete utility-class reference for CSS Flexbox and Grid layout.

Build responsive, one-dimensional (flex) or two-dimensional (grid) layouts without writing custom CSS. Every class is generated from SCSS variables and compiled into omnia_main.css.
