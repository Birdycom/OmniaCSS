Gap

_gap.scss v0.2.0

Space between rows and columns of flex and grid containers.

gap adds space between items only (never at the outer edge), which removes the need for margin hacks on the first or last child. It works in grid, flexbox and multi-column layouts. .gap-x-* sets the column gap, .gap-y-* the row gap. The scale is rem based: .gap-1 is 1rem, decimals such as .gap-0.5 are half steps. Gotcha: in a wrapping flexbox the row gap only appears between lines. See MDN: gap.

ClassAxes Affected
.gap-{n}Both row and column
.gap-x-{n}Column only (horizontal)
.gap-y-{n}Row only (vertical)
.gap-0Remove all gaps
.gap-0.50.5rem on both axes
