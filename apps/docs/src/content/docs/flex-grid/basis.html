Flex Basis

_flexbox.scss v0.2.0

Set the initial main-size of a flex item before free space is distributed.

flex-basis is the starting size of an item along the main axis. It beats width in a row (and height in a column) and can be a length, a percentage of the container or auto (use the width/content). Fractions such as .basis-perc-1/3 make column grids with flexbox; remember that gaps are not subtracted, so three 1/3 items plus a gap wrap or shrink. The final size may still change through grow and shrink. See MDN: flex-basis.
