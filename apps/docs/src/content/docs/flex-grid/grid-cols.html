Grid Columns

_grid.scss v0.2.0

Define the column tracks of a grid with .grid-cols-{n}.

.grid-cols-3 creates three equal columns with repeat(3, minmax(0, 1fr)). The minmax(0, 1fr) matters: plain 1fr can never shrink below the content width, so a long word or image would blow the track open. Items fill the columns row by row and add implicit rows as needed. Use a breakpoint prefix to change the column count responsively. See MDN: grid-template-columns.

Subgrid

.grid-cols-subgrid lets a nested grid reuse the column tracks of its parent instead of defining its own, so the children line up with the outer grid (baseline in all current browsers since late 2023). The nested element must itself span the tracks it wants to inherit, e.g. with .col-span-3. Gaps are inherited too. See MDN: subgrid.

Gotcha: with equal 1fr tracks both tiles look similar; the difference shows when the outer tracks are uneven (for example grid-template-columns: 8rem 1fr 4rem) or when the parent gap differs from the nested one.
