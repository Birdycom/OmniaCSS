Outline-offset

CSS class _borders_outlines.scss outline-offset.html v0.2.0

Outline offset is the gap between the element’s border and the outline. Use .outline-offset-none (0) or .outline-offset-1 … .outline-offset-12 to add space. Handy for focus rings so the outline doesn’t sit on the border. Values from $outlineoffsets in _variables_layout.scss.

What it does: outline-offset sets the gap between the border edge and the outline; a negative value draws the outline inside the box. When to use: focus rings that breathe (2px is a good default), selection frames and highlight effects. Gotchas: the offset is not part of the outline shorthand, so a later outline: declaration resets it; outlines take no layout space, so a large offset can overlap neighbours or get clipped by a parent with overflow: hidden. See MDN: outline-offset.

CSS classes

All classes set outline-offset. Use .outline-offset-none or .outline-offset-1 … .outline-offset-12. The number is the same scale as border/outline width (e.g. 2 = 4px).

Animate the offset on hover

outline-offset is animatable. Hover or focus the cards: the ring pulls away from the box with a transition, a nice and cheap hover effect.

hover me
.outline-offset-none → 8
hover me
.outline-offset-2 → 8
hover me
.outline-offset-4 → 8
<div class="outline-2 outline-solid outline-offset-2 transition-all hover:outline-offset-8">…</div>

Negative offsets: the ring inside the box

There is no negative offset utility class, so set outline-offset inline or in your own CSS. Inside rings are useful on elements that touch a clipping edge.
