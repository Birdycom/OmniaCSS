Outline-offset

CSS class _borders_outlines.scss outline-offset.html v0.2.0

Outline offset is the gap between the element’s border and the outline. Use .outline-offset-none (0) or .outline-offset-1 … .outline-offset-12 to add space. Handy for focus rings so the outline doesn’t sit on the border. Values from $outlineoffsets in _variables_layout.scss.

What it does: outline-offset sets the gap between the border edge and the outline; a negative value draws the outline inside the box. An outline (unlike a border) takes no space, so changing the offset never moves anything. When to use: focus rings that breathe (2px to 4px is a good default), selection frames and highlight effects. Gotchas: the offset is not part of the outline shorthand: outline: 2px solid leaves the offset as it was, so set it separately; a large offset can overlap neighbours or get clipped by a parent with overflow: hidden. See MDN: outline-offset.

CSS classes

All classes set outline-offset. Use .outline-offset-none or .outline-offset-1 … .outline-offset-12. The number follows the same scale as border and outline width (e.g. 2 = 4px).

The offset scale

The offset is the gap between the edge of the box and the outline. Each box has the same 4px orange outline; only the offset class changes. Look at the strip of page background between the light orange box and the ring: it grows with every step.

Every number from .outline-offset-1 (2px) to .outline-offset-12 exists; the example shows the main steps.

Negative offsets: the ring inside the box

A negative offset pulls the outline inside the box. That helps when an element touches an edge that would clip the ring, like a photo in a scroll strip or a cell in a table. There is no negative utility class, so set outline-offset inline or in your own CSS. The ring is white on the dark tiles, so it stays visible inside.

Animate the offset on hover

outline-offset can be animated. Move the mouse over a card, or Tab to it: the ring moves out to 16px with a short transition. It is a cheap hover effect that never shifts the layout.
