Borders Utilities

This page documents all OmniaCSS utilities for borders, border-radius, outlines, and corner shape. Use the left sidebar to jump to a section. In each section you get a short explanation, the available CSS classes with their output, and live demos. Combine classes (e.g. .border-2 + .border-solid + .border-dodgerblue-50 + .round-4) to style boxes, cards, buttons, and focus rings. Border and outline colors use the same palette as Colors.

Sections

Each topic has its own page with CSS classes, previews, and a Source & Further reading block at the bottom.

  • Border-radius — .round-none … .round-12, .round-full, directional and single-corner variants
  • Border-width — .border … .border-12, per side, divider utilities
  • Border-style — solid, dashed, dotted, double, groove, ridge, inset, outset
  • Border-color — transparent, current, full palette (Omnia, HTML, RAL)
  • Outline-width — .outline-none … .outline-12
  • Outline-style — solid, dashed, dotted, double, etc.
  • Outline-color — transparent, current, full palette
  • Outline-offset — gap between border and outline
  • Outline (focus ring) — combining width, style, color, offset for focus states
  • Border sides & images — per-side and logical borders, single-corner radii, border-image stripes and gradients
  • Corner shape — round, scoop, bevel, notch, square, squircle (experimental)

Source & Further Reading

borders doc

All utilities in this section are generated from src/scss/utilities/_borders_outlines.scss and src/scss/utilities/_corner_shape.scss. Variable maps live in src/scss/variables/_variables_layout.scss: $roundsizes, $bordersizes, $dividersizes, $borderstyles, $bordercolors, $outlinesizes, $outlineoffsets, $outlinestyles, $outlinecolors. Border and outline palette colors are generated in _borders_outlines.scss from the same color maps as Colors. Each subpage has a page-specific Source & Further reading block at the bottom.

SCSS source files

FileContains
src/scss/utilities/_borders_outlines.scssborder-radius, border-width, divider, border-style, border-color, outline-width, outline-offset, outline-style, outline-color (uses maps from _variables_layout.scss and color palette).
src/scss/utilities/_corner_shape.scsscorner-shape: .corner-round, .corner-scoop, .corner-bevel, .corner-notch, .corner-square, .corner-squircle. Experimental; combine with border-radius (e.g. .round-6).
src/scss/variables/_variables_layout.scssMaps: $roundsizes, $bordersizes, $dividersizes, $borderstyles, $bordercolors, $outlinesizes, $outlineoffsets, $outlinestyles, $outlinecolors. Palette border/outline colors are generated in _borders_outlines.scss.

Compiled output

Run npm run build to compile SCSS; all border, outline and corner-shape classes end up in public/css/omnia_main.css (via omnia_main.scss → @use 'utilities/_borders_outlines.scss' and @use 'utilities/_corner_shape.scss').
