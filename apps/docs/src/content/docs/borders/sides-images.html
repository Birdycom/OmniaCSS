Border Sides & Images

CSS class _borders_extended.scss sides-images.html v0.3.0

Style each side of a border separately, use logical sides that follow the writing direction, round single corners and paint borders with images or gradients (border-image). Widths per side (.border-t*) and radius presets (.round-*) are on the Border-width and Border-radius pages. See MDN: border-image.

What it does: this page covers the less common border tools: per-side style and color, logical sides (border-s-* follow the writing direction, so they flip in right-to-left languages), per-corner and logical radii, and border-image for gradient or striped borders. When to use: callouts with an accent side, RTL-ready designs, gradient borders. Gotchas: border-image ignores border-radius (use a background gradient on a padded wrapper for rounded gradient borders); logical properties need a consistent dir; and per-side colors meet at diagonal joins. See MDN: border-image and MDN: border-inline-start.

Per-side style & color

Style and color for one side (t, r, b, l), widths for a pair of sides (x, y), and a one-class line helper.

ClassCSS
.border-{t|r|b|l}-{solid|dashed|dotted|double|none}border-{side}-style: {style}
.border-{t|r|b|l}-currentborder-{side}-color: currentcolor
.border-{t|r|b|l}-transparentborder-{side}-color: transparent
.border-{t|r|b|l}-lineborder-{side}: 1px solid currentcolor
.border-x-{0|1|2|4|8}border-left-width + border-right-width: {n}px
.border-y-{0|1|2|4|8}border-top-width + border-bottom-width: {n}px

Each box has an 8px solid border in one color (.border-4 .border-solid); one extra class changes the style of a single side. Per-side classes only change that side, so you can combine several of them.

Per side you can also set the color: .border-t-current and .border-t-transparent work like .border-current and .border-transparent on the Border Color page, for one side. The logical classes (.border-s-*, .border-e-*, .border-bs-*, .border-be-*) follow the writing direction; see the RTL example below.

Two sides at once

.border-x-* sets the left and right width, .border-y-* the top and bottom width (0, 1, 2, 4 or 8 px). Set the other pair to 0, because a border style without a width falls back to the browser default (3px).

.border-x-8 .border-y-0
An 8px border on the left and right, none on the other two sides.
left + right8px
.border-y-8 .border-x-0
An 8px border on the top and bottom, none on the other two sides.
top + bottom8px

In practice: lines in a table

.border-{side}-line draws a 1px solid line in the current text color, with a single class. Here the header row gets .border-b-line and the total row .border-t-line; the line follows the text color in light and dark mode.

Logical borders

s/e = inline start/end (left/right in left-to-right text, swapped in right-to-left text), bs/be = block start/end (top/bottom in horizontal text). Both boxes below use exactly the same classes; only the text direction differs.

Per-corner & logical radius

Round a single corner. Unlike the .round-tl* classes on the Border-radius page, these set one corner property each, so you can combine them. Logical corners: ss start-start, se start-end, es end-start, ee end-end; the last box is right-to-left, so start-start is the top-right corner.

ClassCSS
.radius-{tl|tr|bl|br}-{none|sm|md|lg|full}border-{corner}-radius: 0 | .25rem | .5rem | 1rem | 9999px
.round-{ss|se|es|ee}-{none|sm|md|lg|full}border-{start|end}-{start|end}-radius

Border image

Paint the border with an image instead of a color. The image here is a CSS gradient, built from the .from-*/.to-* stops of Gradients: in this one example the gradient is the subject, not decoration. The element needs a border width and style. Note the third box: border-image ignores border-radius, so the corners stay square.

ClassCSS
.border-image-noneborder-image: none
.border-image-gradientborder-image-source: linear-gradient(135deg, from, to); slice: 1
.border-image-stripesborder-image-source: repeating-linear-gradient(45deg, …); slice: 1
.border-image-slice-{1|fill}border-image-slice: 1 | 1 fill
.border-image-repeat-{stretch|repeat|round|space}border-image-repeat
.border-image-width-{1|auto}border-image-width
.border-image-outset-{0|1|2}border-image-outset: 0 | .25rem | .5rem
.border-image-gradient
The border is painted with a gradient from magenta to blue.
gradientmagenta to blue
.border-image-stripes
The border is painted with yellow and black stripes.

The modifier classes change how the border image is drawn. .border-image-repeat-* and .border-image-width-* have no example: with the built-in gradients every value looks the same; they only matter for a border image made from a picture with a pattern at its edges.

.md:border-image-none

Browser support

Per-side and logical borders and border-image are broadly supported.
