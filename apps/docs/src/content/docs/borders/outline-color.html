Outline-color

CSS class _borders_outlines.scss outline-color.html v0.2.0

Outline color sets the colour of the outline. Use .outline-transparent or .outline-current for neutrals; the full palette is available as .outline-{name}-{step} (Omnia/HTML) and .outline-{name} (RAL). Combine with outline width and style. See Colors for the full palette. Values from $outlinecolors and palette generation in _borders_outlines.scss.

What it does: outline-color sets the color of the outline, the line that is drawn around an element outside its border without affecting layout. When to use: focus rings, selection and validation highlights, debug frames. Gotchas: like border an outline needs a style and width to appear (.outline-solid .outline-2); the default color is currentcolor (browsers also draw a default focus ring in the accent color); and the ring must have 3:1 contrast with its surroundings in both color schemes. See MDN: outline-color.

CSS classes

All classes set outline-color. Neutrals: .outline-transparent, .outline-current. Palette: .outline-{name}-{step} (Omnia/HTML), .outline-{name} (RAL). Same naming as on the Colors page.

Outline follows currentcolor and the theme

Like borders, outline colors can use currentcolor, light-dark() and color-mix(). This keeps focus and selection rings visible in both light and dark mode without extra classes.

currentcolor
.outline-current
light-dark()
light-dark(30, 90)
color-mix()
color-mix(… 50%, transparent)
