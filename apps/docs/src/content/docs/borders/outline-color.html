Outline-color

CSS class _borders_outlines.scss outline-color.html v0.2.0

Outline color sets the colour of the outline. Use .outline-transparent or .outline-current for neutrals; the full palette is available as .outline-{name}-{step} (Omnia/HTML) and .outline-{name} (RAL). Combine with outline width and style. See Colors for the full palette. Values from $outlinecolors and palette generation in _borders_outlines.scss.

What it does: outline-color sets the color of the outline, the line that is drawn around an element outside its border without affecting layout. When to use: focus rings, selection and validation highlights, debug frames. Gotchas: like border an outline needs a style and width to appear (.outline-solid .outline-2); the default color is currentcolor (browsers also draw a default focus ring in the accent color); and the ring must have 3:1 contrast with its surroundings in both color schemes. See MDN: outline-color.

CSS classes

All classes set outline-color. Neutrals: .outline-transparent, .outline-current. Palette: .outline-{name}-{step} (Omnia/HTML), .outline-{name} (RAL). Same naming as on the Colors page.

ClassCSS
.outline-transparentoutline-color: transparent
.outline-currentoutline-color: currentColor
.outline-{name}-{step}outline-color: var(--color-{name}-{step}), e.g. .outline-red-60, .outline-teal-50
.outline-{name}-mix-{n}outline-color: the palette color mixed with transparent ({n}% color)
.outline-ral{number}outline-color: var(--color-ral{number}), e.g. .outline-ral9023

transparent first, color on focus

.outline-transparent lets you set up the width, style and offset of a ring in advance and only switch the color on with a variant. Press Tab to move through the buttons: each one shows its own color with focus-visible:. Clicking with the mouse does not show the ring.

.focus-visible:outline-teal-50
The ring is see-through until you reach Save with the Tab key; then it turns teal.
.focus-visible:outline-indigo-40
The ring is see-through until you reach Preview with the Tab key; then it turns indigo.
.focus-visible:outline-red-60
The ring is see-through until you reach Delete with the Tab key; then it turns red.

currentcolor: one class for text and ring

.outline-current uses the text color, so a validation state needs one color class for both. Here the ring is always on, the way a form shows an error after submit. A dark: text color switches the ring too.

no outline
No outline: a normal field.
.outline-current (red text)
The outline takes the red text color: something is wrong.
.outline-current (green text)
The outline takes the green text color: all good.

Theme aware: light-dark() and color-mix()

Outline colors take any CSS color. light-dark() picks a darker ring on light pages and a lighter one on dark pages: switch the site theme to see the first box change. color-mix() softens a palette color without a separate class.

light-dark(…)
Dark ring on light, light ring on dark.
light-dark()dark ring on light, light ring on dark
color-mix(in oklch, …)
50% magenta, 50% background.
color-mix()50% magenta, 50% background
