Border-radius

CSS class _borders_outlines.scss border-radius.html v0.2.0

Border-radius rounds the corners of an element. Use it for cards, buttons, inputs, or any box that should have rounded corners. The scale runs from .round-none (0) via .round-1 … .round-12 (1px–32px) to .round-full (pill or circle). You can style all corners, one side (t, r, b, l), or single corners (tl, tr, bl, br). Values come from $roundsizes in _variables_layout.scss.

What it does: border-radius rounds the corners of an element's box; the radius also clips the background and any content that overflows if overflow is not visible. When to use: cards, buttons, inputs, avatars (.round-full). Pick one or two radii for your design system and use them consistently. Gotchas: a huge radius such as .round-full on a non-square box gives a pill, not an ellipse; nested rounded elements look best when the inner radius equals the outer radius minus the padding; and child images do not get rounded unless the parent has overflow: hidden or the image has its own radius. Combine with corner-shape for bevels and squircles. See MDN: border-radius.

CSS classes

All classes set border-radius. Use .round-none … .round-12 or .round-full for all corners; use .round-t*, .round-r*, .round-b*, .round-l* for one side, or .round-tl*, .round-tr*, .round-bl*, .round-br* for a single corner. The number (1–12) is the size step.

Nested radius: inner = outer minus padding

Left: both boxes use the same radius, so the gap between the curves is uneven. Right: inner radius = outer radius minus the padding, so the border looks even all around.
