Border-style

CSS class _borders_outlines.scss border-style.html v0.2.0

Border style sets how the border line is drawn: solid, dashed, dotted, double, or 3D-like groove, ridge, inset, outset. Use .border-none or .border-hidden when you need no visible border. Always combine with a width class (e.g. .border-2) and optionally a color so the border shows. Values from $borderstyles in _variables_layout.scss.

What it does: border-style sets the line pattern of the border: solid, dashed, dotted, double, the 3D groove/ridge/inset/outset, or none/hidden. It is required: the default style is none, so no border appears without it. When to use: solid for almost everything, dashed for drop zones and placeholders, dotted for subtle separators. Gotchas: hidden wins over a neighbour in collapsed table borders while none loses; dashed and dotted patterns differ slightly between browsers; and the 3D styles depend on the color brightness. See MDN: border-style.

CSS classes

All classes set border-style. Use .border-solid, .border-dashed, .border-dotted, etc. for visible lines; .border-none or .border-hidden to hide the border. Pair with a width (e.g. .border-1) and a color for full control.

Style and width together
