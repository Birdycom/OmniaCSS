Outline & focus ring

CSS class _borders_outlines.scss outline-focus-ring.html v0.2.1

An outline is a line drawn around an element outside its border, without taking up layout space. It is the standard way to show keyboard focus. Combine the .outline-* width, style, color and offset utilities into a visible focus ring. See MDN: outline.

Anatomy of a focus ring

What it does: a focus ring tells keyboard and switch users which element is active. It is made of four independent parts: a width (.outline-2, 4px), a style (.outline-solid), a color (.outline-royalblue-50 or any Omnia color) and a gap (.outline-offset-1, 2px). When to use: on every interactive element, shown only for keyboard focus with :focus-visible. Gotchas: never remove the outline (outline: none) without a visible replacement; a 3:1 contrast against the surrounding background is the WCAG minimum for the indicator; the outline follows border-radius in current browsers but not in older ones; and because it takes no space, neighbouring elements may overlap it. Add the focus-visible: variant to each class so the ring only shows for keyboard focus.

PartClasses
Width.outline-none, .outline-1 … .outline-12
Style.outline-solid, .outline-dashed, .outline-dotted, .outline-double …
Color.outline-{palette}-{step}, .outline-current, .outline-transparent
Offset.outline-offset-none, .outline-offset-1 … .outline-offset-12
Forced-colors safe.outline-hidden (2px transparent outline: invisible normally, visible in Windows high contrast mode)

focus vs focus-visible

focus: shows the ring whenever the element has focus, also after a mouse click. focus-visible: lets the browser decide: a ring for the keyboard, none for a mouse click on a button (text inputs always get one, because you type in them). Click both buttons with the mouse, then Tab to them. Safari on macOS does not focus buttons on click at all, so there neither shows a ring after a click.

Ring recipes

Six common rings, always on here so you can compare them. Every ring is built from the four parts in the table above: width, style, color and offset. The inset ring uses a negative offset (inline), which keeps it inside elements that sit against a clipping edge.

A ring that follows the shape

Outlines follow border-radius, so the same classes hug a pill, a circle and a card. With corner-shape (Chrome and Edge 139+) the ring follows a bevel too. These four are real controls: Tab to them to see the ring.

Not in this browser yet. Your browser does not support corner-shape: the last button keeps round corners, so its ring is round too.
