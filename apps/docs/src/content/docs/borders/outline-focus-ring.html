Outline & focus ring

CSS class _borders_outlines.scss outline-focus-ring.html v0.2.1

An outline is a line drawn around an element outside its border, without taking up layout space. It is the standard way to show keyboard focus. Combine the .outline-* width, style, color and offset utilities into a visible focus ring. See MDN: outline.

Anatomy of a focus ring

What it does: a focus ring tells keyboard and switch users which element is active. It is made of four independent parts: a width (.outline-2), a style (.outline-solid), a color (.outline-dodgerblue-50 or any Omnia color) and a gap (.outline-offset-2). When to use: on every interactive element, shown only for keyboard focus with :focus-visible. Gotchas: never remove the outline (outline: none) without a visible replacement; a 3:1 contrast against the surrounding background is the WCAG minimum for the indicator; the outline follows border-radius in current browsers but not in older ones; and because it takes no space, neighbouring elements may overlap it. The classes below are always on so you can see the result.

Show it only on keyboard focus

:focus also matches mouse clicks; :focus-visible only matches when the browser decides a ring helps (keyboard, programmatic focus on inputs). Press Tab to move through the buttons below and click one with the mouse to compare: only keyboard focus draws a ring. The rule behind it is plain CSS: button:focus-visible { outline: 2px solid var(--oc-ring); outline-offset: 2px; }.

A link
button:focus-visible { outline: 2px solid var(--oc-ring); outline-offset: 2px; } /* inset ring: negative offset keeps it inside the box */ .inset:focus-visible { outline-offset: -3px; }

Ring that follows the shape

Outlines follow border-radius, so the same ring hugs a pill, a circle or a rounded card. With the newer corner-shape the ring follows the bevel, notch or squircle too in browsers that support it.
