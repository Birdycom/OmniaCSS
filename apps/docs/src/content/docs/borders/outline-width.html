Outline-width

CSS class _borders_outlines.scss outline-width.html v0.2.0

An outline is a line drawn outside the element’s border; it does not affect layout or box size. Often used for focus rings (accessibility). This section covers outline width (.outline-none … .outline-12). Combine with an outline style (e.g. .outline-solid) and a color so the outline is visible. Values from $outlinesizes in _variables_layout.scss.

What it does: outline-width sets the thickness of the outline. The classes (.outline-1 = 0.125rem … .outline-12 = 2rem) are rem based and the outline never takes up layout space. When to use: 2px for focus rings (WCAG recommends at least 2 CSS pixels), thicker for selection frames. Gotchas: the width alone draws nothing: add a style (.outline-solid); an outline can overlap or be clipped by parents with overflow: hidden; and because it is not part of the box, it is not affected by box-sizing. See MDN: outline-width.

The width scale

An outline is drawn outside the border and takes no space, so it never moves anything around it. Each box below has the same thin grey border and a red outline; only the width class changes. The outline needs a style (.outline-solid) and a color to show. .outline-none (0) is left out because there is nothing to see.

Every number from .outline-1 (2px) to .outline-12 exists; the example shows the main steps. .outline-none sets the width to 0: nothing to show.

Outline vs border: no extra space

Both rows have four equal chips with an 8px gap. In the top row the second chip gets an 8px border: with box-sizing: border-box the chip keeps its size, but its content area shrinks by 16px. In the bottom row the second chip gets an 8px outline: the content keeps its full size and the ring is painted over the gap, right up to the neighbours. Nothing moves either way, but only the outline leaves the box alone.

In practice: the selected photo

A thick outline is a good "selected" mark: switching it on does not shift the grid. Click a photo, or Tab to the group and use the arrow keys. Every thumbnail has a transparent 4px outline; the checked one gets a color with has-[:checked]:, and keyboard focus adds a dashed style.

.outline-2 .has-[:checked]:outline-crimson-50
Click a photo or use the arrow keys: the picked one gets a red outline, the others keep a see-through one.
