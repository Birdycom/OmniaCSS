Outline-width

CSS class _borders_outlines.scss outline-width.html v0.2.0

An outline is a line drawn outside the element’s border; it does not affect layout or box size. Often used for focus rings (accessibility). This section covers outline width (.outline-none … .outline-12). Combine with an outline style (e.g. .outline-solid) and a color so the outline is visible. Values from $outlinesizes in _variables_layout.scss.

What it does: outline-width sets the thickness of the outline. The classes (.outline-1 = 0.125rem … .outline-12 = 2rem) are rem based and the outline never takes up layout space. When to use: 2px for focus rings (WCAG recommends at least 2 CSS pixels), thicker for selection frames. Gotchas: the width alone draws nothing: add a style (.outline-solid); an outline can overlap or be clipped by parents with overflow: hidden; and because it is not part of the box, it is not affected by box-sizing. See MDN: outline-width.
