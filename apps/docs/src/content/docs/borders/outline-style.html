Outline-style

CSS class _borders_outlines.scss outline-style.html v0.2.0

Outline style sets how the outline is drawn: solid, dashed, dotted, double, or 3D-like options. Use .outline-none for no outline, or .outline-hidden for an invisible outline that keeps focus behaviour (2px solid transparent). Combine with outline width and color. Values from $outlinestyles in _variables_layout.scss.

What it does: outline-style chooses the line pattern of an outline (same keywords as border-style, but hidden is not valid). When to use: solid for focus rings, dashed for drop targets. Gotchas: the default style is none; .outline-hidden in OmniaCSS is a transparent 2px outline so that it stays visible in Windows forced-colors (high contrast) mode, unlike outline: none; outline styles other than solid may render slightly differently across browsers. See MDN: outline-style.

CSS classes

All classes set outline-style. Use .outline-solid, .outline-dashed, .outline-dotted, etc. Pair with an outline width (e.g. .outline-2) and a color. .outline-hidden uses a transparent outline for accessibility.

Outline vs border: no layout shift

Toggling a 6px border on hover pushes the neighbours (the left card grows), while a 6px outline is drawn on top and nothing moves. This is why outlines are the right tool for focus and hover indications. Hover each card and watch its neighbour.

neighbour

.outline-solid: stays put
.tile { border: 0 solid; } .tile:hover { border-width: 6px; } /* shifts layout */ .tile { outline: 0 solid; } .tile:hover { outline-width: 6px; } /* does not */
