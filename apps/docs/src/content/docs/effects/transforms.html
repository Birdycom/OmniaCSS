Scale & Rotate

_motion_transforms.scss v0.4.0

Resize and rotate elements with .scale-{n} and .rotate-{deg}. They use the individual CSS properties scale and rotate, so each class works on its own and classes combine freely (no extra .transform class needed). The dashed outline shows the original position.

What it does: scale grows or shrinks an element and rotate turns it, both around the transform-origin (the center by default, change it with .origin-*). When to use: hover and focus feedback, icons, decorative tilts. Gotchas: transforms do not change layout (neighbours do not move and the original space stays reserved), they create a stacking context, and scaling text can make it blurry. These classes use the individual scale and rotate properties, so they combine without overriding each other. See MDN: scale, MDN: rotate and MDN: transform-origin.

Translate & Skew

Move elements with .translate-x-{n} / .translate-y-{n} (CSS translate; x and y combine) and tilt them with .skew-x-{deg} / .skew-y-{deg}. Translating never changes the layout: the space of the original box stays reserved.

What it does: translate moves an element along x and/or y without touching the layout; skew slants it. When to use: slide-in effects, hover lifts, parallelogram buttons. Gotchas: percentages (.translate-x-full) are relative to the element's own size, not its parent; skew has no individual CSS property yet, so .skew-x-* and .skew-y-* set transform and replace each other. See MDN: translate and MDN: skew().

3D Transforms

_motion_transforms.scss

Depth with .perspective-*, .transform-3d and .backface-hidden.

What it does: perspective on a parent sets how strongly its children recede into the screen (smaller value = stronger effect); transform-style: preserve-3d (.transform-3d) lets nested children keep their own depth; backface-visibility: hidden hides an element once it is turned away from you. When to use: flip cards, tilt-on-hover, product spins. Gotchas: perspective goes on the parent of the rotating element, overflow and filter on the parent flatten the 3D scene, and rotation about x or y needs the individual rotate: y 40deg syntax (or transform: rotateY()) since .rotate-* only turns around z. See MDN: perspective and MDN: backface-visibility.
