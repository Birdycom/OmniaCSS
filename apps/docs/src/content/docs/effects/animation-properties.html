Animation Properties & Motion Path

CSS class _animation_properties.scss animation-properties.html v0.3.0

Control every part of an animation separately (duration, delay, iterations, direction, fill mode, play state, composition), use modern easing with linear() and steps(), move elements along a path with offset-*, and rotate with the individual rotate property. The ready-made animations (.animate-spin, …) are on the Animations page. See MDN: animation.

Animation longhands

Combine them with an animation name: .animate-name-* for the four built-in keyframes, or your own animation-name. The races below use a keyframes rule of their own that moves a dot from the start to the end of its track; every other part of the animation comes from the utility classes. Press Play above a race to start it and Replay to see it again (the buttons are checkboxes, so no script is needed). Reduced motion: OmniaCSS then shortens every animation to 0.01ms and one cycle, so the dots jump straight to the finish.

Fill mode decides where an element is before its animation starts (during the delay) and after it ends. Every dot sits at the left of its track; its keyframes start at the dashed ring and end at the finish. Each lane waits 1 s (.animate-delay-1000) and then runs 2 s. Press Play and watch steps 1 and 3: backwards and both jump to the ring during the wait; forwards and both stay at the finish afterwards; none does neither.

Composition: both balls have .translate-x-12 (moved 3rem right; the dashed circle marks that spot) and run keyframes that only say "halfway, be 2.5rem up". With .animate-compose-replace the keyframe value replaces the 3rem, so the ball also drifts back to the left; with .animate-compose-add the hop is added on top and the ball stays above its spot.

Easing functions

linear() approximates springs and bounces with many points; steps() jumps between frames. .animate-ease-* for animations, .ease-* for transitions.

Motion path

Move an element along a path (offset-path) and set its position on that path (offset-distance). .animate-follow-path animates the distance from 0% to 100% and back.

Rotate property & transform-box

The individual rotate property works independently of transform, so it does not overwrite translate/scale utilities. transform-box sets the reference box for transform-origin (useful in SVG).

ClassCSS
.rotate-prop-{0|45|90|180|n45|n90}rotate: {n}deg (n = negative)
.rotate-prop-x-180 / .rotate-prop-y-180rotate: x 180deg | y 180deg
.transform-box-{content|border|fill|stroke|view}transform-box: content-box / border-box / fill-box / stroke-box / view-box

The dashed outline is the box before rotation. The letter shows the turn: with .rotate-prop-x-180 it is flipped upside down, with .rotate-prop-y-180 mirrored.

Browser support

Animation longhands and the rotate property are broadly supported; linear() easing and animation-composition need a recent browser, older ones fall back to linear timing.
