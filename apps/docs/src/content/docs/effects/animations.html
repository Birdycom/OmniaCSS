Keyframe Animations

_motion_transforms.scss v0.2.0

Standard motion patterns for loaders, notifications, and interaction feedback.

What it does: the .animate-* classes start a ready-made @keyframes animation: spin rotates forever (loaders), ping scales and fades out (notification dots), pulse breathes the opacity (skeletons) and bounce hops vertically (scroll hints). When to use: status feedback and loading states, not decoration. Gotchas: infinite animations are distracting and costly, so use them sparingly and honour prefers-reduced-motion (turn them off with .motion-reduce:animate-none or a media query); animations of transform and opacity are cheapest. For custom timing, delays and fill modes see Animation Properties. See MDN: animation.

ClassMotion Pattern
.animate-spinContinuous rotation
.animate-pingScaling pulse effect
