Opacity

_effects.scss v0.2.0

Control the transparency of an element with .opacity-{value}.

What it does: opacity makes an element and everything inside it partially transparent (0 invisible, 1 solid). When to use: disabled states, hover fades, dimmed secondary content, fade-in/out transitions. Gotchas: children cannot be more opaque than their parent, an opacity below 1 creates a stacking context, and an element at opacity-0 is still clickable and focusable: add visibility: hidden or inert if it should disappear for good. To make only the background see-through, use a translucent color (oklch(from var(--oc-primary) l c h / 0.5) or color-mix()) instead. See MDN: opacity.

Opacity vs a translucent color

Left: .opacity-50 fades the whole box, including its text. Right: only the background color is made translucent with relative color syntax, so the text stays fully readable. Both sit on a striped backdrop.

opacity-50: text fades too
background alpha 0.5: text stays crisp
<div class="opacity-50">whole element</div> <div style="background: oklch(from var(--oc-primary) l c h / 0.5)">background only</div>
