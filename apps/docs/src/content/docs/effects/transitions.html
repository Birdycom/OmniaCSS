Transitions

_motion_transforms.scss v0.4.0

Animate the change between two states (for example normal → :hover) with .transition-{property}, .duration-{ms}, .ease-{curve} and .delay-{ms}. Nothing moves until a value changes: every demo below reacts when you hover it (or focus it with the keyboard).

What it does: a transition animates a property from its old to its new value when it changes, instead of switching instantly. You choose which property (.transition-*), how long (.duration-*), how it accelerates (.ease-*) and when it starts (.delay-*). When to use: hover, focus and state changes: color, opacity, shadow, transform. Gotchas: put the transition classes on the base state, not only on :hover, or the way back is instant; transition-all is convenient but animates everything (including layout properties); display and height: auto do not animate without transition-behavior: allow-discrete / interpolate-size; and honour prefers-reduced-motion. See MDN: transition.

Timing & easing

The easing curve controls acceleration: same distance, same duration (.duration-1000), different curve. .ease-spring and .ease-bounce use the CSS linear() function, .ease-steps-4 jumps in four steps.

ClassCSS
.ease-lineartransition-timing-function: linear
.ease-intransition-timing-function: cubic-bezier(0.4, 0, 1, 1)
.ease-outtransition-timing-function: cubic-bezier(0, 0, 0.2, 1)
.ease-in-outtransition-timing-function: cubic-bezier(0.4, 0, 0.2, 1)
.ease-spring / .ease-bouncetransition-timing-function: linear(…) — overshoot / bounce
.ease-steps-4transition-timing-function: steps(4, end)

Animate a custom property for gradients

Gradients cannot transition, but @property turns a custom property into an animatable angle. Hover or focus the tile; the ring fills smoothly with a transition on --p. This pattern works for any value the browser can interpolate once it knows the type.

Hover or focus the ring
@property --p { syntax: "<number>"; inherits: false; initial-value: 0; } .ring { background: conic-gradient(var(--color) calc(var(--p) * 1%), transparent 0); transition: --p 1s; } .ring:hover { --p: 75; }
