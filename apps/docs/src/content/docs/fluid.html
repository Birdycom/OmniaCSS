Fluid values (clamp, min, max)

Use CSS clamp(), min(), and max() for responsive values without media queries: font-size and width scale with the viewport and stay within bounds. The next step, progress(), and the other math functions are on CSS Functions.

clamp(), min(), and max() v0.2.0

min() returns the smallest of its arguments; max() the largest. clamp(MIN, VAL, MAX) is equivalent to max(MIN, min(VAL, MAX)). The preferred value (VAL) is often viewport-relative (e.g. 7vw + 1rem).

MDN: clamp() · MDN: min() · MDN: max()

Function Meaning
min(A, B, …)Smallest value. Use to cap (e.g. width at most 65ch).
max(A, B, …)Largest value. Use to set a minimum (e.g. font-size at least 1rem).
clamp(MIN, VAL, MAX)VAL clamped between MIN and MAX.

min() and max() v0.2.0

Use min() / max() on width for the same effect as width + min-width/max-width. Same idea for padding and margin. Override fluid-cap/floor with CSS variables: style="--w-cap-a: 40vw; --w-cap-b: 50ch". For fixed widths use generated classes like w-50vw, w-65ch (see _clamp.scss).
