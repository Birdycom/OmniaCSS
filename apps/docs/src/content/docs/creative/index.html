Creative CSS

Showcase _css_functions.scss creative/index.html v0.8.2

Effects people usually reach for JavaScript or images to build, made with CSS and the Omnia tokens only: animated gradient borders (@property), neon buttons, 3D flip cards, glassmorphism, text fills, typing and wave text, clip-path reveals, a scroll-driven reading bar, a theme switch with :has(), retro 3D type and loaders. Every effect respects prefers-reduced-motion. Copy the CSS next to your utilities; all colors are var(--color-*) tokens.

Animated glowing border

A registered --cr-angle rotates a conic gradient in the border box; a blurred copy in ::before is the glow, and ::after paints the card face over it, so only a ring and its glow remain.

Glowing border
@property --cr-angle { syntax: "<angle>"; inherits: true; initial-value: 0deg; } .cr-glow { --cr-ring: conic-gradient(from var(--cr-angle), var(--color-vividblue-80), var(--color-magenta-50), var(--color-orange-50), var(--color-teal-50), var(--color-vividblue-80)); position: relative; isolation: isolate; border: 3px solid transparent; border-radius: 18px; background: var(--cr-ring) border-box; /* the ring */ animation: cr-spin 4s linear infinite; } .cr-glow::before { /* the glow, painted first */ content: ""; position: absolute; inset: -3px; z-index: -1; border-radius: inherit; background: var(--cr-ring); filter: blur(1.5rem); opacity: 0.75; } .cr-glow::after { /* the card face, painted over the glow */ content: ""; position: absolute; inset: 0; z-index: -1; border-radius: 15px; background: var(--color-black-30); } @keyframes cr-spin { to { --cr-angle: 360deg; } }

Neon button

A ::before layer scales in from the left; layered box-shadows with a relative-alpha token make the glow. Works for hover and keyboard focus.

.cr-neon { position: relative; isolation: isolate; overflow: hidden; border: 2px solid var(--color-skycyan-50); color: var(--color-skycyan-50); transition: color 0.4s, box-shadow 0.4s; } .cr-neon::before { content: ""; position: absolute; inset: 0; z-index: -1; background: var(--color-skycyan-50); scale: 0 1; transform-origin: left; transition: scale 0.4s; } .cr-neon:is(:hover, :focus-visible) { color: var(--color-black-40); box-shadow: 0 0 0.6rem var(--color-skycyan-50), 0 0 2.5rem var(--color-skycyan-50), 0 0 5rem oklch(from var(--color-skycyan-50) l c h / 0.5); } .cr-neon:is(:hover, :focus-visible)::before { scale: 1 1; }

Wave text with sibling-index()

One animation, and the OmniaCSS .animate-delay-stagger utility gives every letter its own delay from its position. No nth-child list, no inline styles.

OMNIACSS

<p class="cr-wave" aria-label="OMNIACSS"> <span class="animate-delay-stagger stagger-100" aria-hidden="true">O</span> <span class="animate-delay-stagger stagger-100" aria-hidden="true">M</span> … </p> <style> .cr-wave span { animation: cr-jump 1.4s ease-in-out infinite; } @keyframes cr-jump { 0%, 40%, 100% { translate: 0 0; } 20% { translate: 0 -0.35em; color: var(--color-magenta-50); } } </style>

Scroll-driven reading progress

The bar is driven by animation-timeline: scroll(), not by time. Scroll the text box. More on Scroll animations.

Scroll this box. The bar at the top grows from 0 to 100% while you read.

It is a normal @keyframes animation, but its progress comes from the scroll position of the nearest scroll container instead of a clock.

On a real page use scroll(root) on a fixed bar at the top of the viewport.

Browsers without scroll-driven animations simply do not show the bar.

No scroll listeners, no requestAnimationFrame, and it runs off the main thread.

End of the article.

.cr-read-bar { position: sticky; top: 0; block-size: 5px; transform-origin: left; scale: 0 1; background: linear-gradient(90deg, var(--color-vividblue-80), var(--color-magenta-50)); animation: cr-grow linear both; animation-timeline: scroll(nearest block); /* page: scroll(root) */ } @keyframes cr-grow { to { scale: 1 1; } }

Day/night switch with :has()

A real checkbox with appearance: none; its ::before is the thumb. The panel switches theme through :has(.cr-switch:checked).

Toggle day and night
.cr-switch { appearance: none; position: relative; inline-size: 4rem; block-size: 2.1rem; border-radius: 999px; background: var(--color-mistblue-30); } .cr-switch::before { content: "☀"; position: absolute; inset: 0.2rem auto 0.2rem 0.2rem; inline-size: 1.7rem; border-radius: 50%; background: var(--color-white-50); transition: translate 0.4s cubic-bezier(0.3, 1.5, 0.5, 1); } .cr-switch:checked { background: var(--color-indigo-60); } .cr-switch:checked::before { content: "☾"; translate: 1.9rem 0; } .cr-switch-stage:has(.cr-switch:checked) { background: var(--color-black-40); color: var(--color-white-60); }

Loaders

A conic gradient masked into a ring, and pulsing dots whose delay comes from sibling-index().

.cr-loader { inline-size: 4.5rem; aspect-ratio: 1; border-radius: 50%; background: conic-gradient(from 0deg, transparent 10%, var(--color-skycyan-50)); mask: radial-gradient(farthest-side, transparent calc(100% - 0.5rem), var(--color-black-50) calc(100% - 0.45rem)); animation: cr-rot 1s linear infinite; } .cr-dots i { animation: cr-pulse 1s ease-in-out infinite; animation-delay: calc((sibling-index() - 1) * 150ms); } /* = .animate-delay-stagger .stagger-150 */ @keyframes cr-rot { to { rotate: 1turn; } } @keyframes cr-pulse { 0%, 100% { scale: 0.5; opacity: 0.4; } 50% { scale: 1.1; opacity: 1; } }

Browser support

Everything here works in current browsers. Scroll-driven animations are missing in older Firefox and Safari versions (the bar is then hidden); sibling-index() falls back to no delay.
