Pagination

CSS class variants.mjs pagination/index.html v0.8.2

Pagination splits content over pages. For the links, mark the current page with aria-current="page" and style it with the aria-[current=page]: variant, so the visual state and the accessible state can never disagree. Newer CSS can even generate the page buttons (::scroll-marker), and @page paginates printed documents. See MDN: aria-current.

Markup and classes

Use a <nav aria-label="Pagination"> with a list of links. The current page gets aria-current="page", unavailable links aria-disabled="true" (and no href).

Pagination styles

Hover a number, or press Tab to move the focus ring along the links. Every link carries the same classes; only the current one has aria-current="page", and the aria-[current=page]: classes color it. In your own project the server sets that attribute on each page, so the links in this demo do not go anywhere.

Breadcrumbs

The separators are generated with ::after, so screen readers only read the links; the last item is the current page.

.crumbs li:not(:last-child)::after
Each slash is drawn by CSS after a link, not typed in the HTML. The last item is the page you are on. The links in this demo stay on this page; hover them to see the underline.
  1. Home
  2. Products
  3. Product 1
  4. Reviews
<style> .crumbs { display: flex; flex-wrap: wrap; list-style: none; margin: 0; padding: 0; } .crumbs li:not(:last-child)::after { content: "/"; margin-inline: 0.6rem; color: var(--oc-muted-foreground); } .crumbs a { text-decoration: none; } .crumbs a:hover { text-decoration: underline; } .crumbs [aria-current="page"] { color: var(--oc-muted-foreground); } </style> <nav aria-label="Breadcrumb"> <ol class="crumbs"> <li><a href="/">Home</a></li> <li><a href="/products">Products</a></li> <li><a href="/products/product-1">Product 1</a></li> <li><span aria-current="page">Reviews</span></li> </ol> </nav>

Page buttons generated by CSS: ::scroll-marker

Put the pages in a horizontal snap container and let CSS create one marker per page. content: attr(data-page) turns the markers into numbered buttons, :target-current highlights the visible page. The browser handles clicks, keyboard arrows and the accessible tab roles — no JavaScript.

Not in this browser yet. Your browser does not draw scroll markers: the numbers are missing, but you can still scroll or swipe from page to page.

Print pagination: @page and page breaks

For printed pages, @page margin boxes add page numbers and .break-* utilities decide where a new page starts. Use the print: variant to hide navigation when printing. These rules only show in a print preview (Ctrl+P), not on screen, so this part has a code sample and no live demo.

@page { size: A4; margin: 2cm; @bottom-right { content: "Page " counter(page) " / " counter(pages); } } /* <h2 class="break-before-page">Chapter 2</h2> <figure class="break-inside-avoid">…</figure> <nav class="print:d-none">…</nav> */

Browser support

Link-based pagination works everywhere. ::scroll-marker pagination is Chromium-only for now; @page margin boxes need Chrome 131 or Firefox 146.
