Text Transform

CSS class _text.scss text-transform.html v0.2.0

Utilities for controlling the capitalization of text.

ClassValue
.uppercasetext-transform: uppercase (all capitals)
.lowercasetext-transform: lowercase (no capitals)
.capitalizetext-transform: capitalize (first letter of each word)
.normalcasetext-transform: none (the text as written)

One text, four results

Every row has the same HTML text: order SHIPPED to customer 1. Only the class changes what you see; the text itself, for example for copy and paste or search engines, stays as written.

.capitalize
