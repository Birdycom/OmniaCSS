Emoji and math

Fonts for symbols rather than words. .font-emoji draws emoji as plain shapes in the text color; .font-coloremoji draws them in full color.

.font-emoji
One color: the emoji take the text color, like letters.

😀🚀📦✅

.font-coloremoji
Full color. Uses Noto Color Emoji when it is installed, otherwise the system emoji.

😀🚀📦✅

.font-math
Symbols for formulas, such as sums, integrals and Greek letters.

∑∫√π≈∞

<p class="font-emoji">😀🚀📦✅</p> <p class="font-coloremoji">😀🚀📦✅</p> <p class="font-math">∑∫√π≈∞</p>

Other writing systems

Two classes are for text that is not written in Latin letters. The name .font-fangsong is a little misleading: fangsong is a Chinese brush style, but the class asks first for Noto Serif JP, a Japanese font. Use it for Japanese text; the browser's own fangsong font is only the last fallback.

.font-fangsong
“Japanese text”. This docs site does not download the Japanese font (it is very large), so you see it here only when your device has it; otherwise your system shows its own Japanese font.

日本語の文章

.font-hieroglyphs
Ancient Egyptian signs (Unicode U+13000 and up). The font is used only when it is installed on the device.

𓀀 𓁐 𓃒 𓆣 𓋹
