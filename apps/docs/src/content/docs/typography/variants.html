Font Variants & Text Effects

CSS class _font_variants.scss variants.html v0.3.0

OpenType features (small caps, ligatures, sub/superscript glyphs, emoji presentation), variable font axes, fallback-font tuning with font-size-adjust, hyphenation details, text stroke/fill effects, ruby annotations and MathML styles. Numeric variants are .font-num-* on the Font Style page. See MDN: font-variant.

Variable fonts & size adjust

font-variation-settings sets variable font axes directly — it only has effect with a variable font (the demo uses Roboto Flex, which OmniaCSS loads as a variable font with a weight axis from 100 to 1000). font-size-adjust keeps the x-height equal when a fallback font is used.

Ruby & MathML

Ruby puts a small note above or below a word with <ruby> and <rt>. It comes from Chinese and Japanese, where the note shows how to read a character; in English you can use it for a pronunciation hint or a translation. The math classes switch a MathML formula between its large display size and the compact size used inside a line of text.

ClassCSS
.ruby-{over|under|inter-character}ruby-position
.ruby-align-{start|center|space-between|space-around}ruby-align
.ruby-overhang-{auto|none}ruby-overhang
.math-{normal|compact}math-style
.math-depth-{auto|0}math-depth: auto-add | 0
.math-shift-{normal|compact}math-shift

Unsupported font features are ignored and the default glyphs are shown.
