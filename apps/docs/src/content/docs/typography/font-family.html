Font Family

CSS class _fonts.scss font-family.html v0.2.0

Set the typeface of an element with one class. Each class sets a font-family stack: a list of fonts, of which the browser uses the first one it has. To see every font at full size, open the Font Catalog; to learn which fonts are downloaded and how, read Loading Fonts.

Using the classes

A font family is inherited: put the class on a parent and every child uses it, then give single elements their own class. Combine it with a size and a weight class. The two cards below hold the same content; only the font classes differ.

.font-fantasy .font-source .font-monospace
The heading in .font-fantasy, the text in .font-source and the code line in .font-monospace.
