Loading Fonts

CSS class _fonts.scss fonts.html v0.2.0

Where the fonts behind the Font Family classes come from, what omnia.css downloads, and how to host the fonts yourself. To see the fonts, open the Font Catalog.

Three kinds of fonts

Every font class falls in one of three groups. Only the first group causes a download.

Where the font comes fromClasses
Google Fonts
Downloaded from Google Fonts through one @import at the top of omnia.css.		.font-roboto .font-source .font-cursive .font-fantasy .font-emoji .font-math .font-fangsong
Installed on the device
Nothing is downloaded. The stack names fonts that almost every computer and phone already has.		.font-serif .font-sansserif .font-monospace
Only if installed
An @font-face rule with local(): the font is used when the device has it, otherwise the next font in the stack.		.font-coloremoji .font-hieroglyphs

What omnia.css and the on-demand build load

The full omnia.css starts with one Google Fonts @import for all eight web fonts. The on-demand build (PostCSS @omnia; or the engine) is smarter: it keeps only the families your classes use, and drops the import when you use none.

/* Top of omnia.css (shortened) */ @import url("https://fonts.googleapis.com/css2?family=Cedarville+Cursive&family=Cormorant+Infant…&family=Roboto+Flex…&display=swap"); /* On-demand build, page uses only .font-roboto: */ @import url("https://fonts.googleapis.com/css2?family=Roboto+Flex:opsz,wght@8..144,100…&display=swap");

Why loading matters

When a font is missing, the browser moves down the stack and uses the next font it has. The left tile uses .font-cursive with Cedarville Cursive loaded; the right tile shows what a visitor gets without it: the browser's own cursive font, which differs per device.

Hosting the fonts yourself

The Google import sends each visitor's IP address to Google. To avoid that, download the font files, serve them from your own server and declare them with @font-face under the same family name. The classes keep working, because they only refer to the name. Remove the Google @import from your copy of the CSS (or use the on-demand build without font classes). This docs site does exactly that.

/* Your own CSS, loaded before omnia.css */ @font-face { font-family: "Roboto Flex"; src: url("/fonts/roboto-flex.woff2") format("woff2"); font-weight: 100 1000; font-display: swap; }
