Typography

v0.2.0

Core utilities for controlling font styles, text alignment, and advanced typographic features.

The Typography module provides a comprehensive suite of utilities for handling everything from basic font sizing to advanced layout concerns like line-clamping and truncation.

Source & Further Reading

The typography utilities come from five SCSS partials in src/scss/utilities/. See MDN: font and MDN: text-wrap.

SCSS source

FileContains
src/scss/utilities/_fonts.scssFont family, size, style and weight
src/scss/utilities/_text.scssText align, decoration, transform, letter spacing, line height
src/scss/utilities/_typography_advanced.scsstext-wrap, line clamp, truncation, font smoothing, hyphens
src/scss/utilities/_typography_modern.scsstext-box trimming, initial letters, emphasis marks, whitespace collapsing, kerning
src/scss/utilities/_font_variants.scssFont variants, variable font axes, font-size-adjust, text stroke and fill, ruby

Compiled output

Run npm run build to compile the SCSS; all classes end up in public/css/omnia_main.css.
