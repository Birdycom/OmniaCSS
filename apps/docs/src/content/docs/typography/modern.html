Modern Typography

CSS class _typography_modern.scss modern.html v0.3.0

Newer typography features: trim the extra space above and below text with text-box, drop caps with initial-letter, emphasis marks, CJK spacing control and font rendering switches. These complement the Advanced utilities (line clamp, text-wrap, hyphens). See MDN: text-box.

Text box trim

Removes the half-leading above the cap height and below the baseline, so text is optically centered in buttons and badges.

.text-box-trim-endtext-box-trim: trim-end; text-box-edge: cap alphabetic
.text-box-trim-extext-box: trim-both ex alphabetic

Text wrap style & white space

.text-stable keeps earlier lines stable while the user edits text. The white-space-collapse classes control space collapsing independently of wrapping (.text-balance, .text-pretty live in Advanced).

Initial letter

Drop caps on the first letter of a paragraph. .initial-letter-3-2 = 3 lines tall, sunk 2 lines.

ClassCSS
.initial-letter-normal::first-letter { initial-letter: normal }
.initial-letter-2::first-letter { initial-letter: 2 }
.initial-letter-3::first-letter { initial-letter: 3 }
.initial-letter-3-2::first-letter { initial-letter: 3 2 }

Browser support

Every class is a progressive enhancement: unsupported browsers ignore it and render the default typography.
