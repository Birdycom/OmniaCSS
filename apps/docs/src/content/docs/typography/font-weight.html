Utilities for controlling the font weight (thickness) of text.

ClassValue
.font-thinfont-weight: 100
.font-extralightfont-weight: 200
.font-lightfont-weight: 300
.font-normalfont-weight: 400
.font-mediumfont-weight: 500
.font-semiboldfont-weight: 600
.font-boldfont-weight: 700
.font-extraboldfont-weight: 800
.font-blackfont-weight: 900
.font-extrablackfont-weight: 1000

.font-normal also sets font-style: normal; see Font Style.

All weights

A font only shows the weights it has. This demo uses .font-roboto (Roboto Flex), a variable font with every weight from 100 to 1000, so each row really is a step thicker. With a font that has only regular and bold, the browser rounds to the nearest weight it has.
