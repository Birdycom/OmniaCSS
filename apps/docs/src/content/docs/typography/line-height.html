Relative line heights

These classes multiply the font size, so the spacing stays right when the text gets bigger or smaller. Read the same paragraph in each tile, from the closest lines to the widest: tight lines feel crowded, loose lines feel airy. For body text, .lineheight-relaxed or a value near 1.5 reads best.

Line height 1: the lines almost touch. Only for big headings.

Fixed line heights

The numbered classes set a fixed height in rem, whatever the font size. Use them to line up text with icons or form fields. Watch out: a fixed height that is smaller than the font makes lines overlap. All three tiles use 2rem text: 1.5rem lines overlap, 2rem lines touch, 2.5rem lines read well.

.font-2 .lineheight-1.5
Lines of 1.5rem on 2rem text: the lines overlap.

.font-2 .lineheight-2
Lines exactly as high as the text: they touch.

Lines of 2.5rem: room to breathe.
