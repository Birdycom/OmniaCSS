Scroll Behavior

What: scroll-behavior: smooth animates jumps caused by anchor links and scrollTo(). When: in-page navigation. Gotchas: set it on the scroll container (often html), not on every element; wrap it in a prefers-reduced-motion: no-preference query for motion-sensitive users; sticky headers need scroll-margin-top on the targets so they do not hide the heading. More: MDN: scroll-behavior.

Scroll Snap

What: the scroller (scroll-snap-type) decides the axis and strictness, each child (scroll-snap-align) says where it wants to rest. When: carousels, galleries, onboarding steps, full-page sections. Gotchas: mandatory can trap users when an item is taller than the scrollport, so prefer proximity for long content; add scroll-padding to compensate for sticky bars. More: MDN: scroll-snap-type.

Scroll Markers (CSS carousels)

Generates a group of navigation dots for a scroll container. Each child gets a ::scroll-marker you can style; combine with .snap-x and .overflow-x-auto for a CSS-only carousel. Gotcha: Chromium only for now; without support the container is a plain scroll-snap list, which is a fine fallback. More: MDN: ::scroll-marker.

Touch Action

What: tells the browser which touch gestures it may handle. When: pan-y on a horizontal slider so vertical page scrolling still works, none on custom drawing surfaces, manipulation to remove the double-tap-to-zoom delay on buttons. Gotcha: restricting gestures can block zoom and scroll for users, so scope it to the element that needs it. More: MDN: touch-action.

Scroll Anchoring & Print Color

Disable scroll anchoring for feeds that should not jump, and force backgrounds and colors to print exactly (badges, charts). What: scroll anchoring keeps the visible content steady when content above it loads. Opt out only where it fights your own scroll logic. More: MDN: overflow-anchor.
