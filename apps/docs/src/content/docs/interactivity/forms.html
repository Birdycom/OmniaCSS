Accent Color, Appearance, Caret & Color Scheme

What: accent-color tints native checkboxes, radios, range and progress in one declaration; appearance removes or restores native styling; caret-color colors the text cursor; color-scheme tells the browser which scheme the element supports so it can render native widgets, scrollbars and default colors to match. Gotchas: accent-color picks a readable contrast color itself, so test light and dark; appearance: none removes the focus ring and the check mark, and you must rebuild both. More: MDN: accent-color.

Resize

What: lets the user drag the corner of an element to resize it. When: textareas (vertical only is the common choice) and panels. Gotcha: it only works when overflow is not visible, and it is a pointer feature: keyboard users cannot resize, so do not hide content behind it. More: MDN: resize.

Field Sizing

Let <textarea>, <input> and <select> grow and shrink with their content — no JavaScript auto-resize needed. Combine with a min-*/max-* size to keep the field in bounds. Gotcha: a field with field-sizing: content has no intrinsic width of its own (about one character when empty), so set a min-inline-size as well. More: MDN: field-sizing.

Customizable Select

.appearance-base-select opts a <select> (and its ::picker(select) dropdown) into the new fully stylable rendering, so options can contain icons and rich HTML. Gotchas: only Chromium renders it today, other browsers show a normal select (a good fallback); the option content must stay accessible text, and you style the open list through ::picker(select). More: MDN: appearance.
