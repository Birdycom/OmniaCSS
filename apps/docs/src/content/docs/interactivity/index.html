Interactivity

CSS class _interactivity.scss interactivity/index.html v0.3.0

Utilities for controlling user interaction: cursor styles, user selection, pointer events, scroll behavior, snap, touch actions, resize, will-change, accent color, appearance, caret style and color scheme — plus newer features: auto-growing form fields (field-sizing), customizable <select>, reading-flow, CSS carousel scroll markers, scroll anchoring and print color control.

Browser support

Unsupported values are ignored and the browser keeps its default behaviour, so these classes are safe progressive enhancements.

Usage example

<button class="cursor-pointer select-none touch-manipulation"> Interactive Button </button> <div class="snap-x scroll-smooth"> <div class="snap-start">Slide 1</div> <div class="snap-start">Slide 2</div> </div>
