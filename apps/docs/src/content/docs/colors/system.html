Color Settings

v0.2.0

Global configuration for the color engine.

Main setting: $DEFAULT-COLOR-TYPE-VALUE. Supported types: hex, hsl, rgb, oklch, oklab.

// src/scss/config/omniacss.config.scss $DEFAULT-COLOR-TYPE-VALUE: oklch !default;
