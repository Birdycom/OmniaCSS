RAL color-mix examples

RAL has one token per color (--color-ral5015), so there are no -mix-{step} tokens. Mix them directly with color-mix(in oklch, var(--color-ral5015) 40%, white): with white or black to lighten and darken, or with another RAL color for a blend. Each strip goes from 100% of the first color to 0%.

RAL 5015 (sky blue) mixed with white: 100% down to 0% RAL

RAL 3020 (traffic red) mixed with white

RAL 6018 (yellow green) mixed with black

RAL 2004 (pure orange) mixed with black

RAL 5015 (sky blue) mixed with RAL 1003 (signal yellow)

RAL 3020 (traffic red) mixed with RAL 6018 (yellow green)

RAL 4005 (blue lilac) mixed with RAL 2004 (pure orange)

.swatch { background: color-mix(in oklch, var(--color-ral5015) 40%, var(--color-white-50)); } /* lighter */ .swatch { background: color-mix(in oklch, var(--color-ral6018) 60%, var(--color-black-50)); } /* darker */ .swatch { background: color-mix(in oklch, var(--color-ral5015) 50%, var(--color-ral1003)); } /* blend two RAL colors */ .swatch { background: color-mix(in oklch, var(--color-ral3020) 30%, transparent); } /* the .bg-ral3020-mix-30 utility */
