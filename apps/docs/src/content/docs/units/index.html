CSS Units

CSS class _sizing_logical.scss units/index.html v0.8.2

Lengths can be absolute (px, cm), relative to the font (em, rem, ch, cap, ic, lh, rlh), to the viewport (vw, svh, lvh, dvh) or to a container (cqi, cqb). OmniaCSS uses rem for its scale (.size-4 = 1rem) and has dedicated utilities for line-height and viewport units. See MDN: Values and units.

The lh unit: size things in lines of text

1lh is the computed line height of the element. An icon of 1lh always lines up with the first line, a box of 3lh shows exactly three lines, and a background of 1lh stripes follows the text, whatever the font size.

ClassCSS
.size-lh, .w-lh, .h-lhwidth/height: 1lh
.h-{2|3|4|5|6|8|10}lhheight: {n}lh
.min-h-{n}lh, .max-h-{n}lhmin-height / max-height: {n}lh
.block-size-{n}lhblock-size: {n}lh
.size-rlh, .h-rlh, .max-h-rlh …Same with rlh (root line height)

The check mark is exactly one line high, so it stays aligned with the first line even when the text wraps to a second line.

<p class="flex gap-2"><svg class="size-lh" viewBox="0 0 24 24">…</svg>Text that may wrap …</p>

OmniaCSS sizes this quote in lines, not in pixels. Whatever the font size or line height, the box shows exactly three lines and scrolls the remaining text. Change the font size and the box follows, because lh is computed from the element itself. Useful for previews, comments and log output.

<div class="max-h-3lh overflow-auto">Long text …</div> .un-notebook { line-height: 1.75; min-block-size: 4lh; background: var(--oc-card) repeating-linear-gradient(transparent 0 calc(1lh - 1px), var(--color-mistblue-20) calc(1lh - 1px) 1lh) local; } /* <textarea class="un-notebook field-sizing-content"></textarea> */

cap, ch and ic

1cap matches the height of capital letters (icons next to headings), ch counts characters (a readable line length of 45–75ch), ic does the same for CJK text.

CAPITAL HEIGHT

This paragraph has max-inline-size: 45ch, about 45 characters per line, which keeps long texts comfortable to read on wide screens.

.un-cap span { inline-size: 1cap; block-size: 1cap; } .un-measure { max-inline-size: 45ch; } .cjk { max-inline-size: 30ic; }

Viewport units: svh, lvh and dvh

On mobile the browser bars come and go. 100svh fits with the bars shown, 100lvh with them hidden, 100dvh follows them live (and may cause layout shifts while scrolling). Pick svh for hero sections that must fit, dvh for full-screen apps.

Container units: cqi and cqb

Inside a size container (.cq-inline), 1cqi is 1% of its inline size. Type scales with the card, not with the screen. Drag the corner.

Container-sized heading

The text follows the width of this box.

.card { container-type: inline-size; } /* = class="cq-inline" */ .card h4 { font-size: clamp(1rem, 7cqi, 2.75rem); } .card p { font-size: clamp(0.75rem, 2.8cqi, 1rem); }

Browser support

lh, rlh, cap, ic, the small/large/dynamic viewport units and container units work in all current browsers.
