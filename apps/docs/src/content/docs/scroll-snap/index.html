Scroll Snap

CSS class _interactivity.scss scroll-snap/index.html v0.8.2

Scroll snapping makes a scroll container stop on its items: carousels, full-screen sections and pickers, without JavaScript. Put .snap-x or .snap-y on the container and .snap-start/.snap-center on the items. Modern CSS adds generated controls (.scroll-markers-after for dots, .scroll-buttons for arrows) and lets you style the snapped item with the snapped: variant. Basics are also on Scrolling & touch. See MDN: CSS scroll snap.

Style the snapped item: snapped-x:

Make each item a scroll-state container (.container-scroll-state); its child can then react to "I am snapped" with snapped-x:. The centered card grows, the others fade. Scroll sideways.

The CSS behind .scroll-buttons and the markers

.scroll-buttons { anchor-name: --oc-scroller; anchor-scope: --oc-scroller; } .scroll-buttons::scroll-button(*) { position: absolute; position-anchor: --oc-scroller; top: anchor(center); translate: 0 -50%; background: oklch(from var(--color-mistblue-95) l c h / 0.75); } .scroll-buttons::scroll-button(inline-start) { content: "‹" / "Previous"; left: calc(anchor(left) + 0.5rem); } .scroll-buttons::scroll-button(inline-end) { content: "›" / "Next"; right: calc(anchor(right) + 0.5rem); } .scroll-buttons::scroll-button(*):disabled { opacity: 0.3; } .scroll-markers-after { scroll-marker-group: after; } .scroll-markers-after > *::scroll-marker { content: ""; inline-size: 0.7rem; aspect-ratio: 1; border-radius: 50%; } .scroll-markers-after > *::scroll-marker:target-current { background: var(--color-vividblue-80); }

Browser support

Scroll snapping works everywhere. Scroll buttons, markers and scroll-state() queries are Chromium-only for now; other browsers simply show a snapping row without controls.

Source & Further Reading
