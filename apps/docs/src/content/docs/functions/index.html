CSS Functions

CSS class _css_functions.scss functions/index.html v0.8.2

CSS can calculate. From calc() via clamp() to progress(), stepped values (round(), mod()), exponents and trigonometry, tree counting (sibling-index(), sibling-count()), typed attr(), inline conditions with if(), calc-size() and random(). OmniaCSS ships utilities on top of them (.delay-stagger, .fan, .text-fluid-*), and you can use every function in your own CSS next to the tokens. Color functions are on Color functions. See MDN: CSS functions.

From clamp() to progress()

clamp(min, value, max) limits a value. progress(value, start, end) goes one step further: it tells you how far a value is between two points, as a number from 0 to 1. Use that number for anything: width, opacity, a color mix, a counter. Below, the container width (100cqi) between 12rem and 36rem drives the bar, its color and the percentage text. Drag the corner to resize.

Drag the bottom-right corner →

.fn-resize { container-type: inline-size; resize: horizontal; overflow: hidden; } .fn-progress { --p: 0.5; /* fallback */ --p: clamp(0, progress(100cqi, 12rem, 36rem), 1); /* 0 … 1 */ inline-size: calc(var(--p) * 100%); background: color-mix(in oklch, var(--color-blue-50), var(--color-magenta-50) calc(var(--p) * 100%)); counter-reset: fnp calc(var(--p) * 100); /* integer context rounds */ } .fn-progress::after { content: counter(fnp) "%"; } /* The same idea for fluid type, without the "preferred value" math of clamp() */ h1 { font-size: calc(1.5rem + progress(100vw, 20rem, 80rem) * 2rem); }

Stepped values: round(), mod(), rem()

round(strategy, value, step) snaps to a multiple of step (nearest, up, down, to-zero). The bar below only grows in whole 3rem steps, whatever the container width.

Resize: the bar jumps per 3rem column

.fn-snap { inline-size: round(down, 100%, 3rem); } /* More examples */ .grid-auto { grid-template-columns: repeat(round(down, 100cqi, 16rem) / 16rem, 1fr); } .hue-wrap { rotate: mod(450deg, 360deg); } /* 90deg */ .offset { margin-left: rem(-7px, 3px); } /* -1px (sign of the dividend) */ .distance { inline-size: abs(var(--delta)); } .direction { translate: calc(sign(var(--delta)) * 1rem); }

Exponential: pow(), sqrt(), hypot(), log(), exp()

A modular type scale is one formula: 1rem × 1.25step. hypot() gives the diagonal of a box, sqrt() and log() smooth large ranges.

Aa-1 Aa0 Aa1 Aa2 Aa3 Aa4 Aa5
.fn-scale span { font-size: calc(1rem * pow(1.25, var(--step))); } .diagonal { inline-size: hypot(30rem, 20rem); } /* ≈ 36.06rem */ .root { inline-size: calc(sqrt(2) * 10rem); } .soft { opacity: calc(log(var(--n) + 1) / log(101)); }

Trigonometry + tree counting: a circle without JavaScript

Each dot computes its own angle from sibling-index() and sibling-count(), then its position with cos() and sin(). Add or remove dots and the circle redistributes itself; the color mixes between two Omnia tokens along the way.

.fn-orbit > span { --a: calc((sibling-index() - 1) * 360deg / sibling-count()); position: absolute; left: calc(50% + cos(var(--a)) * 5.5rem - 1.1rem); top: calc(50% + sin(var(--a)) * 5.5rem - 1.1rem); background: color-mix(in oklch, var(--color-blue-50), var(--color-magenta-50) calc((sibling-index() - 1) / (sibling-count() - 1) * 100%)); } .fn-orbit { animation: fn-turn 18s linear infinite; } @keyframes fn-turn { to { rotate: 1turn; } }

Typed attr(): data straight from HTML

attr() used to work only in content. With a type it works in every property: attr(data-value type(<percentage>), 0%). The bar chart below has no inline styles, only data attributes.

.fn-chart div::before { content: attr(data-label); } .fn-chart span { inline-size: 40%; /* fallback */ inline-size: attr(data-value type(<percentage>), 0%); } /* other types: attr(data-size type(<length>)), attr(data-color type(<color>)), attr(data-n type(<integer>)) */ /* <div data-label="CSS"><span data-value="78%"></span></div> */

if(): conditions inside a value

if() picks a value based on style(), media() or supports(), without a separate rule. Write a plain value first for browsers without if().

done busy idle
.fn-status { background: var(--color-gray-50); /* fallback */ background: if( style(--fn-state: done): var(--color-green-60); style(--fn-state: busy): var(--color-orange-60); else: var(--color-gray-50) ); } .card { padding: if(media(width >= 40rem): 2rem; else: 1rem); } .grid { display: if(supports(display: grid-lanes): grid-lanes; else: grid); }

calc-size() and interpolate-size: animate to auto

interpolate-size: allow-keywords (utility .interpolate-size-keywords) lets height: auto animate. calc-size(auto, size + 1rem) calculates with intrinsic sizes. Open the accordion: no JavaScript, no max-height trick.

How does this open smoothly?

The ::details-content pseudo-element animates its block-size from 0 to auto, because the parent allows keyword interpolation. content-visibility switches with allow-discrete at the end.

.fn-acc { interpolate-size: allow-keywords; } /* or class="interpolate-size-keywords" */ .fn-acc::details-content { block-size: 0; overflow: clip; transition: block-size 0.35s, content-visibility 0.35s allow-discrete; } .fn-acc[open]::details-content { block-size: auto; } /* Only for one property: */ .panel { block-size: calc-size(auto, size + 2rem); }

random(): a different value per element

Every piece of confetti gets its own position and angle. Browsers without random() keep the line above it: a pseudo-random spread from sin() of the sibling index.

.fn-confetti i { /* fallback: deterministic spread */ translate: calc(sin(sibling-index() * 57deg) * 9rem) calc(cos(sibling-index() * 91deg) * 3.5rem); rotate: calc(sibling-index() * 47deg); /* random() per element */ translate: random(-10rem, 10rem) random(-4rem, 4rem); rotate: random(0deg, 360deg); } .dice { --n: random(1, 6, by 1); } /* steps */ .same { rotate: random(--shared, 0deg, 90deg); } /* same value for every element */

env(): safe areas and the device

.app-bar { padding-bottom: max(1rem, env(safe-area-inset-bottom)); } /* notch / home bar */ .screen { height: calc(100dvh - env(safe-area-inset-top)); } /* = .h-screen-safe */ .titlebar { inline-size: env(titlebar-area-width, 100%); } /* installed PWA */ .kb-aware { padding-bottom: env(keyboard-inset-height, 0px); } /* virtual keyboard */

Browser support

calc(), min(), max(), clamp(), the stepped, exponential and trigonometric functions work in every current browser. progress(), sibling-index() and typed attr() are new; if(), calc-size() and random() are not everywhere yet — every demo here writes a fallback first.
