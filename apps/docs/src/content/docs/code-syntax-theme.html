From VS Code theme to code-syntax CSS

CSS oc-code-syntax.css v0.2.0

Uitleg hoe we uit het VS Code-thema (Birdycom Omnia Dark) de kleuren voor codeblokken halen en in CSS gebruiken. Eén gedeelde set variabelen voor HTML, CSS, PHP, JS, JSON, Python. Voor de technische reference (bestanden, script, token variables) zie Code syntax.

Situatie

Het thema src/json/omniathememain.json bevat colors (editor UI) en tokenColors (scope → foreground/fontStyle). Onze syntax-CSS (oc-code-syntax.css) kleurt klassen zoals .hl-tag, .hl-attr, .hl-string; die spans worden bij de build toegevoegd door de docs-highlighter (apps/docs/src/lib/highlight.mjs). Doel: dezelfde kleuren als in de editor voor codeblokken op de site, met één theme-CSS file voor alle talen.

Overzicht per programmeertaal (thema → CSS)

Eén set CSS custom properties; het conversiescript leest de theme JSON en vult --oc-syntax-*. Zo blijft één file bruikbaar voor HTML, PHP, JS, enz.

Hoe we aan de CSS komen

We gebruiken een build script: oc-code-syntax.css bevat alle token-klassen en de Omnia Dark theme variables in één bestand. Het script leest src/json/omniathememain.json, zoekt per token-type de juiste tokenColors- of colors-entry, en werkt het :root-blok in oc-code-syntax.css bij.

Zie Code syntax → Theme generation voor het commando (npm run code-syntax-theme) en de scriptlocatie.

Gebruik voor andere talen (bv. PHP)

Dezelfde CSS-file geldt voor alle codeblokken. Voor PHP of JS moet een highlighter de bron omzetten naar HTML met dezelfde klassen (.hl-keyword, .hl-string, .hl-variable, enz.), bijv. via Prism/Highlight.js met een custom theme of een uitbreiding van apps/docs/src/lib/highlight.mjs. Het overzicht per taal in deze doc is de referentie voor welke theme-scope bij welk token-type hoort.
