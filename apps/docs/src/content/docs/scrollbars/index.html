Scrollbars

CSS class _scrollbar.scss scrollbars/index.html v0.3.0

Style scrollbars with standard CSS: make them thin or hidden, reserve space so layouts do not shift, and set thumb and track colors. See MDN: scrollbar-color.

Scrollbar width

.scrollbar-none hides the scrollbar while the element stays scrollable — keep a visible scroll hint for accessibility. What: scrollbar-width chooses between the default, a thin (compact) or no scrollbar. When: thin for dense panels, code blocks and sidebars; none for carousels and tab strips that have their own affordance. Gotchas: the value is a hint, browsers decide the exact size; hiding the scrollbar removes the only visual cue that content continues, so keep keyboard access (tabindex="0") and a visible hint. More: MDN: scrollbar-width.

ClassCSS
.scrollbar-autoscrollbar-width: auto
.scrollbar-thinscrollbar-width: thin
.scrollbar-nonescrollbar-width: none

Scrollbar gutter

Reserve space for the scrollbar so content does not jump when it appears (e.g. opening a modal). What: stable always keeps the gutter, both-edges mirrors it on the opposite side so centred content stays centred. When: containers whose content length changes (filtered lists, accordions, tabs), and <html> for pages that toggle a modal. Gotcha: overlay scrollbars (macOS default, mobile) have no gutter, so you only see the effect with classic scrollbars. More: MDN: scrollbar-gutter.

.scrollbar-gutter-auto

Short text, no scrollbar: it uses the full width.

.scrollbar-gutter-stable

Same text: a strip on the right stays reserved.

.scrollbar-gutter-both

Reserved on both sides, so content stays centred.

<div class="overflow-y-auto scrollbar-gutter-stable">…</div> <div class="overflow-y-auto scrollbar-gutter-both">…</div>

Scrollbar color

.scrollbar-color applies the thumb and track colors set by the .scrollbar-thumb-* and .scrollbar-track-* classes (custom properties --oc-scrollbar-thumb / --oc-scrollbar-track). What: scrollbar-color takes two colors (thumb, then track) and is the standards-based way to theme scrollbars; it is inherited, so one class on a parent colors every scroller inside. Gotchas: setting a color switches the scrollbar from the native look to a flat, custom one; there is no hover state or rounding to control; keep enough contrast between thumb and track (at least 3:1) so it stays findable. More: MDN: scrollbar-color.

Browser support

Unsupported scrollbar properties are ignored and the platform's default scrollbar is shown.

OmniaCSS scrollbar

_scrollbar.scss v0.4.0

.scrollbar-omnia gives a thin scrollbar with an Omnia-blue thumb on a transparent track, in light and dark mode. scrollbar-color is inherited, so one class on <html> themes every scroll area — this documentation site does exactly that. Inside it, .scrollbar-none, .scrollbar-auto and the color classes still win.
