Responsive, Dark Mode & State Variants

Use prefix-based modifiers to apply utilities conditionally. Responsive (sm:/md:/lg:), dark mode (dark:/auto-dark:), states (hover:/focus:/active:) and group hover (group-hover:).

Breakpoints v0.2.0

OmniaCSS uses three mobile-first breakpoints. Each prefix generates a min-width media query.

PrefixMin-widthCSS
sm:36rem (576px)@media (min-width: 36rem)
md:50rem (800px)@media (min-width: 50rem)
lg:64rem (1024px)@media (min-width: 64rem)

Responsive Utilities v0.2.0

The following utility families have responsive variants:

Display

<!-- Hidden on mobile, flex on medium+ --> <div class="hidden md:flex">...</div> <!-- Block on mobile, grid on large --> <div class="block lg:grid lg:grid-cols-3">...</div>

Grid columns

<!-- 1 column mobile, 2 medium, 4 large --> <div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-4"> <div>Item 1</div> <div>Item 2</div> <div>Item 3</div> <div>Item 4</div> </div>

Width

<!-- Full width on mobile, half on medium, third on large --> <div class="w-full md:w-1/2 lg:w-1/3">...</div>

Text alignment

<!-- Center on mobile, left on large --> <p class="text-center lg:text-left">Responsive text</p>

Spacing

<!-- Tight padding on mobile, more on medium+ --> <div class="p-2 md:p-6 lg:p-8">Content</div>

Dark Mode v0.2.0

Dark mode works with CSS only: color-scheme + light-dark() tokens, switched with a radio group and :has(). No JavaScript is needed to switch.

CSS-only switch (recommended)

Every --oc-* theme token is light-dark(light, dark). A .oc-theme-switch radio group anywhere on the page sets color-scheme on :root through :has(), so the whole page follows instantly (the header switch of this site works that way).

The demo below is deliberately isolated: it uses its own radio name and scopes the same :has() trick to the demo box (.oc-theme-scope) instead of :root, so it only themes the box and never fights with the header switch.

This box follows the switch above; the rest of the page does not.

 <fieldset class="oc-theme-switch" aria-label="Color theme"> <label><input type="radio" name="oc-theme" value="system" checked> System</label> <label><input type="radio" name="oc-theme" value="light"> Light</label> <label><input type="radio" name="oc-theme" value="dark"> Dark</label> </fieldset> /* components.css */ :root:has(.oc-theme-switch input[value="light"]:checked) { color-scheme: light; } :root:has(.oc-theme-switch input[value="dark"]:checked) { color-scheme: dark; } /* scoped variant (as in the demo above): only the container is themed */ .oc-theme-scope:has(input[value="dark"]:checked) { color-scheme: dark; } /* your own styles */ .card { background: light-dark(var(--color-white-50), var(--color-duskblue-100)); }

Remembering the choice: pure CSS cannot persist state between page loads. The docs site adds one optional, tiny progressive-enhancement script that only stores the selected value in localStorage and restores it as data-theme. The switching itself never depends on it; without the script the page simply starts in "System" again.

Fixed theme and the dark: variants

Set a fixed theme in markup with <html data-theme="dark"> (or class="dark"). The dark: utilities apply below a .dark ancestor, so they are meant for pages that are dark from the server or from the markup.

<html class="dark"> <body> <div class="dark:bg-gray-900 dark:text-white"> Dark mode content </div> </body> </html>

Auto-detection

Uses prefers-color-scheme: dark to follow the OS. No JS needed.

<div class="auto-dark:bg-gray-900 auto-dark:text-white"> Automatically dark when OS is in dark mode </div>

State Variants v0.2.0

Apply utilities on hover, focus, active or focus-visible states.

<!-- Hover: scale up and add shadow --> <div class="hover:scale-105 hover:shadow-lg" style="transition:all 0.15s;"> Hover me </div> <!-- Focus: add ring --> <input class="focus:ring-2 focus:outline-none" type="text"> <!-- Active state --> <button class="hover:bg-gray-100 active:scale-95">Click me</button>

Group hover

Parent with class .group triggers child state changes on hover.

<div class="group"> <img src="..." class="group-hover:scale-105"> <p class="group-hover:text-white">Title</p> </div>

Disabled state

<button class="disabled:opacity-50 disabled:cursor-not-allowed" disabled> Disabled button </button>

Combining Variants v0.2.0

You can combine responsive, dark mode and state variants by stacking classes:

<!-- On mobile: block, on medium: flex, on hover: shadow --> <div class="block md:flex hover:shadow-lg dark:bg-gray-800"> Combined variants </div> <!-- Responsive grid with hover effects --> <div class="grid grid-cols-1 md:grid-cols-3 gap-4"> <div class="p-4 hover:scale-105 hover:shadow-lg dark:bg-gray-900">Card</div> </div>
