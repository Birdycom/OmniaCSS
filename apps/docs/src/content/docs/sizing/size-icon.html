Icon & Square Size

_sizing.scss v0.2.0

Set width and height at the same time with .size-{n}.

.size-n sets width and height to the same rem value, ideal for icons, avatars and square buttons. Pair it with .flex-shrink-0 so the box is not squeezed in a flex row, and with .round-full for circles. If you need a ratio rather than a fixed size, use .aspect-1 with a width instead. See MDN: width and MDN: height.
