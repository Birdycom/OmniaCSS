Min/Max Height

_sizing.scss v0.2.0

Set a floor or a ceiling for the height of an element.

min-height reserves space (cards that should align, full-height pages) while still letting content grow; max-height caps the box and, together with overflow-auto, creates a scroll area. Avoid fixed heights for text: they overflow when users enlarge fonts. .min-h-screen is 100vh; on mobile prefer .min-h-dvh. A percentage max-height needs a parent with a definite height. See MDN: min-height and MDN: max-height.
