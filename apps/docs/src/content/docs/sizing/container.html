Container

_container.scss v0.2.0

A component for fixing an element's width to the current breakpoint.

.container centres a block, adds horizontal padding and caps its max-width per breakpoint, so page content never gets uncomfortably wide. It sets width: 100% first, so on small screens it simply fills the viewport. Nest it only once per page section; for components that react to their own width, use a container-query (.container-inline-size) instead, which is a different feature.
