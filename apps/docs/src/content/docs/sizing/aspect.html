Aspect Ratio

_aspect.scss v0.2.0

Utilities for setting the preferred aspect ratio of an element.

aspect-ratio keeps width and height in proportion, so media boxes reserve their space before an image or video loads (no layout shift) and cards stay uniform. It needs one auto dimension: if both width and height are set, the ratio is ignored. The ratio is a preferred value: content that is taller than the box (or min-height) makes it grow, unless you add .overflow-hidden and a fixed size. For replaced elements like <img> and <video>, .aspect-auto uses the intrinsic ratio of the file. See MDN: aspect-ratio.

Ratio with images and content overflow

Pair the ratio with .object-cover to crop a differently shaped image to the box. The dashed outline in each tile is the 16:9 shape. Short content fits it; long content makes the box grow past it; with .overflow-hidden .min-h-0 the box keeps its ratio and the text is cut off.

.aspect-16
Short content: the box keeps 16:9.
16 : 9, short content
.aspect-16
Too much content: the box grows.
This text is longer than the box has room for, so the box grows taller than the dashed 16:9 shape. The browser does this on purpose: aspect-ratio is only a preferred size, and the box has a minimum height of auto, so it grows to keep all the text readable. Customer 1 can still read every word of this note.
.aspect-16 .overflow-hidden .min-h-0
Keeps 16:9, the text is clipped.
This text is longer than the box has room for. Because overflow is hidden and the minimum height is 0, the box keeps its 16:9 shape and the rest of the text is cut off at the bottom edge. Customer 1 can no longer read the end of this note, so only use this for content that may be cut.
