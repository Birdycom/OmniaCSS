Aspect Ratio

_aspect.scss v0.2.0

Utilities for setting the preferred aspect ratio of an element.

aspect-ratio keeps width and height in proportion, so media boxes reserve their space before an image or video loads (no layout shift) and cards stay uniform. It needs one auto dimension: if both width and height are set, the ratio is ignored. The ratio is a preferred value: content that is taller than the box (or min-height) makes it grow, unless you add .overflow-hidden and a fixed size. For replaced elements like <img> and <video>, .aspect-auto uses the intrinsic ratio of the file. See MDN: aspect-ratio.
