Min/Max Width

_sizing.scss v0.2.0

Constrain how narrow or wide an element may become while its width stays flexible.

max-width keeps a box from growing beyond a limit while still allowing it to shrink: it is the right tool for readable text columns (.max-w-prose is 65ch) and responsive cards, where a fixed width would overflow small screens. min-width prevents shrinking, e.g. buttons or flex items; a flex item that must be allowed to shrink below its content needs .min-w-0. max-width overrides width, min-width overrides both. See MDN: max-width and MDN: min-width.

.max-w-prose is measured in characters (65ch), so it follows the font size. It keeps lines of text at a comfortable reading length. Drag the box narrower and the text simply wraps sooner.

Min-Width Utilities

The numbered min-width classes use quarter steps of a rem: .min-w-{n} is n × 0.25rem, so .min-w-24 is 6rem (96px). The width scale .w-{n} uses whole rems.

The most useful min-width is .min-w-0. A flex item will not shrink below its content by default, so a long file name pushes the button out of the box. With .min-w-0 the name may shrink and .truncate adds the dots. The button has .min-w-24 and never gets narrower than 6rem. The box starts narrow, so the second row already overflows; drag it wider and narrower and compare the two rows.

.min-w-0 .truncate
With it the file name shrinks and gets dots. Without it the name pushes the button out.
