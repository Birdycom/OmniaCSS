Min/Max Width

_sizing.scss v0.2.0

Constrain how narrow or wide an element may become while its width stays flexible.

max-width keeps a box from growing beyond a limit while still allowing it to shrink: it is the right tool for readable text columns (.max-w-prose is 65ch) and responsive cards, where a fixed width would overflow small screens. min-width prevents shrinking, e.g. buttons or flex items; a flex item that must be allowed to shrink below its content needs .min-w-0. max-width overrides width, min-width overrides both. See MDN: max-width and MDN: min-width.
