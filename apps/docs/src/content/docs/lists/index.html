Lists & Counters

CSS class _text.scss lists/index.html v0.3.0

Utilities for list markers (type, position, image) and for CSS counters, which number any element — not only list items. See MDN: Using CSS counters.

List style type

list-style-type picks the marker for <ul>, <ol> and any element with display: list-item. Besides bullets and decimal numbers it offers alphabetic, roman, greek and many international systems; the disclosure-* markers are the open/closed triangles used by <details>. Gotcha: list-style-type: none removes the list role in Safari VoiceOver, so add role="list" when you reset the markers of a navigation or card list. An unknown type falls back to decimal or disc. See MDN: list-style-type.

List style position & image

Position decides whether the marker sits outside the item's box (default, text lines align with each other) or inside it, where the marker is the first inline element of the text and wrapped lines go underneath it. list-style-image replaces the marker with an image; the highlighted background below shows each <li> box. For coloured or sized markers use the ::marker pseudo-element instead of images. See MDN: list-style-position and MDN: list-style-image.

CSS counters

CSS counters number any element, not only list items, and can be nested (1, 1.1, 1.2). Three steps: counter-reset on the parent creates (or restarts) the counter, counter-increment on each child adds one, and .content-counter prints the value in ::before. .content-counters joins the values of all nested counters (1.2.3). Gotcha: a counter that is reset on a sibling instead of the parent restarts the numbering at the wrong level, and display: none elements do not increment. See MDN: counter-reset.

Custom counter styles

@counter-style defines your own marker system (symbols, suffix, range) and works with both list-style-type and counter(). It is plain CSS, so declare it next to your component; the style name is then usable as a value. Use ::marker to colour or resize the marker without touching the text. See MDN: @counter-style.

@counter-style steps { system: numeric; symbols: "1" "2" "3" "4" "5" "6" "7" "8" "9"; suffix: " - "; } .steps { list-style-type: steps; } .steps li::marker { color: var(--color-vividblue-80); font-weight: 700; }

Browser support

List and counter utilities are broadly supported; unknown list-style types fall back to decimal/disc.
