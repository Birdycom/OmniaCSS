Code syntax

CSS oc-code-syntax.css v0.2.0

Technische reference: bestanden, usage, theme-generation script en token variables. Voor de uitleg hoe we uit het VS Code-thema aan de CSS komen en de mapping per taal, zie Theme to CSS.

Files

FileContains
public/css/oc-code-syntax.cssBase block (pre.code), all token classes (e.g. .hl-tag, .hl-keyword), --oc-syntax-* variables (Omnia Dark). To refresh from theme: npm run code-syntax-theme.

Usage

Use <pre class="code"><code>...</code></pre>. Tags, attributes and strings get spans with .hl-tag, .hl-attr, .hl-string, etc. The docs build highlights code ahead of time (no script in the page); in your own project wrap tokens in the same .hl-* spans or render them on the server.

Theme generation

To regenerate the Omnia theme CSS from the VS Code theme JSON:

npm run code-syntax-theme

Runs scripts/build-code-syntax-theme.mjs: reads src/json/omniathememain.json, maps tokenColors and colors.editor.* to --oc-syntax-*, and updates the :root block in oc-code-syntax.css in place. Per-language mapping: Theme to CSS → Overzicht per taal.
