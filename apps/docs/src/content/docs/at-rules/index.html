At-rules

CSS feature variants.mjs at-rules/index.html v0.8.2

Every CSS statement that starts with @: conditional rules (@media, @container, @supports), cascade control (@layer, @scope), definitions (@property, @keyframes, @font-face, @counter-style, @function) and page/print rules (@page). OmniaCSS turns the conditional ones into variants (md:, cq-md:, supports-[…]:, starting:), so you rarely write them by hand. See MDN: At-rules.

All at-rules and how OmniaCSS uses them

@supports: feature queries

Apply styles only when the browser understands a declaration, a selector (selector()), a font technology (font-tech(), font-format()) or an at-rule (at-rule()). Combine them with and, or and not. In OmniaCSS you write the condition in the class: supports-[field-sizing:content]:inline; spaces become _.

@layer: cascade layers

Layers decide which rules win before specificity is compared: a later layer beats an earlier one, even when the earlier rule uses an id. omniacss build puts all utilities in @layer omnia, so you can place your own reset before it and your overrides after it. Unlayered CSS always beats layered CSS.

#id in layer ar-base → loses
.class in layer ar-theme → wins (green)
@layer ar-base, ar-theme; /* order is decided here */ @layer ar-theme { .ar-layer-box { background: var(--color-green-50); } } @layer ar-base { #ar-layer-target.ar-layer-box { background: var(--color-red-60); } /* higher specificity, earlier layer */ } /* With OmniaCSS */ @layer reset, omnia, components, overrides; @import url("omnia.css") layer(omnia); @import url("theme.css") layer(components) supports(display: grid);

@property: typed, animatable variables

A registered custom property has a type (<angle>, <color>, <length>, <integer> …), an initial value and an inheritance flag. Because the browser knows the type it can interpolate it: gradients, angles and counters become animatable. More on the Variables page.

@property --ar-angle
@property --ar-angle { syntax: "<angle>"; inherits: false; initial-value: 0deg; } .ar-spin-border { border: 3px solid transparent; border-radius: 16px; background: linear-gradient(var(--oc-card), var(--oc-card)) padding-box, conic-gradient(from var(--ar-angle), var(--color-blue-50), var(--color-magenta-50), var(--color-orange-50), var(--color-blue-50)) border-box; animation: ar-angle 4s linear infinite; } @keyframes ar-angle { to { --ar-angle: 360deg; } }

@scope: styles with an upper and a lower limit

@scope (root) to (limit) styles only the elements between the scope root and the limit (a "donut"). Slots, nested widgets and user content inside the limit stay untouched, without long selectors or naming schemes.

Inside the scope: blue and bold.

Inside the limit (.ar-scope-slot): not styled by the scope.

@scope (.ar-scope-card) to (.ar-scope-slot) { p { color: var(--color-vividblue-80); font-weight: 600; } } /* :scope refers to the root itself */ @scope (.card) { :scope { container-type: inline-size; } }

@container style(): query a variable

Size queries are covered on Container queries. Style queries test a custom property of the parent: set --status once and every child adapts. Every element is a style container, so no container-type is needed.

--status: ok
--status: warn
--status: danger
@container style(--status: ok) { .ar-badge { background: var(--color-green-60); } } @container style(--status: warn) { .ar-badge { background: var(--color-orange-60); } } @container style(--status: danger) { .ar-badge { background: var(--color-red-60); } } /* <div style="--status: danger"><span class="ar-badge">…</span></div> */

@function: your own CSS functions

A custom function takes arguments and returns a result. Write the plain declaration first: browsers without @function drop the second line and keep the fallback. Drag the corner of the box to resize it.

Resize me: fluid heading

@function --ar-fluid(--min, --max) { result: clamp(var(--min), 0.5rem + 4cqi, var(--max)); } .ar-fn-text { font-size: 1.25rem; /* fallback */ font-size: --ar-fluid(1rem, 2.75rem); /* Chromium 139+ */ }

@media: range syntax and custom media

Media queries accept comparison operators. @custom-media gives a query a name; until browsers support it widely, the OmniaCSS breakpoint variants do the same job.

@media (40rem <= width < 64rem) { … } /* = md: up to lg */ @media (prefers-reduced-motion: no-preference) and (hover: hover) { … } @media (dynamic-range: high) and (color-gamut: p3) { … } @media (scripting: none) { … } /* noscript: variant */ @custom-media --tablet (40rem <= width < 64rem); /* Firefox only, behind a flag */ @media (--tablet) { … }

@page: print pages and margin boxes

Set paper size, margins and running headers or page numbers for printing. Combine with .break-before-page and .break-inside-avoid from Fragmentation.

@page { size: A4; margin: 2cm 1.5cm; @bottom-center { content: "Page " counter(page) " of " counter(pages); } } @page :first { margin-top: 4cm; @bottom-center { content: none; } } @page chapter { @top-left { content: "OmniaCSS"; } } .chapter { page: chapter; }

@import, @namespace, @font-palette-values, @font-feature-values

@charset "UTF-8"; @import url("omnia.css") layer(omnia) supports(color: oklch(0% 0 0)); @import url("print.css") print; @namespace svg url(http://www.w3.org/2000/svg); svg|a { fill: currentColor; } @font-palette-values --brand { font-family: "Bungee Spice"; override-colors: 0 var(--color-vividblue-80), 1 var(--color-magenta-50); } .logo { font-palette: --brand; } @font-feature-values "Fira Sans" { @styleset { alt-g: 1; } } .alt { font-variant-alternates: styleset(alt-g); }

Browser support

@media, @supports, @layer, @property and @container work everywhere. @scope and style queries are new in Firefox and Safari; @function and at-rule() are Chromium-first, so always write a fallback first.
