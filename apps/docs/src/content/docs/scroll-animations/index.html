Scroll-driven Animations

CSS class _scroll_animations.scss scroll-animations/index.html v0.3.0

Drive CSS animations by scroll progress instead of time. Use a ready-made preset (.animate-view-fade-in, .animate-scroll-progress) or combine your own animation with .timeline-* and .animate-range-*. Presets are wrapped in @supports, so content stays visible in browsers without support. See MDN: Scroll-driven animations.

Presets

Complete scroll-driven animations: add one class. What: instead of running for a number of seconds, the animation progresses as the user scrolls, entirely on the compositor and without IntersectionObserver or scroll listeners. When: reading-progress bars, reveal-on-scroll, parallax, sticky headers that shrink. Gotchas: the presets use scroll(root) or view(); view() looks at the nearest scrolling ancestor, so it works inside any scroll container, while scroll(root) needs the page itself to scroll. The animation has no duration: animation-duration is ignored (auto), and animation: x 1s shorthands reset the timeline, so set the timeline after the shorthand. Presets switch off for prefers-reduced-motion. More: MDN: Scroll-driven animations.

Animation timeline

Which timeline drives the animation on the element. What: scroll() follows how far a scroller is scrolled (0% to 100%); view() follows how far the element itself has travelled through the scrollport (entering, covering, exiting). When: use scroll() for progress bars and header effects, view() for reveals, parallax and highlights. Gotchas: the axis matters (.timeline-scroll-x, .timeline-view-x for horizontal scrollers); the scroller must really overflow, and overflow: hidden ancestors also count as scrollers and can steal the timeline. More: MDN: animation-timeline.

Animation range

Which part of the timeline the animation runs in. What: a view timeline has named phases: entry (starts to enter until fully inside), contain, cover (whole crossing) and exit; you can also use offsets like entry 0% entry 50%. When: to let a reveal finish early (entry) or to fade an element out at the end (exit). Gotcha: animation-range shorthand resets when you write the animation shorthand afterwards, so order your declarations. More: MDN: animation-range.

Named timelines & scope

Create the named timeline --oc-timeline on a scroller or subject and use it elsewhere with .timeline-oc. .timeline-scope-oc on a common ancestor makes it visible to elements outside the subtree. What: a named timeline lets an element that is not a descendant of the scroller (a sticky header, a sidebar, a progress indicator) follow it. Gotcha: without timeline-scope on a shared ancestor the name is only visible to the descendants of the element that defines it, and the name must be unique inside that scope. More: MDN: timeline-scope.

Timeline functions

The anonymous forms need no names: scroll(<scroller> <axis>) takes nearest (default), root or self plus block, inline, x or y; view(<axis> <inset>) can shrink the observed area with an inset such as view(block 10% 10%).

FunctionDescription
scroll()Anonymous scroll progress timeline of the nearest (or root) scroller
view()Anonymous view progress timeline — the element crossing the scrollport

Usage example

Combine an existing animation with a timeline and range.

<div class="animate-spin timeline-view animate-range-cover">…</div> /* Custom keyframes */ .card { animation: my-reveal linear both; animation-timeline: view(); animation-range: entry 0% entry 100%; }

Browser support

Presets are wrapped in @supports (animation-timeline: scroll()): browsers without support show the content without animation.
