Table Layout

_table_advanced.scss v0.2.0

Choose the algorithm used to size table columns: content driven or fixed.

With .table-auto (default) the browser reads the whole table to size the columns, so widths follow the content but the table can jump while loading. .table-fixed uses only the first row and the table width: columns are equal unless you set widths on cells, rendering is faster and predictable, and long content is clipped or wraps inside its column instead of widening it. Fixed layout needs a table width (e.g. .w-full). Combine it with .truncate for ellipsised cells. See MDN: table-layout.

Set the column widths

With .table-fixed the browser reads the widths from the first row only. Put the width classes on the header cells: here 1/4, 1/2 and 1/4 of the table.

.table-fixed .w-perc-1/4 .w-perc-1/2
Fixed layout with set widths: a quarter, a half and a quarter of the table.
