Caption Side

_table_advanced.scss v0.2.0

Choose whether a table caption is shown above or below the table.

A <caption> gives a table an accessible name and a visible title. By default it sits on top; .caption-bottom moves it below, which suits source notes and figure-style captions. The class goes on the table (or the caption itself) and it is the caption, not the table, that is aligned with text-align. Prefer a real caption over a heading nearby, because assistive technology announces it together with the table. See MDN: caption-side.
