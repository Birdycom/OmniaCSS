Border Collapse

_table_advanced.scss v0.2.0

Control whether table borders are collapsed into a single border or detached.

With .border-collapse neighbouring cells share one border line, which gives the classic grid look and is what most data tables want. .border-separate (the browser default) draws a border around every cell with a gap between them (see Border Spacing) and is the only mode in which border-radius works on cells. Gotchas: in collapse mode border-spacing is ignored, and conflicting borders are resolved by width, style and then element order. See MDN: border-collapse.
