Border Spacing

_table_advanced.scss v0.2.0

Set the distance between the borders of adjacent cells in a separated-borders table.

border-spacing adds space between cells (and between the cells and the table edge), like a gap for tables. It only works with .border-separate: collapsed tables ignore it. It is inherited, so set it on the table. The scale is rem based, so .border-spacing-1 is a quarter of a rem step as listed below. For a spacing between rows only, use two values in custom CSS (border-spacing: 0 0.5rem) to make "card rows". See MDN: border-spacing.
