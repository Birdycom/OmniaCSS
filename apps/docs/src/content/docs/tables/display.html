Table Display

_table.scss v0.2.0

Give any element the layout behaviour of a table, row or cell.

The display: table-* values apply the table layout algorithm to ordinary elements. That is rarely needed for data (use real <table> markup so screen readers get the semantics), but it is useful for equal-height columns, vertical centring or when a design needs auto-sized columns that grid and flex do not give. Cells of one "row" stay the same height and columns align across rows automatically. Elements with .table-cell need a .table-row (or .table) ancestor; missing wrappers are generated anonymously. See MDN: display.
