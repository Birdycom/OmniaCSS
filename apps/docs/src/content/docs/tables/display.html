Table Display

_table.scss v0.2.0

Give any element the layout behaviour of a table, row or cell.

The display: table-* values apply the table layout algorithm to ordinary elements. That is rarely needed for data (use real <table> markup so screen readers get the semantics), but it is useful for equal-height columns, vertical centring or when a design needs auto-sized columns that grid and flex do not give. Cells of one "row" stay the same height and columns align across rows automatically. Elements with .table-cell need a .table-row (or .table) ancestor; missing wrappers are generated anonymously. See MDN: display.

Equal-height columns

Cells in one row are always the same height. The middle text is the longest, and the other two columns grow with it. .table-fixed makes the three columns equally wide, and .border-separate .border-spacing-2 puts a gap between them.

.table .table-cell
The three cells are always equally high, like the cells of a table row.

Customer 1 picks Product 1.

3. Delivery

Inline table

.table behaves like a block, .inline-table like an inline element. Read the two sentences: the small two-cell table is the same in both.

.table-column-group and .table-column stand for <colgroup> and <col>: empty divs that let you set a background or a width for a whole column at once.
